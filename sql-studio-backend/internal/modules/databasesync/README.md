# 数据库同步

New 注入已保存连接仓库和按数据库类型注册的同步实现。先校验两端数据库类型相同。源和目标可各自使用已保存连接或请求级外部凭据。Databases(ctx,endpoint) 在 10 秒内返回可用库名。Check(ctx,input) 只读检查源库、目标库和可复制的表，最长 30 秒。Run(ctx,input,emit) 独占一个进程内同步名额，最长 30 分钟。每次运行重新检查，回调传递阶段、对象数和已确认写入记录数，并将请求取消传递到驱动。外部凭据只在当前请求使用，连接列表与状态文件不记录临时连接。

目标库必须不存在且显式允许创建。表结构是新库的必要内容，可附带记录。重复请求依据数据库的排他创建结果停止。失败后已写入的对象保留，模块不删除目标库。
