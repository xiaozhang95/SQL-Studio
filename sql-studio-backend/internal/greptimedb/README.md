# GreptimeDB 引擎

`NewClient()` 通过 MySQL 线协议测试连接、管理本客户端会话、读取库表、列、索引与 DDL，以及执行 SQL。缺省连接库为 `public`，显式请求的数据库优先。对象范围只有数据库和表两层。连接可使用 GreptimeDB 已配置的用户名与密码，也可连接未启用鉴权的实例。

底层复用 MySQL 连接生命周期、取消和有界结果读取。每个 API 请求独立打开连接。执行前核对单语句边界，默认只接受读语句及 USE。查询直接发送给 GreptimeDB，写入由调用方显式启用。工作台多语句按顺序单独请求，取消不会回滚已完成的写入。

表字段保留 `TIME INDEX`，视图使用 `SHOW CREATE VIEW`。支持 `TQL` 行结果。流式 SQL 转储与匹配行计数尚未接入。
