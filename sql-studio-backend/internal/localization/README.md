# 应用消息语言

`Language` 支持 Chinese（zh-CN）和 English（en-US）。`ParseAcceptLanguage(header)` 按 Accept-Language 的权重和顺序选择受支持语言；缺失或无法匹配时使用简体中文，不保存全局当前语言。

`Text(language, message)` 翻译完整的已知应用消息；英文案集中在私有 messages 词典。动态错误按原始格式模板匹配，保留路径、对象名、数字和数据库原始原因，仅对 `%w` 包装的应用原因继续翻译。模板优先匹配固定部分较长的消息，不做任意子串替换，未知文本原样返回。词典和模板只在包初始化时建立，随后并发只读。

本包只依赖标准库，由 HTTP 层在编码响应时调用，不影响错误身份、状态码、持久化内容或业务模块依赖。SQL、行列值、用户命名和模型回答不进入此翻译入口。
