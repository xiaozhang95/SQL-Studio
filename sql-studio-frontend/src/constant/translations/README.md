# 中英文案

`englishMessages` 以中文界面文案为键，提供英文翻译。动态内容使用命名占位符，原始 SQL、数据库对象名称、模型输出及用户输入保留原内容。

包含导出阶段日志、文件选择器和保存位置后缀、转储错误及请求备用提示。动态错误通过完整模板匹配，英文文案仅转换应用提示，不翻译插入的表名、路径或数据库值。

连接表单英文标签使用 Name、Group、Database，避免长词组在固定标签列内被截断；维护库帮助说明使用简短英文。

分组弹框标签使用 Name，占位与必填提示为 Enter a name；内置默认分组显示 Default group，自定义分组名称由调用方原样展示。

数据库名称标签使用 Name，输入提示使用 Enter a name，避免英文标签折行。
