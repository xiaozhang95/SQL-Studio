# 中英文案

`englishMessages` 以中文界面文案为键，提供英文翻译。动态内容使用命名占位符，原始 SQL、数据库对象名称、模型输出及用户输入保留原内容。

桌面更新根据固定错误码分别提示限流、拒绝访问、无公开正式版、超时、网络、服务器、响应格式和清单不匹配。下载进度使用准备下载、正在下载、正在校验及进度环的无障碍名称。

包含导出阶段日志、文件选择器和保存位置后缀、转储错误及请求备用提示，以及对象树的连接、数据库、Schema、表、视图、字段、索引和外键空分支提示。查询工具栏使用“优化”“导入”“导出”，英文为 Optimize、Import、Export；预览弹窗使用“优化建议”及 Optimization suggestions。动态错误通过完整模板匹配，英文文案仅转换应用提示，不翻译插入的表名、路径或数据库值。

连接表单英文标签使用 Name、Group、Database，避免长词组在固定标签列内被截断；维护库帮助说明使用简短英文。

Electron 退出确认使用“是否保存对「标签名」的更改？”和“取消 / 不保存 / 保存”；每个弹框只处理对应标签，空白查询不提示保存。仅在该页存在未提交修改或运行任务时展示相应的简短提示。

分组弹框标签使用 Name，占位与必填提示为 Enter a name；内置默认分组显示 Default group，自定义分组名称由调用方原样展示。

数据库名称标签使用 Name，输入提示使用 Enter a name，避免英文标签折行。
