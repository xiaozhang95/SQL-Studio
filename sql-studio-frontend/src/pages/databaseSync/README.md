# 同步数据库

`/sync` 可从全局 Rail 或连接右键菜单进入，接收保存的 `connections`、可选 `initialConnection`、`onCreated(connectionId)` 和共享页面布局参数。连接右键预选该连接为源、采用其数据库类型并读取源库列表。无有效连接的直达链接打开空白表单。

上下文 Header 显示「同步数据库」标题、源→目标面包屑和状态胶囊（未开始/正在检查/正在同步/同步完成/停止/取消）。画布内容最大宽 1120px，使用 18 × 22px 内边距。步骤卡把配置/检查/执行三步与数据库类型选择放在同一行；配置以源端、目标端和同步选项卡片呈现，宽屏并排显示源端和目标端，窄屏纵向排列。源和目标可独立选择同类型的已保存连接或填写外部连接。源库可读取列表，外部源也可手填。通过检查后才能执行：无检查结果时「同步检查」为唯一主按钮；检查通过后保留检查提示，并将「开始同步」设为主按钮。进度卡展示处理表数、已写入记录及耗时，日志卡按时间线显示执行阶段。同步成功后显示“完成”，点击直接返回工作区；失败或取消后仍可修改配置。同步执行期间通过 navigationLock 暂停 Rail 页面切换；浏览器离开或刷新会中止请求，已创建的目标对象可能保留。
