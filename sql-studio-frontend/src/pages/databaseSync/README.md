# 同步数据库

`/sync` 可从全局 Rail 或连接右键菜单进入，接收保存的 `connections`、可选 `initialConnection`、`onCreated(connectionId)`、`onOpenTarget(connectionId, database)` 和共享页面布局参数。连接右键预选该连接为源、采用其数据库类型并读取源库列表。无有效连接的直达链接打开空白表单。

画布内容铺满主区域宽度，内边距沿用 DatabasePage 的 Ant Design 令牌。步骤卡把配置/检查/执行三步与 220px 数据库类型选择放在同一行；配置以源端、目标端和同步选项卡片呈现，宽屏为“源卡 / 原生圆形交换按钮 / 目标卡”，窄屏纵向排列并旋转交换图标。源和目标可独立选择同类型的已保存连接或通过卡片底部链接填写外部连接。源库可读取列表，外部源也可手填；每张卡提供字段说明，同步选项使用「同时复制表数据」和跳过视图计数。交换两端后清除旧源端库列表，新源端按自身连接读取。两侧的选择状态不代表已通过连接校验。新建目标库的引擎勾选「目标库不存在时新建」后可发起检查，Oracle 使用已有的空 Schema。通过检查后才能执行：无检查结果时「取消 / 同步检查」；检查通过后显示原生成功提示和「同步检查 / 开始同步」。进度视图先展示完成/失败主卡、4 项统计，再并排显示带时间的同步日志和含连接类型、库名、内容、跳过视图及表标签的同步摘要；底部保留返回配置、返回工作区和打开目标连接。同步执行期间通过 navigationLock 暂停 Rail 页面切换；浏览器离开或刷新会中止请求，已创建的目标对象可能保留。

源端和目标端共用 88–132px 的横向标签列。两张卡片的标题允许引擎图标的阴影延伸到标题周围。长标签随可用宽度换行，数据库字段的帮助说明与输入列对齐。标签、占位提示和说明随界面语言切换。

Oracle 使用存量空 Schema 作为同步目标。连接填写服务名，源端和目标端选择 Schema。成功后打开目标连接的 Oracle 服务，Schema 由目标账号确定。目标 Schema 含有对象时检查失败。

步骤卡用实色标记当前步骤、淡绿底勾标记已完成步骤。同步成功后三步统一显示已完成状态。配置阶段的说明使用无可见描边的 Ant Design 信息提示，底色跟随全局 Alert 主题并使用原生信息图标。检查通过时，标题和说明使用随亮暗主题调整的高对比度成功色。进度页的 [同步日志](components/syncResult/README.md) 在卡片内独立滚动。
