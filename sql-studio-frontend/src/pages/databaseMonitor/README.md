# 监控指标

`/monitor` 可从工作区顶栏或连接右键菜单进入。页面接收已保存的 `connections`、可选 `initialConnection`、`initialDatabase` 及共享页面布局参数。连接右键直接带入所选连接，顶栏优先使用对象树或当前页签的范围；无有效范围时选择首个连接。

MySQL、MariaDB 和 Redis 显示实例统计，PostgreSQL 和 GreptimeDB 可切换数据库。连接和数据库使用无可见标签的下拉框。全部数据库统一为概览、活动状态（四组趋势与统计卡）、状态信息。指标使用 Ant Design 默认外观与主题，统计卡窄屏两列、宽屏四列。页面显示采样时间。进入页面立即采样，自动刷新默认每 5 秒一次；每次采样完成后开始计时，可手动关闭或改为 5 秒、15 秒、30 秒、1 分钟、5 分钟，手动刷新仍可用。速率类指标从第二次成功采样开始计算，无需先点击刷新。计数保留大整数精度，容量和流量按二进制单位展示。连接与采样由 [useDatabaseMonitor](hooks/useDatabaseMonitor/README.md) 管理。

Redis 经引擎入口组合[专属实例监控](../../databases/redis/monitor/README.md)：概览显示版本、模式、角色、运行时间、客户端、键总数和内存；活动状态提供命令/秒、客户端、内存/RSS、网络吞吐四组实际采样趋势及十二项统计卡。状态信息包含各逻辑库键空间、持久化、复制、内存、客户端、服务器和 CPU 累计耗时。缺失指标显示未知，空逻辑库与缺失统计分开提示。趋势仅保留当前范围最近 120 次成功采样，切换连接/数据库、离开页面或 Redis runId 改变时重新开始，不读取历史数据库或扫描键。

MySQL/MariaDB 显示语句、连接/线程、网络及 InnoDB 读写趋势；PostgreSQL/PolarDB 显示事务、会话、数据块访问及行变更，保留数据库范围和权限可见性；GreptimeDB 显示表/主分片、估算行数、存储及 SST 趋势。引擎经统一入口提供只读定义，页面只组合。累计计数先以 BigInt 做差，再按相邻采样真实秒数计算速率；首次、缺失、回退及重置保留断点，不补零。可选配置或扩展视图读取失败保留基础指标，并展示采样告警。
