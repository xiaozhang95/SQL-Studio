# 监控指标

`/monitor` 可从全局 Rail 或连接右键菜单进入。页面接收已保存的 `connections`、可选 `initialConnection`、`initialDatabase` 及共享页面布局参数。连接右键直接带入所选连接，App 优先使用对象树或当前页签的范围，无有效范围时选择首个连接。画布内容铺满主区域宽度，内边距沿用 DatabasePage 的 Ant Design 令牌。过滤条在同一张面板内展示 236px 连接、190px 数据库、采样时间、132px 自动刷新和刷新按钮。采样失败时，页面顶部展示失败原因，过滤条内展示失败状态及当前是否显示上次数据，悬停或聚焦可查看详情。成功采样后清除失败状态。

MySQL、MariaDB 和 Redis 显示实例统计，PostgreSQL 和 GreptimeDB 可切换数据库。连接和数据库使用无可见标签的下拉框。全部数据库统一为概览、活动状态（四组趋势与统计卡）、状态信息。指标使用主题外观，概览卡显示版本/角色并按引擎字段展示运行时间等指标，统计卡窄屏两列、宽屏四列。页面显示采样时间。连接就绪立即采样并显示可用统计，约 1 秒后自动补第二份采样，速率和趋势按实际间隔计算，无需手动刷新；之后默认每 5 秒刷新。每次采样完成后开始计时，可关闭或改为 5 秒、15 秒、30 秒、1 分钟、5 分钟；关闭自动刷新同时取消待执行的基线补采，手动刷新仍可用。连接列表稍后加载或同一连接对象重新创建不会阻断首次采样，旧范围结果不会混入新范围。计数保留大整数精度，容量和流量按二进制单位展示。连接与采样由 [useDatabaseMonitor](hooks/useDatabaseMonitor/README.md) 管理。

Redis 经引擎入口组合[专属实例监控](../../databases/redis/monitor/README.md)：概览显示版本、模式、角色、运行时间、客户端、键总数和内存；活动状态提供命令/秒、客户端、内存/RSS、网络吞吐四组实际采样趋势及十二项统计卡。状态信息包含各逻辑库键空间、持久化、复制、内存、客户端、服务器和 CPU 累计耗时。缺失指标显示未知，空逻辑库与缺失统计分开提示。趋势仅保留当前范围最近 120 次成功采样，切换连接/数据库、离开页面或 Redis runId 改变时重新开始，不读取历史数据库或扫描键。

MySQL/MariaDB 显示语句、连接/线程、网络及 InnoDB 读写趋势；PostgreSQL/PolarDB 显示事务、会话、数据块访问及行变更，保留数据库范围和权限可见性；GreptimeDB 显示表/主分片、估算行数、存储及 SST 趋势。引擎经统一入口提供只读定义，页面只组合。累计计数先以 BigInt 做差，再按相邻采样真实秒数计算速率；首次、缺失、回退及重置保留断点，不补零。可选配置或扩展视图读取失败保留基础指标，并展示采样告警。
