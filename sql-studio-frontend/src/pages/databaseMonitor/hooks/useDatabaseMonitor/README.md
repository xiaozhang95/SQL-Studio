# 数据库监控采样

`useDatabaseMonitor(connections, initialConnection, initialDatabase)` 优先使用所选或传入连接，未指定或原连接已不存在时使用有效首项；连接列表异步到达也会自动选择并采样。PostgreSQL 和 GreptimeDB 空库值使用连接默认库。返回当前连接、库列表、采样结果与错误，以及 `selectConnection`、`selectDatabase`、`refresh`。

打开页面时立即采样，先显示本次可用统计；只有一个成功采样时，约 1 秒后自动补齐第二份，以真实间隔计算速率与趋势。refreshInterval 默认 5 秒，每次进入重新使用该默认值；补齐基线后按所选间隔采样。请求完成直接安排下一次，不依赖 result/loading 的 React effect 再触发，也不因同一连接对象引用变化而取消首个请求；同一时刻最多一个采样请求。失败后按所选间隔重试，保留同范围上一份统计、时间和历史，不插入失败点。

手动刷新取消旧请求和计时并立即读取，保留同范围有效历史；修改间隔仅调整后续计时，不取消在途读取。选择 0 会清除普通刷新及基线补采定时器，在途请求可完成，手动刷新仍可用。更换连接/数据库或离开页面取消旧请求及定时器，迟到响应不能覆盖新范围。结果与历史绑定连接、引擎和有效库范围。result.history 最多保留最近 120 次成功采样，同一时间戳替换；更换范围、Redis runId、SQL 引擎 details.identity 改变或运行时间回退时从新序列开始。离开页面卸载后不保留，历史不写入工作区配置。
