# 工作区业务编排

[源码](index.tsx)

useWorkspace 返回 WorkspaceModel，区域组件通过 Pick 限定消费字段。主区域只有一层 query/data/structure/ddl 页面标签。SQL 页共用编辑器和最新一批结果，对象操作打开独立结果页；关闭最后一页保留空状态，不自动新建。

`operationError` 提供导出、刷新和关闭等操作的失败原因，`clearOperationError()` 清理该错误。工作区将它与配置、连接列表错误交给 PageHeader 合并展示。

## 范围、补全与请求

每页独立保存连接、库、表和 SQL。树高亮独立于右侧页面，单击/展开/双击不修改 SQL 范围；对象操作携带完整 connectionId/db/table。openConnection 只管理元数据，折叠不关闭；关闭取消该连接共享请求和缓存，清空相关 SQL 页范围但保留草稿与已有结果。删除/编辑不修改其他连接的范围。

顶部新建查询使用左侧已打开且当前可见的选中连接或库及子节点范围；只选连接时数据库留空，schema 节点和表节点保留所属 schema，不预选表。没有有效目标则连接、库、表均为空，不继承当前查询；右键新建继续使用右键目标，导入 SQL 继续显式沿用当前查询范围。

对象树双击展开时按连接、库、schema、表和类型复用已有结构或数据页，切换并刷新；没有匹配页则创建。表格存在未保存修改时先确认，取消不刷新或切换。

表操作的页面范围显式使用 QueryScope（连接、数据库、schema、表）；view 仅传给对象管理操作以区分表和视图，不进入页面、执行范围或工作区保存索引。

新增连接只追加到列表，不切换查询范围、不自动连接或展开分组；编辑仅重置被编辑连接的范围和分支。分组仅整理树结构，所有元数据和查询请求仍以原始连接 ID 隔离。

连接及独立分组列表同时加载，connectionGroups 提供唯一分组选项，含空分组。分组新建、重命名及连接表单自由输入保存后同步列表；移动只替换该连接的脱敏元数据，重命名只更新同组成员及 group 展开/选中 key，不走连接编辑重置路径。分组弹窗和保存期间参与工作区操作锁。

选连接后提供当前连接的数据库补全；选库自动 loadTables 并共用对象缓存，补全表/视图及已加载字段，defaultSchema/defaultTable 与当前页一致。异步数据按连接隔离，范围变化只切换消费方；关闭/刷新取消旧代请求，迟到结果不能重新打开连接。数据库成功加载时只校验保存范围是否仍有效，不自动执行 SQL。

完整草稿或选区由目标数据库适配器 splitStatements 完整扫描，再顺序调用现有单语句接口；表数据语句同样通过适配器 tableDataSQL 生成，工作区不维护具体引号规则。整批固定页 ID、连接、初始库、运行锁与 AbortController；每条即时更新结果，SQL 查询页逐条保存历史，表数据预览不写历史。失败或取消停止后续发送，保留已完成结果并提示未执行数量；请求不传 limit；MySQL/PostgreSQL 查询窗口均显式传 allowWrite=true，不声称此前执行被回滚。

RunState.statements 保存该批逐条输出，resultViews.resultIndex 保存当前结果；selectResult 重置筛选/分页。顶部 Tab 与结果标签 根据该页选中语句的状态着色，切页后保持。运行中可切已有页面，禁止关闭和新增；关闭同步释放该页结果、视图和编辑器布局。

validateDatabases 仅在有效库列表加载成功后校验查询页范围，并通过 explorerAfterDatabasesLoaded 清理目标连接下已消失库及后代的展开/选中记录。首次打开、恢复、刷新连接和对象操作重读列表共用该回调；请求失败或加载中不清理。其他库、连接与布局保留，同名库重建保持收起。

## 本地恢复

useWorkspacePersistence 通过 Go 服务在配置目录保存轻量标签/范围/布局索引，SQL 草稿和结果各自独立保存。启动只读取活动页，其他页按需读取，已保存的非活动内容可释放。只传页面白名单字段，不保存连接密码或表单凭据。顶部展示保存/错误状态。

sidebarWidth/setSidebarWidth 消费App下useSidebarWidth共享状态，连接栏与Agent历史栏同步；宽度继续纳入现有轻量布局索引。恢复通过restoreWidth保留已有宽度；旧快照缺少该字段或不是有效数字时使用272px。Agent打开时工作台保持挂载，调整会触发同一布局保存；展示宽度由useSidebarResize根据窗口边界约束，隐藏/窄屏测量不改写偏好。

进入先恢复索引，再加载活动页后允许编辑；没有当前索引时创建空工作区，不读取其他草稿格式。恢复时仅重连之前打开的连接、加载必要的库表元数据，SQL 与结果直接取本地记录，不自动查询数据。刷新打断的执行标记 interrupted，完成结果保留并提示手动重跑。元数据加载仍使用连接缓存及取消边界。

## 历史与编辑

useQueryHistory 通过 Go 服务保存各连接最新 50 条记录，恢复旧记录时也执行上限。连接删除成功清理其历史，列表成功加载后清理已删除连接的遗留历史；列表失败不清理。入口仅位于 SQL 页，打开时重置搜索，QueryHistory 以连接 ID 重挂载。loadHistory 清理记录里旧的来源标记后，追加到当前编辑器末尾并标注一行 -- 历史记录，不新增页、不切库、不执行；CodeMirror 事务保留撤销。来源标记不进入历史 SQL，重复执行仍保留各次执行信息。

右键打开时捕获选区快照，runSelectedSQL 不回退到整页；工具栏和 Ctrl+Enter 优先执行选区，无选区则完整草稿。导入本地 SQL 新建查询而不执行，exportCurrentSQL 原样导出完整草稿。onEditorReady/onEditorUpdate/rememberEditor 负责恢复并保存编辑位置。

Ctrl/Command+Enter 由 useQueryShortcut 在 window 捕获阶段处理，仅限可见工作台、就绪的查询编辑器内部且无模态框；其他控件、AI 助手、历史搜索、连接表单不触发。先于 CodeMirror 插入空行读取原选区，不修改 SQL 草稿。浏览器回归需同时验证两种引擎的单条选区、多条选区、无选区和运行中重复按键，避免意外执行整份脚本。

executeSQL 在单语句执行开始记录批次 startedAt，按完成语句更新 durationMs，最后一条或失败记录 endedAt；失败语句也保留请求耗时供消息/摘要展示。不新增后端请求，不改变失败/取消停止及结果归属边界。

objectManagement 编排库表表单和写入；objectBusy 与普通查询共用界面锁，SQL 窗口执行显式传 allowWrite=true，表数据预览不传。对象操作后仅刷新目标连接的库列表或目标库已加载的表列表，创建库/表不自动展开，删库/表只清理关联查询范围，重命名更新查询页表范围，保留 SQL 草稿及原输出快照，不自动执行结果页查询。表刷新重新加载所属连接/库元数据，不创建新查询或执行 SELECT。

对象表单打开期间也占用界面运行锁，Ctrl+Enter 不会执行背景 SQL；表单取消后恢复原查询范围与结果。

恢复工作区时仅加载已打开连接、已展开库和已展开表的详情，复用去重缓存；虚拟树等待这些分支完成后恢复目录位置，不自动执行 SQL。

已打开连接列表仅保存元数据成功加载后的 connected 状态，不将 loading/error 节点作为下次启动的恢复目标。恢复失败保留本次错误供查看、手动重试或关闭；自动保存后下次启动不重复重连失败目标，不清除其 SQL 草稿及已有结果。

恢复树展开记录时仅还原已打开连接及其后代，分组展开保留，防止未打开连接因 Tree 的默认展开加载再次发起连接。

新建表、设计表创建 table-create/table-design 主标签，不再打开对象弹窗。同一连接/库/表的设计入口复用已有设计页，新建草稿独立编号。designerBusy/Dirty 按页面 ID 保存状态；只在加载/保存时锁定操作，停留在表单本身不锁定其他页面。关闭当前、其他、右侧均检查即将移除的未保存设计草稿。保存后 tableDesignerCommitted 将新建页转为该表设计页并保持当前标签选择；页面切换和恢复不自动执行 DDL。

replaceTableResult(id,result) 只更新对应 data 页及其首条输出；单元格请求复用按页 busy 锁，不修改其他页或查询的默认只读状态。

refreshResult 固定已执行查询 scope 和当前选中 SQL，不使用后来改变的选择器或草稿；刷新替换原页。旧 SQL 结果缺少 scope 时需重新运行后才能刷新。元数据页刷新复用原页。

关闭数据库/连接会选出该范围所有查询、数据和设计页面，并提示保存 SQL、不保存或取消；多个查询合并为一个 .sql。SQL 保存取消/失败保留窗口；表结构或数据未提交时另有明确放弃说明。确认后取消该范围在途查询，等待后端真实关闭，成功才移除关联页面、结果和编辑状态并收起树；失败保留窗口和 SQL。其他库/连接不受影响。查询运行中仍可右键关闭，其他写入/对象操作占用时禁止关闭。

关闭确认弹窗宽 560px，底栏按钮整体靠右并保持统一间距，顺序为取消、不保存、保存并关闭；无查询 SQL 时右侧为放弃并关闭。仅简化文案与布局，保存和实际关闭流程保持原行为。

成功的 USE 通过引擎 useDatabase 识别，更新发起查询页数据库并清空表范围，后续语句显式传入新库；失败或取消不切换范围。每条语句保存请求数据库及对应历史，刷新当前结果使用该条记录，多个 USE 依次生效，不修改其他页面或连接。此行为只传递默认库，不模拟事务、临时表或其他会话状态。

创建/设计等可视化对象入口除菜单外还检查目标引擎 objects 能力。历史记录携带 databaseType，成功 USE 仍只由目标引擎识别，PostgreSQL 不继承 MySQL USE。

schemaConnections 由连接及引擎 explorer 能力 memo 化提供给对象缓存，不依赖当前查询选择器。

数据库结构结果由所属适配器 tableListResult 生成，PostgreSQL 分开 Schema/表名；schema 结构页按 schema 筛选并在标题中保留范围。查询传递 schema、逐条历史和结果刷新记录它；切库/连接清空，真实 schema 列表确认失效后才清空。只展示当前对象页和结构结果，恢复不转换旧格式或重跑 SQL。

MySQL、MariaDB 和 PostgreSQL 的 SQL 窗口的手动运行与结果刷新均显式传 allowWrite=true，支持 DDL/DML，不增加只读开关或额外确认；对象数据预览保持读取请求。每条 SQL 独立自动提交，批次失败停止后续语句；累计结果只在整批完成、失败或取消后持久化；不支持跨请求事务或会话状态，取消不保证回滚。

dataExport 独立管理导出请求和文件；数据库/Schema/表菜单显式传入目标连接与范围。关闭相同库/连接会取消该导出，关闭其他范围不影响它。查询编辑器不因 objectBusy/running 改变而重挂载；页面关闭按钮恒定占位。

导出前按目标连接的 connected 状态和 closedDatabases 复核；未连接或数据库已关闭时不启动导出，不以当前查询页范围替代目标范围。

工作区使用分片持久化：非活动且已保存的页面仅保留标签/范围/布局；pageReady/pageLoadError/retryPage 控制当前内容等待与恢复。hydrate 按预期SQL和结果身份合并，不覆盖读取期间的新执行或已关闭页面；evict 只删除匹配已提交版本的非活动内容，保留活动/运行窗口。closeScope 在提示保存前按需读取范围内草稿，不读其他结果，防止把卸载后的占位空字符串当作丢失草稿。加载与恢复均不自动执行SQL。

编辑会话由useWorkspaceEditor持有，草稿与位置250ms批量同步；runSQL/exportCurrentSQL/getCurrentSQL在操作时读取最新编辑内容，选区/右键仍使用当前选区快照。切页和范围关闭先同步，关闭页取消缓冲；关闭其他页使用函数式更新，保留活动页刚输入的SQL。pendingDrafts只保护React提交前的短暂草稿，避免持久化回包在快速切页间隙卸载新内容。QueryEditor仅按页面重挂载，范围变化重配补全且不清空当前文本。

getEditorHistory(id) 提供会话内该页撤销/重做的初始化扩展；切页前保存，关闭页释放，不向磁盘工作区添加编辑历史或额外全文快照。

删除分组成功后仅将该组连接归入默认分组并清理旧分组自身的展开/选中 key；连接 ID、子节点展开、对象缓存、查询页面及已有结果保留，不自动展开目标分组。

失效schema及对象标题迁移改由reconcileWorkspacePages在提交前统一校正当前组件状态；未知元数据和对象操作期保留范围，无变化返回原引用，校正稳定后不重复更新，不再通过Effect级联setTabs。

连接列表、批次执行、快捷键分别归属 useWorkspaceConnections/useQueryExecution/useQueryShortcut，组合根负责页面范围和跨模块协调。queryRunning 与 uiBlocked 区分执行及界面占用，树显示禁用状态和原因。执行中切页后顶栏保留取消入口。保存失败不推进旧 revision；加载或保存失败仅保留错误状态，不提供恢复弹窗。

查询页 tabs/runs/resultViews/editorLayouts、运行请求及取消边界集中到 useQuerySession；useWorkspace 继续负责范围关闭、对象操作与上述模块的组合协调，不再直接拥有这些底层状态。
