# Electron 退出确认

useDesktopExit(options) 仅在存在桌面 onBeforeQuit 桥接时注册异步退出处理，并在卸载时移除。普通 Web 不注册关闭/刷新拦截。Options 提供工作区及当前页就绪/读取失败状态、最新快照、全部连接、未提交修改标记、编辑同步、按页草稿读取、标签激活、准备/关闭阶段切换、严格保存、请求取消、连接释放和内存快照应用接口。

收到原生关闭请求后先同步编辑缓冲，回到工作区并从当前标签开始逐页处理。每次激活对应页，最多等待 10 秒读取内容；失败停止本次退出。非空查询使用 Ant Design 默认宽度与位置的确认框，不设置 centered 或位置偏移；标题“确认”、问号图标，正文“是否保存对「标签名」的更改？”，按钮从左到右为“取消 / 不保存 / 保存”。「保存」与 SQL 工具栏的「运行」同为 `primary` 按钮，聚焦时沿用按钮自身样式。空白查询跳过保存确认，直接关闭；有未提交修改或运行任务的页面单独确认，仅补充该页的简短提示。

保存按当前标签的原文和名称独立写文件；每页保存或放弃完成后，严格提交关闭快照并移除对应内存标签、结果和编辑状态，切到下一项后才继续询问。准备阶段暂停自动保存并锁定工作区交互，保留标签可见。取消、文件选择取消或失败时保留当前及剩余标签，之前已关闭的标签保持关闭；全部标签处理完才由 App 挂起页面，停止订阅及请求并统一关闭全部连接。保存冲突或连接释放失败返回 false 并恢复窗口及自动保存，已完成的关闭不回滚。

所有异步回调读取最新 Options；重复退出共享同一任务。没有执行 SQL 的副作用，不删除连接配置或业务数据。未保存为文件的 SQL 在退出关闭标签后不再恢复。编排和取消边界见 [desktopExit](../../utils/desktopExit/README.md)。
