# Electron 退出确认

useDesktopExit(options) 仅在存在桌面 onBeforeQuit 桥接时注册异步退出处理，并在卸载时移除。普通 Web 不注册关闭/刷新拦截。Options 提供工作区就绪/占用状态、最新快照、全部连接、未提交表设计与数据标记、编辑同步、草稿读取、严格保存、请求取消、实际连接关闭和内存工作区清空接口。

收到原生关闭请求后先同步编辑缓冲，读取未常驻的查询草稿；存在任意 SQL 查询标签时展示取消/不保存并退出/保存 SQL 并退出确认，空 SQL 标签也提示保存；未提交表修改或运行任务另有说明。取消及保存文件取消保留全部标签和连接。确认后由 App 挂起页面并暂停自动保存，停止监控、Agent、Redis 订阅和其他页面请求，等待 SQL 请求完成取消，依次保存退出前快照、关闭连接、提交空工作区并清空全部内存标签。成功退出后不恢复这些标签和 SQL。保存失败、冲突或连接释放失败均返回 false，保留内存标签并恢复自动保存；部分已关闭连接不自动回滚。

所有异步回调读取最新 Options；重复退出共享同一任务。没有执行 SQL 的副作用，不删除连接配置或业务数据。未保存为文件的 SQL 在退出关闭标签后不再恢复，界面明确说明这一点。编排和取消边界见 [desktopExit](../../utils/desktopExit/README.md)。
