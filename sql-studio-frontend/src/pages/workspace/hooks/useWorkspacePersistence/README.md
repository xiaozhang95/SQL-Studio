# 按需工作区恢复与保存

useWorkspacePersistence(snapshot,restore,{busy,hydrate,evict}) 读取v2轻量索引，恢复标签、范围、布局，然后仅加载活动页草稿和结果。返回 ready/pageReady/pageLoadFailed/retryPage/draftsFor/saving。活动页未加载时显示等待或重试，编辑器和执行快捷键受保护；切换页面取消旧读取，异步回调核对预期SQL/结果和已关闭标记。

保存500ms防抖、持续变化最多等待3秒入队，单在途及最新等待。服务按页面基线只发送变化部分，保留未加载页引用；成功落盘后仅释放非活动、非运行、与已保存版本一致的内容，未保存/失败状态保留在内存。索引及基线不保存全部页面全文。遇到 409 丢弃排队的旧快照，等当前操作结束后读取最新索引并重新加载活动页。初始化或冲突后读取失败时暂时停止写入，窗口重新聚焦后再次读取。故障页可重试，其他页仍可切换。

draftsFor(pages) 用于关闭数据库/连接前只加载相关草稿，最多4个并发，确保保存确认包含尚未打开标签的SQL。只读草稿不加入常驻缓存。关闭标签移除索引引用，后端延迟清理孤立内容；不会操作业务表。后端读取当前索引和分片，浏览器只按需请求页面内容。恢复不自动执行SQL；中断状态按页保留。

强制退出可能丢失未提交或在途内容；调度时间不是磁盘持久化保证。每份草稿/结果最多32MiB，超限明确失败且不释放未保存内容。大量标签的总结果不再受单个32MiB工作区文件限制。

工作区只读写当前 v2 索引与内容分片，首次缺失初始化当前空索引，不提供旧快照转换。

正在执行页面的累计结果暂留内存，索引继续记录 runningTabId；完成/失败/取消后保存最终结果，避免逐条上传全批结果。浏览器崩溃可能丢失本批尚未持久化输出，已执行的数据库操作不会因此回滚。过期运行标记由 WorkspaceStore.open/hydrate 统一处理，首次自动保存会持久化其清除。

draftsFor(pages,signal?) 读取指定页面的草稿，供关闭范围时检查未保存内容。信号传到草稿请求，取消时拒绝返回部分结果。
