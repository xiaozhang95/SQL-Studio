# 工作区恢复与保存

useWorkspacePersistence(snapshot,restore) 返回 ready/saving/error。读取 Go workspace 分区，缺失时使用默认空工作区；校验后恢复，首次空界面不覆盖已保存配置。读取失败、损坏或未知版本时保留原数据并阻止本会话覆盖。恢复仅重新加载必要元数据，不执行 SQL，不迁移浏览器旧记录。

保存 500ms 防抖，持续变化最多等待 3 秒提交一次，Go 为唯一目标，失败不回落浏览器；修订冲突提示刷新。配置包含页签/SQL/结果/视图/编辑位置/树状态及布局，不含连接密码。强制关闭可能丢失尚未提交的变更。表设计标签描述可恢复，未保存表单草稿不持久化。

旧页面缺省 schema 兼容；存在时必须是 string。保留每页/运行快照 schema，不自动执行或重跑 SQL。

通过 latestWriter 合并保存期间的中间快照，只保留一个最新等待值；序列化推迟到真正开始发送。未变化页面/结果复用弱引用 JSON 缓存，重复的最后一条结果在文件只存一次、恢复时还原共享引用。仍保存完整工作区，不截断 SQL/结果；最终 JSON 传输、后端全量原子落盘及启动全量恢复仍存在，尚未改成按页懒加载存储。强制结束进程可能丢失防抖/在途内容，最多等待不代表磁盘提交时限。
