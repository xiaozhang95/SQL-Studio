# 工作区恢复与保存

useWorkspacePersistence(snapshot,restore) 返回 ready/saving/error。读取 Go workspace 分区，缺失时使用默认空工作区；校验后恢复，首次空界面不覆盖已保存配置。读取失败、损坏或未知版本时保留原数据并阻止本会话覆盖。恢复仅重新加载必要元数据，不执行 SQL，不迁移浏览器旧记录。

保存 300ms 防抖，Go 为唯一目标，失败不回落浏览器；修订冲突提示刷新。配置包含页签/SQL/结果/视图/编辑位置/树状态及布局，不含连接密码。强制关闭可能丢失尚未提交的变更。表设计标签描述可恢复，未保存表单草稿不持久化。

旧页面缺省 schema 兼容；存在时必须是 string。保留每页/运行快照 schema，不自动执行或重跑 SQL。
