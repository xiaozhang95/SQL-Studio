# 按需工作区恢复与保存

useWorkspacePersistence(snapshot,restore,{hydrate,evict}) 读取v2轻量索引，恢复标签、范围、布局，然后仅加载活动页草稿和结果。返回 ready/pageReady/loadError/retryPage/draftsFor/saving/error。活动页未加载时显示等待或重试，编辑器和执行快捷键受保护；切换页面取消旧读取，异步回调核对预期SQL/结果和已关闭标记。

保存500ms防抖、持续变化最多等待3秒入队，单在途及最新等待。服务按页面基线只发送变化部分，保留未加载页引用；成功落盘后仅释放非活动、非运行、与已保存版本一致的内容，未保存/失败状态保留在内存。索引及基线不保存全部页面全文。读取失败保留原文件并阻止覆盖；结果损坏可切换其他页，故障页需重试，不能用占位空SQL覆盖。

draftsFor(pages) 用于关闭数据库/连接前只加载相关草稿，最多4个并发，确保保存确认包含尚未打开标签的SQL。只读草稿不加入常驻缓存。关闭标签移除索引引用，后端延迟清理孤立内容；不会操作业务表。旧版整份工作区由后端首次迁移，原JSON保留，浏览器不接收其全部结果。恢复不自动执行SQL；中断状态按页保留。

强制退出可能丢失未提交或在途内容；调度时间不是磁盘持久化保证。每份草稿/结果最多32MiB，超限明确失败且不释放未保存内容。大量标签的总结果不再受单个32MiB工作区文件限制。

已迁移后旧格式 workspace 分区写入返回409，要求旧客户端刷新；不允许旧格式覆盖或与新索引分叉。回收最多每5秒检查一次，128MiB为孤立内容回收目标（不包括当前引用），不是所有用户结果的总容量限制。
