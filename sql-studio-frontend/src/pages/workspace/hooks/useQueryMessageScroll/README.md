# 执行消息自动滚动

`useQueryMessageScroll({ progress, running })` 返回内容节点 ref，其直接父元素是传给 Virtuoso 的滚动视口。`progress` 包含已完成语句和批次错误，`running` 决定挂载时是否跟随底部。已完成批次初次打开从顶部阅读。

已完成消息增加、执行结束及内容或视口尺寸变化时，跟随状态下定位到底部。ResizeObserver 覆盖实际行高测量、折叠动画和 SQL 预览的延迟高度变化。滚轮、滚动条或键盘向上阅读时暂停，回到底部时恢复。父组件在新批次重挂载以重置状态。

滚动操作限定在当前消息视口。卸载时断开尺寸观察并移除事件监听。底部判断允许 2px 误差以兼容浏览器小数滚动位置。
