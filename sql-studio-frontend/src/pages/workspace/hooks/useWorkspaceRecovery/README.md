# 保存失败恢复入口

useWorkspaceRecovery({capture,histories,blocked}) 返回打开恢复对话框的方法。capture 在用户导出时读取最新编辑器草稿及按需加载所有页面草稿；histories 为当前内存历史。SQL 执行、对象保存或弹窗占用时不启动恢复。用户可导出 JSON 恢复副本、继续编辑，或明确放弃未保存内容并重新载入。导出取消、失败和浏览器下载均不自动刷新，也不推进旧修订或覆盖另一窗口。恢复副本暂供人工提取，不承诺自动导入。

恢复弹窗默认焦点为“继续编辑”。导出期间拦截重复点击并禁用重新载入；关闭弹窗取消尚未完成的草稿读取，不在关闭后更新对话框或再打开保存选择器。原生保存取消显示中文说明并保留页面内容。存在未保存的表格/设计修改时先要求处理该修改。
