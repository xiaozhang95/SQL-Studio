# Electron 退出编排

runDesktopExit(options: DesktopExitOptions) 返回 Promise<boolean>。先同步编辑缓冲并进入 preparing 状态，从当前活动标签开始，每次仅处理一个页面；关闭后选择原位置右侧相邻页，没有右侧页时处理左侧剩余页。activatePage(id) 切到对应页面并等待内容就绪，查询草稿按页读取，避免把已释放内存的内容误判为空。非空查询、isDirty(id) 返回 true 的对象页和运行中的页面调用 decide(page)，空白查询及干净对象页直接关闭。

选择保存时调用 exportSQL(sql,title)，按当前标签原文和名称独立保存文件，不汇总其他查询；不保存则直接进入本页关闭。若该页正在执行，先停止并等待请求结束。每页关闭先严格保存移除该页及其结果/编辑状态、切到下一页的快照，再由 applyWorkspace(snapshot) 同步应用到内存，之后才处理下一项。保存取消、读取或持久化失败保留当前和未处理标签；已经完成关闭的页面不恢复，连接仍保持打开。

所有页面处理完成后才进入 closing 状态并挂起页面，停止其他请求，再以最多 4 个并发关闭全部已保存连接（包括仅供监控使用的连接）。等待全部关闭回执，失败汇总实际连接名及原因并恢复窗口；连接配置不删除。全部成功后提交空已打开连接列表，对象树仅保留默认及自定义连接分组的展开记录，清理连接、数据库及其后代的展开/选中、搜索和滚动位置，再通过 applyWorkspace 应用最终空工作区并返回 true。下次正常启动不恢复已关闭的标签或连接，分组维持原展开/收起状态。

snapshot/connections 读取最新状态；persist 必须在真实保存失败或冲突时拒绝，closeConnection 必须等待后端释放资源。setPreparing 负责暂停自动保存并锁定工作区交互，保持标签可见；setClosing 负责最终挂起页面；stop/waitForIdle 负责请求取消边界。取消或失败解除 preparing/closing 并恢复自动保存，不回滚此前已关闭的标签或连接。Web 不调用此流程。
