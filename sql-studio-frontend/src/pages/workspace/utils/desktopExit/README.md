# Electron 退出编排

runDesktopExit(options: DesktopExitOptions) 返回 Promise<boolean>。先同步编辑缓冲、按需读取全部查询草稿并获取取消/不保存并退出/导出 SQL 后退出的决定。只要存在查询标签（包括空 SQL）就由界面提示保存；选择保存时也可导出空文件。取消和文件保存取消不会关闭标签或连接。

确认后进入关闭状态并暂停自动保存、停止请求、等待 SQL 执行结束，先保存退出前快照，再以最多 4 个并发关闭全部已保存连接（包括仅供监控使用的连接）。逐个等待关闭回执，失败汇总实际连接名及原因并恢复界面；连接配置不删除。全部成功后提交空标签列表、空活动页、空结果/编辑状态和空已打开连接列表，对象树只保留默认及自定义连接分组的展开记录，清理连接、数据库及其后代的展开和选中记录、搜索和滚动位置。再通过 clearWorkspace(empty) 同步清空内存中的全部类型标签，才返回 true 供原生窗口退出。下次正常启动不恢复这些标签或连接，分组维持退出前的展开或收起状态。

snapshot/connections 是读取最新状态的同步函数；persist 必须在真实保存失败或冲突时拒绝，closeConnection 必须等待后端释放资源。decide 负责保存提示及未提交表设计/数据和运行中任务的说明，setClosing 负责挂起页面并暂停/恢复自动保存，stop/waitForIdle 负责请求取消边界。最终空索引提交失败时不调用 clearWorkspace，保留内存标签并恢复自动保存；已成功关闭的连接不回滚。Web 不调用此流程。
