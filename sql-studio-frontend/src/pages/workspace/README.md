# SQL 工作区

[源码](index.tsx) · [组件](components/README.md) · [hooks](hooks/README.md) · [配置](constant/README.md)

页面入口组合顶栏、对象树、查询/结果/设计页、连接与 AI 弹窗；useWorkspace 编排状态。工作区、历史、主题由 Go 分区 JSON 保存，不含连接密码；恢复只加载必要元数据，不执行 SQL。

每个查询页独立持有连接、库、表、SQL 与最新结果。工具栏范围和对象树高亮相互独立；树操作携带显式目标，关闭连接清理相关范围并保留草稿/结果。查询、对象数据、结构、DDL、表设计使用统一页面 Tabs。新建表与设计表保留当前会话草稿，未保存表单不持久化。

多语句在发起页面顺序调用单语句 API，失败或取消停止后续语句。消息、摘要和逐条结果并列；历史按连接隔离，载入追加到当前查询。MySQL/PostgreSQL SQL 窗口均允许执行查询和写入；对象/数据保存显式写入，取消不能视为回滚。表数据支持新增及暂存单元格，顶部统一保存或放弃。

页面和组件布局使用 style/styles；app.scss 仅保留基础全局规则、必要 Ant Design 覆盖及媒体查询、hover/焦点等必须使用选择器的规则。CodeMirror 通过原生样式扩展配置。主题与圆角使用原生 token，控件尺寸约定来自 appearance。对象栏和结果面板支持拖动、键盘调整及恢复，结果分页固定在滚动区外。

顶栏操作按内容固定排列，不绑定侧栏宽度；调整下方对象栏不改变顶栏按钮位置或高度。所有只读 SQL 展示按全文自动换行展开，滚动由外层结果区、历史表格或弹窗统一负责。

AI 配置通过服务商适配器获取模型，Key 仅后端保存；续写作为建议展示，优化结果由用户决定是否载入，不自动执行。配置失败和冲突提示可关闭，关闭提示不代表保存成功。

工作区不展示 message 消息浮层（由 App 通过 Ant Design message.styles.root 统一隐藏），查询输出继续在底部结果/摘要/消息区域展示；确认弹窗及表单内错误保持原交互。
