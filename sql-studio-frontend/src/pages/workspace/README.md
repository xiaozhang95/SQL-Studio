# SQL 工作区

界面固定文案通过共享 useTranslation 跟随已保存语言切换。SQL、用户输入和数据库返回内容按原文展示。

[源码](index.tsx) · [组件](components/README.md) · [hooks](hooks/README.md) · [配置](constant/README.md)

页面入口组合对象树、查询/结果/设计页、连接与 AI 弹窗，由 useWorkspace 编排状态。页签末尾的 `+` 图标用于新建查询，对象栏固定显示。无页签时显示标题、操作提示和新建查询、新建连接按钮，均随界面语言切换。[连接弹窗](components/connectionModal/README.md)的表单标签列随界面语言和字号调整。工作区、历史、主题和界面字号由 Go 分区 JSON 保存，不含连接密码。恢复只加载必要元数据，不执行 SQL。

每个查询页独立持有连接、库、表、SQL 与最新结果。工具栏范围和对象树高亮相互独立；树操作携带显式目标，关闭连接清理相关范围并保留草稿/结果。刷新页面后，对象树恢复已打开连接的数据库、Schema、表等分支的展开状态及选中项。对象树的空分组、已加载的数据库/Schema 列表及表、视图、字段、索引、外键分类，展开后统一显示相应的“暂无…”文本子节点；加载中与加载失败保留各自状态。查询、对象数据、结构、DDL、表设计使用统一页面 Tabs。新建表与设计表保留当前会话草稿，未保存表单不持久化。

查询页签标题随该页选择的数据库/Schema 联动，例如「sql_studio_demo · 查询 1」，未选库时保留原名。切换已有页签显示各页自己的范围，左侧树选中项不参与标题派生；长库名省略时保留查询编号，悬停可查看全文。

Electron 最上方标题栏及系统窗口标题使用当前活动页的同一完整标题；切库、切页、恢复及关闭页面时同步更新，关闭最后一页回到 SQL Studio。工作台隐藏到 AI 页后台时停止同步窗口标题，AI 页显示 Logo 和当前语言的「AI 助手」页面标题。

Electron 正常退出从当前标签逐页处理，非空查询分别提示“取消 / 不保存 / 保存”，空白查询直接关闭；每次仅保存该页为独立 .sql 文件，关闭该标签后跳到下一项。未提交对象修改或运行请求按页提示。取消或保存失败保留当前和未处理标签，已经关闭的标签不恢复。全部标签处理完成后才统一关闭连接并保存空工作区；下次启动不恢复已关闭页面。默认及自定义连接分组保留原展开/收起状态，只收起连接、数据库及后代。Web 行为保持原样。

主页面签选中时滚入可见区域，新建页签自动定位到右端。「更多」面板可搜索和切换全部已打开的页面，并复用工作区关闭流程。多语句在发起页面顺序执行，MySQL、MariaDB 和 PostgreSQL 多语句在同一会话执行，失败或取消停止后续语句。同会话批次的结果可查看和导出，重跑使用原脚本。消息、摘要和数据结果并列，每个有列的数据集独占一个标签，超过 8 个结果集使用下拉选择。执行历史、消息和摘要均按语句记录并连续虚拟滚动。历史按连接隔离，载入追加到当前查询。SQL 窗口显式允许查询和写入，已提交写入在取消后保留。表数据的新增、删除、保存和放弃修改统一放在工具栏左侧。

页面和组件布局使用 style/styles；app.scss 仅保留基础全局规则、必要 Ant Design 覆盖及媒体查询、hover/焦点等必须使用选择器的规则。CodeMirror 通过原生样式扩展配置。主题与圆角使用原生 token，控件尺寸约定来自 appearance。对象栏和结果面板支持拖动、键盘调整及恢复，结果表虚拟滚动，条数固定在滚动区外。

页面切换、主题切换和系统设置由全局 [AppRail](../../components/appRail/README.md) 承载。对象栏标题行和搜索行与 AI 助手会话栏共用布局，标题行显示「对象」、连接数和新建连接。所有只读 SQL 展示按全文自动换行展开，滚动由外层结果区、历史表格或弹窗统一负责。

AI 配置通过服务商适配器获取模型，Key 仅后端保存。保存可用模型后，查询工具栏显示代码补全和优化，两项功能使用与 AI 助手共享的默认模型。工具栏的动作提示使用“优化”“导入”“导出”，预览弹窗标题为“优化建议”。续写作为建议展示，优化结果由用户决定是否载入和执行。

全局 Rail 的「同步数据库」支持同类型 MySQL、MariaDB、PostgreSQL 或 GreptimeDB 连接之间新建目标库并复制表。两端可独立使用已保存连接或本次填写的外部连接。检查通过后可同步表结构，也可附带数据。目标库已存在时停止。[同步数据库](../databaseSync/README.md)作为独立页面打开，从连接右键进入会预选源连接。

工作区操作错误通过 PageErrorBanner 展示。查询输出位于底部结果、摘要及消息区域，错误同样使用 ErrorNotice。连接经复核不可用时清理该连接的旧会话与对象树子节点，原因和重试入口显示在连接下方。重连重新读取库列表，库以下层级按用户展开重新加载。

工作区布局索引与每页草稿、执行结果分别落盘，启动只读取索引与当前页；已保存的非活动内容释放内存，切换时按需加载，加载失败可重试。后台执行页及未保存内容保留。完整结果不再随输入、滚动等布局更新一起发送或回传。

当前标签加载时，等待图标和说明覆盖整个工作区主体（含对象栏和页签）并水平、垂直居中；加载失败的重试入口同样居中，加载期间对象栏和页签操作暂不可用。

工作区配置、主题、连接列表和其他页面操作错误统一由 PageErrorBanner 在内容上方展示，相同原因去重。连接列表重试按钮位于提示内。ErrorNotice 使用全局一致的错误外观与关闭按钮。

工作区底层、连接侧栏与主内容统一使用 Ant Design `colorBgContainer`（`--surface`），与 AI 助手、监控和同步的主内容背景一致。页签栏使用 30px 透明页签、1px 边框和 2px 主色活动线，未保存修改显示琥珀色圆点，末尾提供新建查询图标按钮，栏右侧通过「更多」图标打开页面列表。对象栏搜索行、查询工具栏和表数据结果页签栏单行均为 42px，计入分隔线。结果页签右侧依次显示毫秒耗时文本和成功或失败图标。结果集选择器位于状态左边，筛选框位于操作图标左边。两个控件等宽等高，使用子网格时在窄面板中也保持上下对齐。数据表使用标准尺寸、吸顶表头和水平分隔线，条数固定在表格滚动区外。

连接侧栏与Agent历史侧栏共用App提供的宽度偏好及尺寸配置，切换页面不重置；工作台始终挂载并沿用现有布局索引保存、恢复宽度，Agent不新增独立宽度存储。

App 传入 active 标识，隐藏工作台不会处理执行快捷键。页签栏右侧提供后台查询的取消操作。执行或打开弹窗时，侧栏保持节点布局稳定。查询结果按钮命名“重新执行”，提示写语句也会再次执行。后台配置保存冲突后自动读取服务端最新内容。

全局 Rail 的[监控指标](../databaseMonitor/README.md)打开独立统计页面，App 自动带入对象树或页签范围；连接右键入口直接定位该连接。页面切换时保持工作区挂载。

Redis 使用相同的查询标签和连接/数据库选择器。逻辑库由实例返回，工具栏右侧可切换键详情、命令行和发布订阅。默认显示命令编辑器，支持选区运行和本地候选。Redis 隐藏代码补全与优化按钮，其他数据库的补全偏好保持独立，导入/导出使用相同的简短动作提示。键树默认折叠，支持双击展开或收起，删除和刷新保留已有分组状态。右键删除和详情删除共用弹框确认完整键名。键名及值直接通过表单编辑，不提供复制按钮。TTL 输入默认 0，实际期限在右侧倒计时显示。命令行使用“主机:db编号>”提示符，空行回车只换行，不发请求。输入命令前缀时显示可选择的本地 Select 候选和参数说明，输入 SELECT 时提示当前实例可选的逻辑库。
