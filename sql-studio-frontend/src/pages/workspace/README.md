# SQL 工作区

[源码](index.tsx) · [组件](components/README.md) · [hooks](hooks/README.md) · [配置](constant/README.md)

页面入口组合顶栏、对象树、查询/结果/设计页、连接与 AI 弹窗；useWorkspace 编排状态。工作区、历史、主题和界面字号由 Go 分区 JSON 保存，不含连接密码；恢复只加载必要元数据，不执行 SQL。

每个查询页独立持有连接、库、表、SQL 与最新结果。工具栏范围和对象树高亮相互独立；树操作携带显式目标，关闭连接清理相关范围并保留草稿/结果。查询、对象数据、结构、DDL、表设计使用统一页面 Tabs。新建表与设计表保留当前会话草稿，未保存表单不持久化。

查询页签标题随该页选择的数据库/Schema 联动，例如「sql_studio_demo · 查询 1」，未选库时保留原名。切换已有页签显示各页自己的范围，左侧树选中项不参与标题派生；长库名省略时保留查询编号，悬停可查看全文。

Electron 最上方标题栏及系统窗口标题使用当前活动页的同一完整标题；切库、切页、恢复及关闭页面时同步更新，关闭最后一页回到 SQL Studio。工作台隐藏到 AI 页后台时停止同步窗口标题，AI 页继续隐藏最上方标题。

多语句在发起页面顺序调用单语句 API，失败或取消停止后续语句。消息、摘要和数据结果并列；无列回执不生成标签，超过 8 个结果集使用下拉选择，摘要每页 50 条；历史按连接隔离，载入追加到当前查询。MySQL/PostgreSQL SQL 窗口均允许执行查询和写入；对象/数据保存显式写入，取消不能视为回滚。表数据支持新增及暂存单元格，顶部统一保存或放弃。

页面和组件布局使用 style/styles；app.scss 仅保留基础全局规则、必要 Ant Design 覆盖及媒体查询、hover/焦点等必须使用选择器的规则。CodeMirror 通过原生样式扩展配置。主题与圆角使用原生 token，控件尺寸约定来自 appearance。对象栏和结果面板支持拖动、键盘调整及恢复，结果分页固定在滚动区外。

顶栏操作按内容固定排列，不绑定侧栏宽度；调整下方对象栏不改变顶栏按钮位置或高度。所有只读 SQL 展示按全文自动换行展开，滚动由外层结果区、历史表格或弹窗统一负责。

AI 配置通过服务商适配器获取模型，Key 仅后端保存；续写作为建议展示，优化结果由用户决定是否载入，不自动执行。配置失败和冲突提示可关闭，关闭提示不代表保存成功。

工作区不展示 message 消息浮层（由 App 通过 Ant Design message.styles.root 统一隐藏），查询输出继续在底部结果/摘要/消息区域展示；确认弹窗及表单内错误保持原交互。

工作区布局索引与每页草稿、执行结果分别落盘，启动只读取索引与当前页；已保存的非活动内容释放内存，切换时按需加载，加载失败可重试。后台执行页及未保存内容保留。完整结果不再随输入、滚动等布局更新一起发送或回传。

当前标签加载时，等待图标和说明在标签内容区水平、垂直居中，随内容区伸缩。

工作区配置/主题错误与连接列表加载失败统一由顶部单个横幅展示，相同原因去重；连接列表的重试按钮放在横幅内，侧栏不再重复显示错误卡片。顶部保存状态仍准确反映配置保存结果，关闭横幅不代表故障恢复。

工作区底层、连接侧栏与主内容统一使用 Ant Design colorBgContainer（--surface），避免左右空白区域及导航底层因layout/container混用而产生色差；表格、控件和选中态保留原生主题层次。

顶栏左侧提供新建连接和新建查询，竖线后是「AI 助手」入口按钮，随后是齿轮图标加文字的「系统设置」按钮，与其他按钮对齐。右侧显示保存状态；设置菜单用于配置 DeepSeek API 和选择外观。

连接侧栏与Agent历史侧栏共用App提供的宽度偏好及尺寸配置，切换页面不重置；工作台始终挂载并沿用现有布局索引保存、恢复宽度，Agent不新增独立宽度存储。

App 传入 active 标识，隐藏工作台不会处理执行快捷键。顶栏在后台页执行时提供取消执行；侧栏不因执行或弹窗占用插入提示文字，保持节点布局稳定。查询结果按钮命名“重新执行”，提示写语句也会再次执行。保存失败仅显示错误提示，不提供恢复弹窗。
