# 输出标签导航

界面固定文案通过共享 useTranslation 跟随已保存语言切换；SQL、用户输入和数据库返回内容按原文展示。

[组件索引](../README.md) · [源码](index.tsx)

ResultTabs 接收 run:RunState、running:boolean、activeKey:string、onChange(key:string) 和可选 status:ReactNode，前四项必传。消息 key=messages，摘要 key=summary。首个数据集的 key 为语句索引，后续数据集为 `语句索引:数据集索引`。由 queryResults 控制选中视图并传入成功/失败、耗时、行数和列数状态，工作区保存所选的数据集位置。

消息、摘要与数据结果共用 42px 线形导航。页签高 30px，文字跟随全局字号和正文色，激活项用 2px 主题色活动线标识。消息与摘要带类型图标，结果标签显示序号，行数在执行状态中展示。两侧留白纳入 Tabs 滚动测量，保留键盘焦点和溢出菜单。执行状态与结果选择器在右侧并排，空间不足时换到下一行。外层为整栏绘制单条主题分隔线。结果标签按数据集连续编号，悬停可查看语句序号和 SQL。

每个有列的数据集生成一个结果标签，包括零行 SELECT、带返回列的 RETURNING 和同一条 CALL/EXECUTE 的后续结果。无列回执与错误在消息和摘要中展示。对象数据使用单结果标签。

最多并排显示 8 个结果标签。更多时保留当前结果标签，右侧小号 Select（aria-label=选择结果集）提供全部结果。执行期间禁用结果选择，消息标签显示加载图标，消息和摘要仍可访问。切换视图读取当前批次的本地结果。
