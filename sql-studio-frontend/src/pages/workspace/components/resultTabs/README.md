# 输出标签导航

界面固定文案通过共享 useTranslation 跟随已保存语言切换；SQL、用户输入和数据库返回内容按原文展示。

[组件索引](../README.md) · [源码](index.tsx)

ResultTabs 接收 run:RunState、running:boolean、activeKey:string、onChange(key:string) 和可选 status:ReactNode，前四项必传。消息 key=messages，摘要 key=summary。首个数据集的 key 为语句索引，后续数据集为 `语句索引:数据集索引`。由 queryResults 控制选中视图并传入执行回执，右侧依次显示毫秒耗时文本和状态图标。工作区保存所选的数据集位置。

消息、摘要与数据结果共用 42px 线形导航。页签高 30px，文字跟随全局字号和正文色，激活项用 2px 主题色活动线标识。消息与摘要带类型图标，结果标签显示序号。导航外层统一提供 16px 左右留白，Tabs 在剩余空间内定位选中页签及溢出菜单。结果选择器位于右侧执行状态左边，组间距 8px。状态图标与下方操作按钮使用等宽的居中区域。空间不足时换行，继续沿右侧留白对齐。外层为整栏绘制单条主题分隔线。结果标签按数据集连续编号，悬停可查看语句序号和 SQL。

每个有列的数据集生成一个结果标签，包括零行 SELECT、带返回列的 RETURNING 和同一条 CALL/EXECUTE 的后续结果。无列回执与错误在消息和摘要中展示。对象数据使用单结果标签。

最多并排显示 8 个结果标签。更多时保留当前结果标签，右侧 Select（aria-label=选择结果集）提供全部结果。选择器与下方筛选框等宽等高，在支持 CSS 子网格的环境下同列对齐。状态与操作组共用右栏，窄布局将页签移至单独一行。执行期间禁用结果选择，消息标签显示加载图标，消息和摘要仍可访问。切换视图读取当前批次的本地结果。
