# 输出标签导航

界面固定文案通过共享 useTranslation 跟随已保存语言切换；SQL、用户输入和数据库返回内容按原文展示。

[组件索引](../README.md) · [源码](index.tsx)

ResultTabs 接收 run:RunState、running:boolean、activeKey:string、onChange(key:string) 和可选 status:ReactNode，前四项必传。消息 key=messages，摘要 key=summary，结果 key 为语句索引字符串。由 queryResults 控制选中视图并传入成功/失败、耗时、行数和列数状态，工作区保存结果索引，无内部业务状态。

消息、摘要与数据结果使用同一层 38px 线形导航：页签高 30px、文字跟随全局界面字号，激活项使用正文色文字和 2px 绿色底线；消息/摘要带类型图标，结果标签只显示序号，行数在右侧执行状态中展示。导航使用结果面板底色，两侧留白与工具栏对齐，保留键盘焦点和溢出菜单。结果页签右侧与状态同排，窄屏或结果过多时同时容纳结果集下拉。结果标签按数据集连续编号，key 保留原始语句索引，悬停可查看语句序号和 SQL。

返回数据列的语句生成结果标签，包括零行 SELECT 和带返回列的 RETURNING。无列回执与错误在消息和摘要中展示。对象数据使用单结果标签。

最多并排显示 8 个结果标签。更多时保留当前结果标签，右侧小号 Select（aria-label=选择结果集）提供全部结果。执行期间禁用结果选择，消息标签显示加载图标，消息和摘要仍可访问。切换视图读取当前批次的本地结果。
