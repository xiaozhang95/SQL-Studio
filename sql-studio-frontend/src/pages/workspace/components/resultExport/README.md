# 查询结果导出

`ResultExport({ result, selectedCount, rows, disabled })` 提供工作区结果的导出按钮和导出弹框。弹框中的导出格式和导出范围使用左标签、右单选组的横向布局。窄屏时标签可换行，单选组随控件列收缩。格式可选 CSV、Excel 或 JSON，范围可选已加载的筛选结果或选中行。每次打开默认选中 CSV 和已加载的筛选结果。选中行显示数量，未选中任何行时禁用该范围。确认后调用 `rows(selected)` 取得当前排序下的对应行。

弹框绑定当前结果，结果切换使旧选择失效。导出期间禁用重复提交，成功发起下载后关闭，失败时在弹框内保留选项和错误。首行过大且仅提供只读预览时禁用导出。JSON 保存列定义、二维行和截断状态。Excel 保留文本精度，结果截断时附说明工作表，单元格超限时提示改用 JSON。
