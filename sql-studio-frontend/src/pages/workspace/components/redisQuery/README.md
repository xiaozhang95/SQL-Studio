# Redis 查询工具

`RedisQuery` 渲染在统一的查询标签内，接收连接、页签范围和主题。左侧是连接、逻辑库和运行操作。右侧从键详情、命令行和发布订阅图标切换工具，右边是代码补全、美化、导入导出及执行历史。再次点击当前工具返回编辑器。Redis 不提供 AI 代码补全，开关在所有工具中固定不勾选并禁用置灰，不读取或修改其他数据库共享的 AI 偏好。编辑器和命令行的本地命令候选、参数用法继续可用。连接选择包含已保存的 Redis 和关系型数据库。

[编辑器](components/editor/README.md)复用工作区文档草稿和位置保存。[终端](components/console/README.md)按标签和连接保存草稿、光标/选区、历史及回执，刷新时恢复原输入位置和当前工具。[发布订阅](components/pubsub/README.md)在工具切换时保留实时请求。关闭标签或切换连接时释放旧范围的请求。使用 SELECT 更新发起标签的数据库。
