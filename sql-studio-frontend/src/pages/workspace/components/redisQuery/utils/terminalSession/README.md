# Redis 终端会话

按查询页 ID 和连接 ID 保存当前单行输入、`TerminalSelection {anchor,head}` 光标/选区、最多 50 条非空命令历史和已完成回执。空输入回车产生的提示符行使用空 command/answer 保存，计入回执条数，不计入命令历史。使用当前窗口的 sessionStorage，刷新同时恢复草稿和原光标/选区，关闭标签时清理。`readTerminal` 校验位置为有限整数并限制在草稿长度内，没有有效位置时默认放到命令末尾；`saveTerminal` 接收同一会话结构并保存有效范围。页签选中的工具也在这里按页保存。回执最多保存各自前 4096 个字符。浏览器拒绝存储时可继续使用当前组件内的会话。读取记录不会调用 Redis。
