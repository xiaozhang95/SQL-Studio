# Redis 终端

接收页签 ID、连接 ID、主机 `host`、当前逻辑库编号、连接返回的库列表、主题和可见状态。提示符显示为 `host:db编号>`，使用主题黄色，亮暗主题的终端都随工作区显示 `colorBgContainer`。[单行输入](../consoleInput/README.md)在命令前缀处显示带参数说明的本地 Select 候选，方向键选择、Enter/Tab 接受、Escape 关闭；没有候选时 Enter 执行，空输入回车只追加一行提示符，不调用 Redis、不写命令历史，方向键上下检索非空命令历史。历史抽屉可载入同连接的单条命令，语法提示自动在提示符下展示当前命令的用法。`SELECT` 同时提示可选逻辑库，最多显示前 16 项。输入区和输出区的空白处都可点击后直接键入，拖拽仍可选中文本。输入 `clear` 或按 Ctrl/Command+L 清屏。通过[终端会话](../../utils/terminalSession/README.md)恢复输入、历史和已完成回执，不使用 AI 续写。

终端的提示符、输入、回执和命令用法统一继承系统默认字体，候选下拉跟随输入区字体，不单独使用等宽字体。草稿和光标/选区同步保存，刷新后在恢复位置取得输入焦点，不跳回命令开头。成功的 SELECT 通过 `onDatabase` 传回发起标签。执行期间 `onBusy` 暂停该页范围切换，卸载取消在途请求。

命令错误的具体原因显示在对应回执下。连接、超限和请求错误由可见终端登记到顶部，也可以展开对应回执中的「执行失败」再次查看原因。疑似断线时通过 `onVerifyConnection(id)` 在后台复核发起连接，普通命令错误、超限和取消跳过复核。
