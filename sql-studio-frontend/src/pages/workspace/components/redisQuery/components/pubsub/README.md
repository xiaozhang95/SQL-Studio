# Redis 发布订阅

频道列表右沿、筛选行与工具栏使用 `--layout-divider`，消息行使用 Ant Design 的 `colorBorderSecondary`。

`PubSub({id,active})` 使用满高双栏：左侧为活跃频道列表，宽度上限为 320px 和面板宽度的 55% 中较小者，使用与键浏览相同的 [SidebarSearch](../../../../../../components/sidebarControls/README.md)，输入停顿后自动筛选频道名称。普通关键词匹配名称中的任意位置，显式 Redis 通配符按原模式匹配。频道名后紧跟订阅者数（间距 8px）；行高与对象树一致（30px），选中行使用全局中性选中底，左右内边距与标题栏和筛选行统一为 16px。右侧为实时消息流。两侧标题栏单行高度为 42px，窄面板中的消息操作可以换行。点击频道会把名称带入订阅输入并切回精确频道模式，订阅进行中禁用频道切换。

可输入频道或模式启动临时实时订阅，保留最近 100 条消息并记录接收时间。消息行的时间、频道和内容按同一基线对齐，时间沿用 Ant Design 默认字号、次级文字色和等宽数字。消息流标题栏提供小号自动滚动开关，以及暂停和清空按钮。继续接收、停止订阅或连接中断会补入暂停期间已收到的消息；清空同时清除暂存和可见消息。切回工具时按当前自动滚动设置恢复跟随。频道或模式、开始/停止和订阅状态位于顶部同一行；频道列表被截断时在标题旁提示仅显示部分内容。停止订阅、关闭页签或切换连接会取消请求。
