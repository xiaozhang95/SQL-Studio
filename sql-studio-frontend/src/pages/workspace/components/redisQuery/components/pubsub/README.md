# Redis 发布订阅

`PubSub({id,active})` 使用满高双栏：左侧为 320px 活跃频道列表，按匹配模式筛选并显示订阅者数，行高与对象树一致（30px）并左右铺满；右侧为实时消息流。两侧标题栏同为 42px，底部分隔线齐平。点击频道会把名称带入订阅输入并切回精确频道模式，订阅进行中禁用频道切换。

可输入频道或模式启动临时实时订阅，保留最近 100 条消息并记录接收时间。消息流标题栏显示条数、自动滚动开关以及暂停/清空操作；暂停期间新消息暂存，继续后一次补入。频道或模式、开始/停止和订阅状态位于顶部同一行；频道列表被截断时在标题旁提示仅显示部分内容。文字、状态、消息频道和内容均使用 Ant Design 默认颜色与字体，标题栏和筛选行的图标按钮统一使用默认尺寸并右对齐。停止订阅、关闭页签或切换连接会取消请求。
