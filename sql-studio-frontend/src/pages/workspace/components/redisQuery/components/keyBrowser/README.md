# 键浏览

`KeyBrowser({id,database,themeMode,active})` 使用满高的左右分栏：左侧为键浏览，右侧为键详情，不再使用并排卡片。同一连接/逻辑库内的组件保持挂载，切换页签或 Redis 工具后展开分组、筛选、已加载列表、当前详情和表单草稿不重置；非活动时暂停 TTL 轮询并收起新增/删除弹框。左侧用 SCAN 分页，支持 Redis 通配符。输入框回车或筛选按钮触发筛选。已加载的键通过[分组树](../keyTree/README.md)按冒号命名空间展示，文件夹显示已加载的键数量，默认折叠，可双击展开/收起。左侧顶部显示已加载键数和新增/刷新入口，标题栏与筛选行的图标按钮统一使用 Ant Design 默认尺寸并右对齐；扫描状态条在搜索框下提供「扫描下一批」「连续扫描」「停止扫描」等操作，仅在可继续扫描或需要重扫时出现。「扫描下一批」最多追加 10 页，「连续扫描」沿当前游标扫描到末尾。两种扫描均可停止，保留已加载的键、当前详情和可继续使用的游标。集群游标失效时保留已加载的键，顶部显示原因，续扫按钮替换为「重新扫描」，从当前筛选的第一页扫到末尾。重新筛选或刷新从第一页开始。首次点击读取键详情，刷新按钮重新读取。列表与展开状态由 [useKeyBrowser](../../hooks/useKeyBrowser/README.md) 管理，删除只移除目标键。键和分组提供右键菜单，删除绑定右键目标。

详情通过[原位编辑器](../keyEditor/README.md)直接编辑键名、TTL 和键值，修改后共用保存/取消，不提供编辑弹窗或独立重命名按钮。支持完整 UTF-8 String、List、Set、Hash、ZSet，集合保留 JSON 数组形式；截断、二进制、Stream 或未知值只读，键名及 TTL 仍可独立修改。右侧头部只保留类型、大小、TTL 标签和刷新/删除操作；键名与 TTL、键值保持左标签右控件的横向表单。输入框显示读取时的剩余秒数，不随每秒倒计时跳动；用户编辑后显示待设置秒数。头部倒计时独立反映服务端当前期限，不展示过期日期。仅改 TTL 使用 ttl 操作，同时改名或改值时一次提交。键名和值仅保留编辑区，不提供复制按钮；截断时明确提示仅显示部分内容。键值复用 SQL 编辑器的 CodeMirror 外观和行号。保存通过统一 commit 互斥请求，失败保留草稿，成功重新读取；保存期间禁用筛选、刷新及其他写入。切换键或刷新丢弃未保存草稿，不自动提交。

从键列表右上角打开新增表单，填写键名、值和 TTL 创建字符串键。详情删除按钮和右键删除共用 [确认弹框](../keyDelete/README.md)，弹框绑定发起删除的键，失败时保留目标和错误，成功后关闭。TTL 在详情中直接设置。弹框输入由组件状态控制，Form 提供横向布局。保存期间禁用关闭。TTL 输入以秒为单位，倒计时显示天数及 HH:mm:ss，填 0 设为永久。未编辑 TTL 时保留原期限。当前键有过期时间时每秒读取 TTL，到期后清除已失效的详情和列表项。已被其他客户端修改的值会提示重读。换库、切换连接及关闭页签取消旧范围的请求。
