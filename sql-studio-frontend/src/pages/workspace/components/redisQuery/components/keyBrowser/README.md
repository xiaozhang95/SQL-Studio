# 键浏览

`KeyBrowser({id,database})` 用 SCAN 分页，支持 Redis 通配符。筛选使用带悬停说明和无障碍名称的图标按钮，输入框回车同样触发筛选。已加载的键通过[分组树](../keyTree/README.md)按冒号命名空间展示，文件夹显示已加载的键数量，默认折叠，可双击展开/收起。扫描下一页会追加数据并保留当前详情，重新筛选或刷新从第一页开始。首次点击读取键详情，同一个键的单击及双击共用当前详情，刷新按钮重新读取。键树与左侧连接对象树共用行距、箭头、图标及文字布局。

详情通过[原位编辑器](../keyEditor/README.md)直接编辑键名、TTL 和键值，修改后共用保存/取消，不提供编辑弹窗或独立重命名按钮。支持完整 UTF-8 String、List、Set、Hash、ZSet，集合保留 JSON 数组形式；截断、二进制、Stream 或未知值只读，键名及 TTL 仍可独立修改。键名、属性、TTL 和键值共用表单对齐线，类型与大小同排；TTL 单独一整行，数字框与右侧只读按钮通过 Space.Compact 组合，整体铺满内容列。按钮显示 HH:mm:ss 倒计时，超过一天时带天数，永久键显示永久有效。输入框保持本次载入值或待设置秒数，不随每秒 TTL 读取而变化；右侧倒计时独立反映服务端当前期限，不展示过期日期。仅改 TTL 使用 ttl 操作，同时改名或改值时一次提交。复制按钮位于对应输入区右侧，复制当前输入的键名或值，截断时明确提示仅复制当前预览，不创建 Redis 副本。保存通过统一 commit 互斥请求，失败保留草稿，成功重新读取；保存期间禁用筛选、刷新及其他写入。切换键或刷新丢弃未保存草稿，不自动提交。

从键列表右上角打开新增表单，填写键名、值和 TTL 创建字符串键。新增和删除保留弹窗，TTL 在详情中直接设置；弹窗输入由组件状态控制，Form 仅提供横向布局，不创建外部表单实例；遮罩关闭使用 mask.closable，保存时禁止关闭。TTL 输入以秒为单位，倒计时转为天及 HH:mm:ss，填 0 设为永久；未编辑 TTL 时保留原期限。当前键有过期时间时每秒读取 TTL，到期后自动清除已失效的详情和列表项，详情回到空状态。已被其他客户端修改的值会提示重读。删除需要确认。换库、切换连接及关闭页签取消旧范围的请求。
