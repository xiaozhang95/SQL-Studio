# 键浏览

`KeyBrowser({id,database})` 用 SCAN 分页，支持 Redis 通配符。首次点击读取键详情，同一个键的单击及双击共用当前详情，刷新按钮重新读取。键行复用连接类型的悬停和选中反馈。

详情分两行显示键名、类型、TTL 和大小。从键列表右上角打开新增表单，填写键名、值和 TTL 创建字符串键，也可编辑可完整预览的 UTF-8 字符串键。TTL 的输入和倒计时均显示秒，填 0 设为永久，编辑时未调整 TTL 则保留期限定时。当前键有过期时间时每秒读取 TTL，到期后自动清除已失效的详情和列表项，详情回到空状态。已被其他客户端修改的值会提示重读。复制和重命名从同库生成不同名称，不覆盖现有键。删除需要确认。换库、切换连接及关闭页签取消旧范围的请求。
