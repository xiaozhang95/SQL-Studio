# 键详情直接编辑

`KeyEditor({selected,detail,saving,error,onSave,clearError,ttlMillis})` 在键详情卡片原位提供横向键名输入框、TTL 数字框和值编辑区，同时展示类型和大小信息。ttlMillis 是父级维护的当前剩余毫秒数，仅驱动右侧的实时剩余秒数；TTL 输入默认 0，取消和重新载入恢复为 0；右侧倒计时不回填输入。默认显示 0 不会改变当前期限，只有用户明确编辑 TTL 后保存才提交。TTL 以整数秒直接设置，填 0 移除过期时间，不打开弹窗；与键名、键值共用的保存/取消按钮始终显示，未修改、TTL 空值或越界时禁用保存，保存期间禁用两者。键名和键值仅保留表单输入，不提供复制按钮。草稿由 [useKeyEditor](../../hooks/useKeyEditor/README.md) 管理。

键名、类型、TTL、键值共用横向 Form 的 92px 标签列及右对齐标签，内容从同一列开始。类型和大小同排展示，TTL 独占一整行，使用 Ant Design Space.Compact 将数字框和右侧只读按钮连成一组，整体占满内容列。数字框通过 flex 铺满可用空间，按钮独立显示“剩余 HH:mm:ss”；超过一天时显示“剩余 D 天 HH:mm:ss”，例如 90061 秒显示“剩余 1 天 01:01:01”，永久键显示“永久有效”。倒计时不写回输入框，不展示过期日期，按钮禁用且不触发保存。键名输入框、键值文本域、TTL 控件及底部按钮共用同一右边界。TTL 校验和 0 值说明、集合编辑说明及截断提示均放在对应内容列下方。外观沿用 Ant Design 默认控件和主题 token。

完整的 UTF-8 String、List、Set、Hash 和 ZSet 可编辑。String 使用原文；List/Set 使用 JSON 字符串数组；Hash/ZSet 使用 [字段或成员, 值或分数字符串] 的 JSON 数组。限制为 16KiB、最多 50 个集合元素，集合不能为空，后端校验并保留原类型及未修改的 TTL。截断、二进制、Stream 或未知类型只读显示值；键名和 TTL 仍可独立编辑。保存期间禁用编辑，失败保留草稿；切换键、刷新或离开详情丢弃未保存的输入，不自动提交。
