# 键详情直接编辑

详情头部与底部操作栏使用 `--layout-divider`。键名、TTL 和键值编辑器的常态边框与圆角共用 Ant Design 的 `colorBorder` 和 `borderRadius`。

`KeyEditor({selected,detail,saving,onSave,clearError,ttlMillis,onDelete,onRefresh})` 渲染完整的键详情面板：头部仅保留类型/大小/TTL 标签和刷新、删除操作，主体表单依次编辑键名、TTL 和键值，底部固定保存/取消。ttlMillis 是父级维护的当前剩余毫秒数，仅驱动头部标签的实时剩余秒数；TTL 输入显示读取时的剩余秒数，取消和重新载入恢复为该值；头部倒计时独立刷新且不回填输入。未编辑 TTL 时保存保留原期限，只有用户明确编辑 TTL 后保存才提交。TTL 以整数秒直接设置，填 0 移除过期时间，不打开弹窗；与键名、键值共用的保存/取消按钮始终显示，未修改、TTL 空值或越界时禁用保存，保存期间禁用两者。键名和键值仅保留表单输入，不提供复制按钮。草稿由 [useKeyEditor](../../hooks/useKeyEditor/README.md) 管理。

类型、大小、TTL 收进头部标签，标签使用 Ant Design 默认外观，不再显示独立的「键详情」标题；头部刷新和删除使用统一图标按钮并带悬停说明。键名、TTL 与键值使用横向 Form 的紧凑右对齐标签列，键名和 TTL 输入使用与 SQL 窗口一致的标准控件并铺满内容列。键值区复用 SQL 窗口的 CodeMirror 外观与行号，行号槽间距、分隔线和激活行底色随 SQL 编辑器一致，输入上限 16KiB。倒计时显示“剩余 HH:mm:ss”；超过一天时显示“剩余 D 天 HH:mm:ss”，例如 90061 秒显示“剩余 1 天 01:01:01”，永久键显示“永久有效”。倒计时只出现在头部标签，不写回输入框，不展示过期日期。键名输入、键值编辑区、TTL 控件及底部按钮共用同一右边界。TTL 校验提示放在对应内容列下方；截断时在键值区底部提示仅显示部分内容。外观沿用 Ant Design 默认控件和主题 token。

完整的 UTF-8 String、List、Set、Hash 和 ZSet 可编辑。String 使用原文；List/Set 使用 JSON 字符串数组；Hash/ZSet 使用 [字段或成员, 值或分数字符串] 的 JSON 数组。限制为 16KiB、最多 50 个集合元素，集合不能为空，后端校验并保留原类型及未修改的 TTL。截断、二进制、Stream 或未知类型只读显示值；键名和 TTL 仍可独立编辑。保存期间禁用编辑，失败保留草稿；切换键、刷新或离开详情丢弃未保存的输入，不自动提交。
