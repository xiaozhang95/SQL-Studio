# 工作区查询收藏

顶栏打开收藏列表，支持搜索、重命名、删除及打开新查询标签。编辑器收藏选区或全文，执行历史也能收藏原 SQL。收藏保留原连接与数据库范围，失效的连接可打开为未绑定草稿。弹窗只输入收藏名称，打开收藏不执行 SQL。读取失败在抽屉内显示原因，标题栏可重试。删除失败保留对应收藏的确认气泡和失败原因。

列表 SQL 列和展开详情均复用 [SQLPreview](../sqlPreview/README.md) 的 compact 模式，与执行历史使用相同的高亮、换行和复制布局。预览按收藏的连接类型高亮，原连接已删除时使用默认适配器。复制保留原始 SQL 的全部内容和换行。复用 [useTableViewportLayout](../../hooks/useTableViewportLayout/README.md) 将长 SQL 的滚动限制在表体，保留抽屉搜索、表头和分页。
