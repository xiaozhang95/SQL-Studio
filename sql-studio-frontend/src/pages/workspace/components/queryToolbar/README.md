# 查询工具栏

`QueryToolbar` 接收当前查询页的范围、已保存的连接和对象元数据。SQL 与 Redis 共用左侧连接和库下拉，dropdown 高度沿用 Ant Design 默认控件尺寸。调用者可在 `runActions` 提供运行/取消按钮，通过 children 提供右侧操作图标。工具栏单行最小高度 42px，计入底部分隔线，与对象栏搜索行和表数据结果页签栏对齐。布局由 Flex 管理。内边距、表面和底部分隔线取主题 token。

工作台与 Redis 编辑器共用 [RunButton](../runButton/README.md) 作为唯一 primary 运行操作，并显示执行快捷键。执行中显示 text danger「取消执行」。AI 补全、优化、导入、导出和历史使用图标或短文本操作。Redis 使用 `compact` 收缩两个下拉。工具栏按编辑面板宽度换行，选择器等宽收缩，运行和右侧工具优先共用操作行。换行时继续使用统一的水平留白和紧凑行距。

工具栏只负责布局与分组，不读取执行状态；按钮的禁用、加载、危险语义由调用方传入。
