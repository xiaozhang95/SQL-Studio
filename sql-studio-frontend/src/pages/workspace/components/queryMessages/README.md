# queryMessages

[组件索引](../README.md) · [源码](index.tsx)

QueryMessages 接收 run:RunState、running:boolean、themeMode:ThemeMode 和可选 databaseType，按执行顺序展示本批 SQL、成功/错误与查询耗时。SQL 通过 sqlPreview 只读高亮并支持复制；执行时展示已完成消息和进行中提示。兼容未保存 SQL 的旧结果。不修改结果选择和数据库状态。

SQL 使用 compact 变体，复制图标与摘要、历史及 DDL 一致，不额外显示 SQL 标题及复制 SQL 文本按钮。

每条 SQL 的复制图标位于其左侧，紧邻首行；不随消息区宽度移到最右端，短语句和多条执行消息也能明确对应。

成功消息按是否有结果列区分查询结果与纯执行回执，兼容旧无列成功记录。错误消息使用全局 ErrorNotice。

每条完成语句使用 Ant Design Collapse 独立折叠，标题显示序号、成功/失败图标及文案和耗时；默认展开错误项、收起成功项，正文保留 SQL 复制与完整回执。新批次按startedAt（旧记录回退id）重置折叠状态。

消息按50条分页，仅构建当前页的折叠项与预览，默认跟随最新一页，手动翻页后保留选择，新批次重置；记录全部保留。折叠项关闭后销毁预览编辑器，页码不改变结果索引或SQL范围。

useQueryMessageScroll负责在已完成消息增加时滚到当前结果视口底部，并跟随内容/面板高度变化；不滚动编辑器或整个页面。手动向上滚动或翻页时暂停并固定当前页，避免跨50条时切走正在阅读的内容；回到最新页底部后恢复跟随。新执行重置跟随；已完成历史初次打开从顶部阅读。QueryResults以页面ID隔离消息组件，切页或切到摘要/数据视图后清理旧滚动监听。
