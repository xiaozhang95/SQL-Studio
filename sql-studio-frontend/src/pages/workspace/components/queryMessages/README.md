# queryMessages

界面固定文案通过共享 useTranslation 跟随已保存语言切换；SQL、用户输入和数据库返回内容按原文展示。

[组件索引](../README.md) · [源码](index.tsx)

QueryMessages 接收 run:RunState、running:boolean、themeMode:ThemeMode 和可选 databaseType，按执行顺序展示本批 SQL、成功/错误与查询耗时。SQL 通过 sqlPreview 只读高亮并支持复制；执行时展示已完成消息和进行中提示。兼容未保存 SQL 的旧结果。不修改结果选择和数据库状态。

SQL 使用 compact 变体，复制图标与摘要、历史及 DDL 一致，不额外显示 SQL 标题及复制 SQL 文本按钮。

每条 SQL 的复制图标位于其左侧，紧邻首行；不随消息区宽度移到最右端，短语句和多条执行消息也能明确对应。

成功状态显示在折叠项标题中。展开成功消息可查看 SQL，无结果列且记录了实际影响行数时，SQL 下方同时显示影响行数。SQL 和 Redis 编辑器的语句错误在折叠项标题下直接展示具体原因。请求级错误在顶部提示，展开失败消息可再次查看具体原因。未关联到语句的请求错误在列表末尾单独显示可展开的「请求失败」。主动取消显示取消状态。

每条语句使用 Ant Design Collapse 独立折叠，标题显示原始序号、成功、失败或取消状态及耗时。默认收起，点击可查看和复制 SQL。Virtuoso 按实际高度虚拟渲染全部已完成消息，展开或滚出视口后仍保留该条的折叠状态。关闭折叠项或滚出挂载区域会卸载预览编辑器。父组件在新批次重置折叠状态。

useQueryMessageScroll 在新增完成消息及内容或面板高度变化时跟随列表底部。手动向上阅读暂停，回到底部恢复跟随。执行中打开默认跟随，打开已结束的批次从顶部阅读。切换主页面、批次或输出视图后清理旧滚动监听。
