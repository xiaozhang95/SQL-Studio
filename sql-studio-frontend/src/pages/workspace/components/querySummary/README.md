# querySummary

界面固定文案通过共享 useTranslation 跟随已保存语言切换；SQL、用户输入和数据库返回内容按原文展示。

[组件索引](../README.md) · [源码](index.tsx)

QuerySummary 接收 run:RunState、running:boolean、themeMode:ThemeMode 和可选 databaseType。汇总已处理/总数、成功、错误、开始/结束时间及批次运行耗时，下方按语句显示高亮可复制 SQL、消息和查询耗时。仅显示错误为组件内筛选，不影响结果选择。旧快照缺少时序字段显示未记录。双向滚动由表体管理，列宽可拖动表头右缘调整，文字统一左对齐。

查询列采用 SQLPreview compact 模式，第一行并排显示实际 SQL 与复制图标。消息列展示语句错误的具体原因。连接和请求错误在顶部展示，摘要保留执行状态并单独标记取消。

摘要的原生 Table 虚拟滚动连续展示全部匹配语句，仅挂载视口附近的行并测量实际行高。切换「仅显示错误」时从顶部阅读。逐条更新保留当前批次的筛选，新批次由父组件 key 重置。无结果列的成功回执显示实际影响行数。
