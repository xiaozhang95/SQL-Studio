# 已打开的页面

[源码](index.tsx) · [主区域页面标签](../README.md)

`OpenPagesMenu` 接收已打开页面的 ID、标题、范围、图标、未保存状态和当前页 ID，由工作区提供选择、关闭当前行及关闭其他页的回调。只要有已打开的页面，页签栏右端就显示「更多」图标按钮。面板关闭时，悬停或键盘聚焦显示 Ant Design Tooltip，按钮的可访问名称为「更多」。

点击打开右对齐的 Ant Design Popover。顶部显示标题和标准尺寸搜索框，按标题或连接范围筛选。入口、每行关闭按钮和底部「关闭其他」都使用 30px 标准控件高度。标题、搜索框、列表与底部操作按主题间距分隔。列表保留页签顺序。悬停底色覆盖整行，当前页通过右侧对勾标识。选中某行后切到对应页签并关闭面板。Enter 打开首个匹配项，Esc 关闭面板并将焦点还给「更多」。

各行关闭按钮与主页面签使用相同的主题图标色和悬停正文色。关闭单页和底部「关闭其他」复用工作区关闭流程。执行或编辑占用期间禁用关闭操作。有未保存设计页时沿用现有确认。列表高度受视口限制并可滚动。
