# 主区域页面标签

界面固定文案通过共享 useTranslation 跟随已保存语言切换；SQL、用户输入和数据库返回内容按原文展示。

[源码](index.tsx) · [组件索引](../README.md)

model 提供 tabs/activeTab、runs、运行状态和切换/关闭回调，children 为当前页。只有这一层 Tabs；查询 SQL 和本批所有结果共用一个主页面。

查询页可见标题跟随该页选择的数据库/Schema，例如「sql_studio_demo · 查询 1」或「demo / public · 查询 1」；未选库时保留原名。由 [pageTitle](../../utils/pageTitle/README.md) 在显示层派生，不改写保存的 title、不读取左侧树选中项。长库名优先省略，保留查询编号，悬停展示完整标题及原执行来源；对象、设计页沿用原标题。

按 kind 显示图标，运行页显示 loading。标题使用主题正文色，执行成功或失败在结果和消息中展示。业务状态随工作区索引和分片恢复。

右键关闭当前/其他/右侧按目标计算，执行中禁止关闭；最后一页可关闭并保存为空，下次刷新仍为空。

主页面的导航和内容高度覆盖仅作用于直属导航栏及内容容器，不影响结果区的嵌套 Tabs。

主页面使用 Ant Design 卡片页签，常态、悬停和选中态均沿用左右对称的上圆角和卡片间距。导航栏顶部和两侧留出主题内边距，页签边框颜色沿用 Ant Design 默认值。当前页使用内容区底色和主题指示线。原生样式覆盖限定在 app.scss 的直属导航范围。

Ant Design 6 主页面的 body-holder → body → content → workspace-page 连续传递高度，content 层的 100% 仅作用于直属主页面容器，避免编辑器和结果区塌缩。

model 额外提供 connections/designerDirty，renderDesigner(page) 注入表设计页面。table-create/table-design 使用设计图标，Tab 星号标记未保存；隐藏时保留已访问的组件实例，不提前加载未访问页。其他页面继续切换销毁展示组件。主页面标签的关闭和右键批量关闭复用工作区回调并检查草稿。

全局不启用 destroyOnHidden，仅逐项设置；否则全局销毁会覆盖设计页的 false，导致切页丢失草稿。查询等普通页仍按项销毁，设计页保持挂载。

关闭按钮始终保留布局占位；运行/弹框占用期间降低图标透明度并由 closeTabs 拒绝关闭，避免按钮隐藏引起标签宽度变化。

顶部主标签通过 Tabs.styles.item 统一固定为 workspaceTabLayout.width（200px），不随标题长度或选中状态改变。标题在图标与关闭按钮之间占满剩余空间，超长省略，原 title 保留完整名称和执行来源；关闭按钮始终靠右对齐。超过可用宽度继续使用原生溢出菜单，不影响嵌套结果导航。

非活动结果释放后，标签仍可从轻量索引显示来源摘要。tabBusy 只锁定实际执行或对象操作，当前页内容加载失败时仍允许切换和关闭标签。
