# AI 配置弹窗

AISettings({themeMode}) 顶部按钮按profile展示DeepSeek文字及官方图标；弹窗标题为“DeepSeek 配置”，移除服务商选择，采用label与控件左右排列的水平表单，展示官方动态模型、API Key及代码补全开关。模型加载错误显式展示且可重试，不假装静态选项来自官方 API；Key 修改后自动获取模型，成功后允许保存。再次打开用已保存 Key 自动获取模型。留空 Key 保留旧值，成功保存后广播配置更新，代码补全开关跨页面生效。表单生命周期由 useAISettings 管理。

表单顺序为API Key、模型、代码补全，Key位于模型列表之前；新Key填写后停顿自动获取列表，模型行按钮可手动重试。

表单不展示模型来源、Key留空规则与续写快捷键的常驻说明，保留字段label、占位符及实际错误提示。

页脚右侧依次为取消、移除配置、保存（移除仅已配置Key时可用）；移除期间禁用表单及关闭操作，移除后允许重新配置。

模型选择器提供请选择模型的placeholder；Key保留按是否已配置区分的现有占位符。
