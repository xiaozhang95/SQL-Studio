# 数据库连接树

[组件索引](../README.md) · [源码](index.tsx)

## 参数与回调

model 通过 Pick 仅消费 connections、objects、running，以及 connectionAction、openConnection、databaseAction、tableAction；不消费查询标签的连接/库/表或选择回调。

## 行为与边界

一棵树展示连接 → 数据库 → 表/视图。无保存布局时连接全部收起，有记录时恢复展开状态，点击箭头或双击连接/数据库节点加载、展开或收起子列表，单击文本只更新对象树独立的选中高亮，不改变右侧查询下拉框；右侧切换范围或查询标签同样不改变树高亮。节点 key 包含节点类型、连接 ID、库、表，同名对象不会跨连接混淆。结构缓存与工具栏选择器共享。

连接全部放在所属文件夹节点下，旧数据缺少 group 或空分组时归入“默认分组”，自定义分组保持原值。分组内连接右键仍支持编辑，可更换连接配置及分组。分组 key 为独立的 group/名称，不冒充连接 ID；分组展开/收起不请求数据库、不修改查询范围、不关闭连接。搜索同时匹配分组名，并临时展开分组显示匹配内容；清空搜索恢复原折叠状态。分组展开状态随原有加密布局保存，新建或移动连接保存后展开目标分组。

连接根节点使用 20px 白色海豚状态图标，成功加载结构后底色为 success，未成功打开、已关闭或失败时底色为灰色；折叠不会置灰，只有关闭才释放打开状态。库和表图标始终使用正常正文色，不按结构加载状态置灰。未选中节点文字使用主题正文色，暗色下为白色，亮色下使用深色，不因已加载而变蓝；选中仍使用 primary 背景及反色文字。图标与文本间距为 8px。失败显示原因。关闭后隐藏子项，重新展开会重新加载。搜索匹配连接名和已加载的库表，未加载连接仍保留供展开；长名称省略并提供完整 title。

连接右键提供打开/关闭、刷新、编辑、删除，加载中可关闭以取消请求。数据库右键提供新建查询、查看表列表、刷新结构；表/视图提供新建查询、查询数据、查询结构、查看 DDL。菜单均有图标，携带完整原始连接/库/表范围，停止冒泡；不依赖先点击选中，执行期间禁用。

树体独立滚动，选中态及 hover 使用 Ant Design 原生 primary/controlItemBgHover token。

双击通过原生 Tree expandAction=doubleClick 与箭头共用展开、loadData 和加载状态；表/视图叶节点不展开。图标容器统一 flex 居中，连接图标外层也使用 flex，覆盖原生 inline-block 的基线偏移；图标和文字在最小 28px 的选中背景内垂直居中，上下各留 2px，节点不额外加 padding-block；覆盖原生 margin-bottom 为 2px，行距约 30px。

双击库同时创建独立结构页（表名、类型、注释），与树展开共用一次 loadTables 缓存请求；已展开的库双击仍可打开结构页。双击表/视图调用只读查询并创建独立数据页，不隐式创建 SQL 编辑器；箭头只控制子项，不创建页面。

树节点文字禁止浏览器选择，双击仅执行展开/收起，不产生文本高亮。连接关闭时子节点的选中高亮随节点隐藏失效；查询范围只按连接关闭后的有效性清理，不参与树的日常选择。SQL 编辑器、结果和历史 SQL 仍可正常选择复制。

连接节点的 loadData 调用工作区 openConnection，和右键打开共用元数据生命周期；打开、折叠或选择树节点均不修改查询范围。

折叠按钮使用与内容块一致的最小 28px 高度，图标通过 flex 垂直居中；按钮始终透明，移除原生 hover 背景伪元素，不影响节点内容的选中或悬停背景。

explorer/updateExplorer 由工作区受控，保存 expanded/selected/search/top，并随本地加密快照恢复。恢复只加载已打开连接及展开库的元数据；切换查询范围不会改树的选中和展开状态。

折叠箭头区域宽 20px、右侧 margin 为 0，节点内容保留左右 8px 内边距，让选中背景不贴住图标；保留原有层级缩进、28px 点击高度，图标到文字为 4px。

库和表右键打开菜单时更新对象树选中高亮，不改变查询页范围。库增加编辑/新建/删除、新建表，表增加设计/新建/删除/清空/重命名/刷新，转储 SQL 文件子菜单目前仅结构。空库可从库菜单新建表，无库时可从已打开连接菜单新建数据库。视图不提供表字段设计和清空，删除按视图处理。所有回调携带节点的原始连接与库表名。

库菜单刷新文案统一为“刷新”；库、表、连接的右键目标覆盖图标、文字与行内空白，左键仍保留原生展开行为。

转储子菜单增加“结构和数据”，视图禁用该项。
