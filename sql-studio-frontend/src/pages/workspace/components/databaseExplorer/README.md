# 数据库连接树

[组件索引](../README.md) · [源码](index.tsx)

## 参数与回调

model 通过 Pick 消费 connections、objects、running，以及 connectionAction、openConnection、databaseAction、tableAction 和 openExplorerPage；不消费查询标签的连接/库/表或选择回调。

## 行为与边界

一棵树按引擎层次展示对象；MySQL 为连接 → 数据库 → 表分类 → 表 → 字段/索引，PostgreSQL 在数据库与分类之间增加 schema。原有视图放入独立视图分类，不增加新的对象能力。无保存布局时连接全部收起，有记录时恢复展开状态，点击箭头或双击连接/数据库节点加载、展开或收起子列表，单击文本只更新对象树独立的选中高亮，不改变右侧查询下拉框；右侧切换范围或查询标签同样不改变树高亮。节点 key 包含节点类型、连接 ID、库、表，同名对象不会跨连接混淆。结构缓存与工具栏选择器共享；展开/折叠只增删当前节点的记录，不替换其他分支状态。

连接全部放在所属文件夹节点下，旧数据缺少 group 或空分组时归入“默认分组”，自定义分组保持原值。分组内连接右键仍支持编辑，可更换连接配置及分组。分组 key 为独立的 group/名称，不冒充连接 ID；分组展开/收起不请求数据库、不修改查询范围、不关闭连接。搜索同时匹配分组名，并临时展开分组显示匹配内容；清空搜索恢复原折叠状态。分组展开状态随原有加密布局保存，新建或移动连接不自动展开分组。

连接根节点使用 20px 所属引擎的官方品牌图标，成功加载结构后状态圆点为 success，未成功打开、已关闭或失败时圆点为灰色；折叠不会置灰，只有关闭才释放打开状态。库和表图标始终使用正常正文色，不按结构加载状态置灰。未选中节点文字使用主题正文色，暗色下为白色，亮色下使用深色，不因已加载而变蓝；选中仍使用 primary 背景及反色文字。图标与文本间距为 8px。失败显示原因。关闭后隐藏子项，重新展开会重新加载。搜索匹配连接名和已加载的库表，未加载连接仍保留供展开；长名称省略并提供完整 title。

连接右键依次提供打开/关闭、新建数据库、编辑、删除，“刷新”位于菜单最底部；加载中可关闭以取消请求。数据库右键提供新建查询、查看表列表、刷新结构；表/视图提供新建查询、查询数据、查询结构、查看 DDL。菜单均有图标，携带完整原始连接/库/表范围，停止冒泡；不依赖先点击选中，执行期间禁用。

树体独立滚动，选中态及 hover 使用 Ant Design 原生 primary/controlItemBgHover token。

双击通过原生 Tree expandAction=doubleClick 与箭头共用展开、loadData 和加载状态；表可展开字段和索引，视图保持叶节点。图标容器统一 flex 居中，连接图标外层也使用 flex，覆盖原生 inline-block 的基线偏移；图标和文字在最小 28px 的选中背景内垂直居中，上下各留 2px，节点不额外加 padding-block；覆盖原生 margin-bottom 为 2px，行距约 30px。

异步展开时，加载指示显示在展开箭头区域；隐藏 Tree 在 `showIcon=false` 时额外插入的加载图标占位，节点图标和文字保持位置不变。

双击展开数据库时打开结构页：PostgreSQL 展示 schema 列表（包含空 schema），MySQL 展示表列表；双击展开 PostgreSQL schema 展示该 schema 的表和视图。数据库右键相应显示“查看 Schema 列表”或“查看表列表”。双击展开表时打开数据页。按连接、库、schema、表和页面类型匹配已有标签，存在则切换并刷新，否则新建；表数据未保存时先确认。双击折叠时只收起节点，不打开页面；视图是叶节点，双击仍打开数据。箭头只控制子项，不创建页面。

树节点文字禁止浏览器选择，双击仅执行展开/收起，不产生文本高亮。连接关闭时子节点的选中高亮随节点隐藏失效；查询范围只按连接关闭后的有效性清理，不参与树的日常选择。SQL 编辑器、结果和历史 SQL 仍可正常选择复制。

连接节点的 loadData 调用工作区 openConnection，和右键打开共用元数据生命周期；打开、折叠或选择树节点均不修改查询范围。

折叠按钮使用与内容块一致的最小 28px 高度，图标通过 flex 垂直居中；按钮始终透明，移除原生 hover 背景伪元素，不影响节点内容的选中或悬停背景。

explorer/updateExplorer 由工作区受控，保存 expanded/selected/search/top，并随本地加密快照恢复。恢复只加载已打开连接及展开库的元数据；切换查询范围不会改树的选中和展开状态。

成功刷新连接或重读库列表后，工作区移除已不存在库及后代的展开/选中记录；同名库重建后保持收起，其他连接和仍存在库的展开状态保留。刷新失败不清理布局。

折叠箭头区域宽 20px、右侧 margin 为 0，节点内容保留左右 8px 内边距，让选中背景不贴住图标；保留原有层级缩进、28px 点击高度，图标到文字为 4px。

库和表右键打开菜单时更新对象树选中高亮，不改变查询页范围。库增加编辑/新建/删除、新建表，表增加设计/新建/删除/清空/重命名/刷新，转储 SQL 文件子菜单目前仅结构。空库可从库菜单新建表，无库时可从已打开连接菜单新建数据库。视图不提供表字段设计和清空，删除按视图处理。所有回调携带节点的原始连接与库表名。

库菜单刷新文案统一为“刷新”；库、表、连接的右键目标覆盖图标、文字与行内空白，左键仍保留原生展开行为。

转储子菜单增加“结构和数据”，视图禁用该项。

表箭头首次展开时调用 loadTableDetails，仅查询字段与索引元数据；折叠再展开复用会话缓存。字段按定义顺序显示，主键使用钥匙图标；索引按名称展示，悬停说明类型、唯一性、组成字段、前缀和降序。表达式字段仅标记“表达式”。无表/字段/索引有明确空态，失败显示原因和重试按钮。表分类右键复用新建表、查看表列表及刷新。双击表仍打开数据，箭头不会打开数据页；字段/索引仅供浏览，不触发 SQL 或索引修改。所有新节点 key 都包含完整原始连接、库、表和对象名，展开/选中沿用工作区保存。

数据库菜单增加关闭数据库，关闭后显示打开数据库。关闭是带保存确认和后端释放确认的完整操作；箭头折叠仍只控制布局。查询运行中右键仅保留关闭项，其他操作禁用。

树采用原生虚拟滚动，ResizeObserver 提供视口高度；按展开层级生成纯数据，titleRender 仅渲染可见行，右键时才生成菜单。节点数据按连接、元数据、展开和搜索缓存，SQL 编辑、选中及滚动不会重建万表节点。滚动结束 150ms 后保存一次位置，首次加载等待元数据恢复后再定位；主题、伸缩、查询范围与菜单行为保持一致。

Tree 与视口 ref 使用 ExplorerNode 泛型。titleRender 直接消费 Tree 传入的节点快照；折叠动画仍保留旧子节点时，当前 byKey 已可能裁剪它们，不能再次通过 byKey 取标题或回退显示内部 key。名称、图标及 tooltip 在收起动画期间保持完整，操作目标仍从当前 byKey 校验。

Tree 显式设置 motionAppear/motionEnter/motionLeave=false，展开和折叠直接更新可见行（Ant Design 会将 null 回退为默认动画，不能用 motion=null 禁用）。按展开状态裁剪后代数据会同步移除原生树的层级索引，关闭过渡可避免离场节点缩进归零、先跳到最左侧再消失；保留虚拟滚动与按需加载。

右键菜单按所属连接适配器能力显示操作，隐藏未实现的数据转储。PostgreSQL 支持建库、删库、删表或视图、清空表和重命名；schema、表分类及表节点支持新建表，表节点支持设计表字段。表名保留完整双引号 schema/table 标识。

PostgreSQL 新增 schema 文件夹层：连接 → 数据库 → schema → 表/视图 → 对象 → 字段/索引。schema/类别只展开本地元数据，不切换查询范围、不发送表数据 SQL。表标题省略所属 schema，菜单和详情仍以原始完整表身份操作；schema 内分类不提供指向整个数据库的菜单。

schema 节点双击/菜单可打开仅此 schema 的结构列表或新建带该 schema 范围的查询；schema 内表分类菜单指向所属 schema。表菜单和详情始终保留完整标识。

PostgreSQL 数据库及 schema 右键可新建 Schema；schema 右键可重命名或删除。删除要求输入名称并使用 RESTRICT，仅允许删除空 Schema。相关表设计页或未保存表格修改须先保存或关闭。

数据库菜单按 databaseEditor 能力显示编辑数据库；PostgreSQL 可编辑所有者、连接数上限和注释，库名/编码/排序规则只读。表的转储子菜单按 dataDump 能力显示结构和数据；MySQL 与 PostgreSQL 均支持，视图仍禁用数据项，执行入口独立复核能力。
