## 参数与回调

model 通过 Pick 消费 connections、objects、running，以及 connectionAction、openConnection、databaseAction、tableAction 和 openExplorerPage；不消费查询标签的连接/库/表或选择回调。onOpenDatabaseSection(section, scope) 使用右键节点原始连接 ID 进入监控或同步页面。

## 行为与边界

空白处右键提供“新建分组”；分组右键提供“新建分组”“重命名分组”和“删除分组”，内置默认分组禁用重命名和删除；连接右键提供“移动到分组”子菜单，当前归属禁用。分组来自 connectionGroups 共享列表，空分组也展示并由后端独立保存。重命名同步更新成员连接、展开记录以及新建/编辑连接的分组选项；移动不关闭连接、不重置查询范围、不自动展开目标分组。保存失败保留原状态。

一棵树按引擎层次展示对象；MySQL 和 MariaDB 为连接 → 数据库 → 表分类 → 表 → 字段/索引，PostgreSQL 在数据库与分类之间增加 schema。原有视图放入独立视图分类，不增加新的对象能力。无保存布局时连接全部收起，有记录时恢复展开状态，点击箭头或双击连接/数据库节点加载、展开或收起子列表，单击文本只更新对象树独立的选中高亮，不改变右侧查询下拉框；右侧切换范围或查询标签同样不改变树高亮。节点 key 包含节点类型、连接 ID、库、表，同名对象不会跨连接混淆。结构缓存与工具栏选择器共享；展开/折叠只增删当前节点的记录，不替换其他分支状态。

连接全部放在所属文件夹节点下，连接分组为空时使用“默认分组”，自定义分组保持原值。分组内连接右键仍支持编辑，可更换连接配置及分组。分组 key 为独立的 group/名称，不冒充连接 ID；分组展开/收起不请求数据库、不修改查询范围、不关闭连接。搜索同时匹配分组名，并临时展开分组显示匹配内容；清空搜索恢复原折叠状态。分组展开状态随工作区索引保存，新建或移动连接不自动展开分组。

默认分组在节点标题、悬停和“移动到分组”菜单中使用当前语言，英文显示 Default group；搜索同时匹配原名称及显示标签。原始 key 和菜单目标值保持不变，自定义名称不翻译。默认分组作为未分组连接及删除其他分组后的归属，禁止删除和重命名。

连接根节点使用 20px 所属引擎图标，成功加载结构后为绿色底板与白色图形，未成功打开、已关闭或失败时为灰色底板与白色图形；折叠不会置灰，只有关闭才释放打开状态。数据库使用实心图标区分独立状态：未打开与未连接引擎图标底板共用 --inactive-icon（text-tertiary）单色灰色、打开中为 primary、成功为 success 绿色、失败为 error；悬停显示状态与实际错误。仅加载数据库名称不会把所有库置为已打开，成功加载空库同样绿色，折叠保持已打开状态。表图标仍使用正常正文色。未选中节点文字使用主题正文色，暗色下为白色，亮色下使用深色，不因已加载而变蓝；选中使用 controlItemBgActive 较深灰色背景和主题正文色，悬停和键盘聚焦时保持同一底色。图标与文本间距为 8px。失败显示原因。关闭后隐藏子项，重新展开会重新加载。搜索匹配连接名和已加载库表，未加载连接仍保留供展开；长名称省略并提供完整 title。

连接右键依次提供新建数据库、打开/关闭、监控指标、同步数据库、编辑、移动到分组、删除，“刷新”位于菜单最底部；加载中可关闭以取消请求。数据库右键提供新建查询、查看表列表、刷新结构；表/视图提供新建查询、查询数据、查询结构、查看 DDL。菜单均有图标，携带完整原始连接/库/表范围，停止冒泡；不依赖先点击选中，执行期间禁用。

连接失败节点同时提供“打开连接”和“关闭连接”：前者手动重试，后者复用范围关闭流程取消请求、清理错误及展开状态。数据库服务离线也可调用关闭接口；关闭不删除连接配置，现有草稿确认和关闭失败保留窗口规则不变。

失败连接在 Tree 的 loadedKeys 中表示本次加载已结束，阻止受控展开状态自动重复调用 loadData；这不表示连接成功，图标及功能权限仍依据 error/connected 状态。

树体独立滚动，选中态及 hover 使用 Ant Design 原生 primary/controlItemBgHover token。

双击通过原生 Tree expandAction=doubleClick 与箭头共用展开、loadData 和加载状态；表可展开字段、索引及支持引擎的外键，视图保持叶节点。图标容器统一 flex 居中，连接图标外层也使用 flex，覆盖原生 inline-block 的基线偏移；图标和文字在最小 28px 的选中背景内垂直居中，上下各留 2px，节点不额外加 padding-block；覆盖原生 margin-bottom 为 2px，行距约 30px。

异步展开时，加载指示显示在展开箭头区域；隐藏 Tree 在 `showIcon=false` 时额外插入的加载图标占位，节点图标和文字保持位置不变。

数据库层双击只展开或折叠，首次展开按原有流程加载子项元数据，不打开、切换或刷新结构页。数据库右键相应提供“查看 Schema 列表”（PostgreSQL，包含空 schema）或“查看表列表”（MySQL）。双击展开 PostgreSQL schema 展示该 schema 的表和视图；双击展开表时打开数据页。页面按连接、库、schema、表和类型匹配已有标签，存在则切换并刷新，否则新建；表数据未保存时先确认。双击折叠时只收起节点，不打开页面；视图是叶节点，双击仍打开数据。箭头只控制子项，不创建页面。

“表 / 视图 / 字段 / 索引 / 外键”等分类层双击只通过 Tree 的 expandAction 展开或折叠，不打开、切换或刷新页面，也不触发数据查询。页面操作回调仅接受 schema/table 节点；数据库及分类的右键入口保持独立。

树节点文字禁止浏览器选择，双击仅执行展开/收起，不产生文本高亮。连接关闭时子节点的选中高亮随节点隐藏失效；查询范围只按连接关闭后的有效性清理，不参与树的日常选择。SQL 编辑器、结果和历史 SQL 仍可正常选择复制。

连接节点的 loadData 调用工作区 openConnection，和右键打开共用元数据生命周期；打开、折叠或选择树节点均不修改查询范围。

折叠按钮使用与内容块一致的最小 28px 高度，图标通过 flex 垂直居中；按钮始终透明，移除原生 hover 背景伪元素，不影响节点内容的选中或悬停背景。

explorer/updateExplorer 由工作区受控，保存 expanded/selected/search/top，并随工作区索引恢复。恢复只加载已打开连接及展开库的元数据；切换查询范围不会改树的选中和展开状态。

成功刷新连接或重读库列表后，工作区移除已不存在库及后代的展开/选中记录；同名库重建后保持收起，其他连接和仍存在库的展开状态保留。刷新失败不清理布局。

折叠箭头区域宽 20px、右侧 margin 为 0，节点内容保留左右 8px 内边距，让选中背景不贴住图标；保留原有层级缩进、28px 点击高度，图标到文字为 4px。

库和表右键打开菜单时更新对象树选中高亮，不改变查询页范围。库增加编辑/新建/删除、新建表，表增加设计/新建/删除/清空/重命名/刷新，转储菜单提供“仅结构”和“结构和数据”，视图仅支持结构。空库可从库菜单新建表，无库时可从已打开连接菜单新建数据库。视图不提供表字段设计和清空，删除按视图处理。所有回调携带节点的原始连接与库表名。

库菜单刷新文案统一为“刷新”；库、表、连接的右键目标覆盖图标、文字与行内空白，左键仍保留原生展开行为。

表箭头首次展开时调用 loadTableDetails，仅查询字段、索引和外键元数据；折叠再展开复用会话缓存。字段按定义顺序显示，主键使用钥匙图标；索引按名称展示，悬停说明类型、唯一性、组成字段、前缀和降序。表达式字段仅标记“表达式”。MySQL、MariaDB、PostgreSQL／PolarDB 表按约束名列出外键，悬停展示有序列映射、引用表以及更新和删除规则。无表/字段/索引/外键有明确空态，失败显示原因和重试按钮。表分类右键复用新建表、查看表列表及刷新。双击表仍打开数据，箭头不会打开数据页；字段/索引/外键仅供浏览，不触发 SQL 或索引修改。所有新节点 key 都包含完整原始连接、库、表和对象名，展开/选中沿用工作区保存。

数据库菜单增加关闭数据库，关闭后显示打开数据库。关闭是带保存确认和后端释放确认的完整操作；箭头折叠仍只控制布局。查询运行中右键仅保留关闭项，其他操作禁用。

树采用原生虚拟滚动，ResizeObserver 提供视口高度；按展开层级生成纯数据，titleRender 仅渲染可见行，右键时才生成菜单。节点数据按连接、元数据、展开和搜索缓存，SQL 编辑、选中及滚动不会重建万表节点。滚动结束 150ms 后保存一次位置，首次加载等待元数据恢复后再定位；主题、伸缩、查询范围与菜单行为保持一致。

Tree 与视口 ref 使用 ExplorerNode 泛型。titleRender 直接消费 Tree 传入的节点快照；折叠动画仍保留旧子节点时，当前 byKey 已可能裁剪它们，不能再次通过 byKey 取标题或回退显示内部 key。名称、图标及 tooltip 在收起动画期间保持完整，操作目标仍从当前 byKey 校验。

Tree 显式设置 motionAppear/motionEnter/motionLeave=false，展开和折叠直接更新可见行（Ant Design 会将 null 回退为默认动画，不能用 motion=null 禁用）。按展开状态裁剪后代数据会同步移除原生树的层级索引，关闭过渡可避免离场节点缩进归零、先跳到最左侧再消失；保留虚拟滚动与按需加载。

右键菜单按所属连接适配器能力提供对象操作。PostgreSQL 支持建库、删库、删表或视图、清空表和重命名；schema、表分类及表节点支持新建表，表节点支持设计表字段。表名保留完整双引号 schema/table 标识。

PostgreSQL 新增 schema 文件夹层：连接 → 数据库 → schema → 表/视图 → 对象 → 字段/索引/外键。schema/类别只展开本地元数据，不切换查询范围、不发送表数据 SQL。表标题省略所属 schema，菜单和详情仍以原始完整表身份操作；schema 内分类不提供指向整个数据库的菜单。

schema 节点双击/菜单可打开仅此 schema 的结构列表或新建带该 schema 范围的查询；schema 内表分类菜单指向所属 schema。表菜单和详情始终保留完整标识。

PostgreSQL 数据库及 schema 右键可新建 Schema；schema 右键可重命名或删除。删除要求输入名称并使用 RESTRICT，仅允许删除空 Schema。相关表设计页或未保存表格修改须先保存或关闭。

数据库菜单按 databaseEditor 能力显示编辑数据库；PostgreSQL 可编辑所有者、连接数上限和注释，库名/编码/排序规则只读。MySQL、MariaDB 和 PostgreSQL 的表均可转储结构和数据，执行入口复核引擎能力。

数据库和 Schema 右键提供“转储文件 → 仅结构 / 结构和数据”，与表转储共用独立进度弹框；目标来自节点，不推断当前查询范围。

连接未打开、加载中、连接失败或目标数据库已关闭时，数据库、Schema 和表的转储菜单禁用；仅折叠树节点不影响导出。执行入口在打开保存文件选择器前再次检查目标连接及数据库状态。

转储菜单与实际入口共用 exportAvailability：连接及目标库表列表成功加载（包括空库），且无加载中/错误/关闭状态时才允许转储。仅列出库名时显示“打开数据库”并禁用转储；折叠已打开节点不撤销状态。

菜单内容与 open 分开受控；关闭时保留内容至原生离场完成，右键切换目标只替换菜单，显示由 Dropdown onOpenChange 管理。空白处与节点共用同一入口，不在 capture 阶段先清空菜单；菜单点击停止冒泡并关闭，避免先右键分组再从空白处新建时闪烁。

界面占用时 Tree 沿用原生 disabled 行为，右键关闭能力继续由原有工作区策略控制。不在树上方插入执行、弹窗或加载占用说明，避免频繁操作造成节点跳动；SQL 执行状态由右侧执行区展示。

选中节点的背景比普通悬停更明显。

节点加载失败时的重试入口使用 small ToolbarButton 刷新图标，保留“重试加载”提示和可访问名称；点击阻止冒泡，不改变节点选择或展开。

空态图标复用公共 EmptyStateIcon。搜索框伸缩与 Tree 的 root/itemTitle 布局通过 style/styles 提供，节点交互覆盖保留在 app.scss。

选中节点的灰色底衬托原有图标，实心数据库图标始终保留状态色和 aria-label。
