# 页面结果展示

[组件索引](../README.md) · [源码](index.tsx)

QueryResults 接收 model（当前页 run/result、连接信息、运行状态、筛选、分页、结果索引与高度及其回调）和 themeMode:ThemeMode。没有 run 返回 null。query 页输出与编辑器上下共存且可拖动高度，data/structure/ddl 页输出铺满可用区域。

结果工具栏的新增行、删除行、保存、放弃修改、刷新/重新执行、取消和导出 CSV 统一使用 [ToolbarButton](../toolbarButton/README.md) 仅图标按钮，默认无边框；功能名称通过 Tooltip 和 aria-label 提供，保留原生悬停、键盘焦点、禁用、加载及危险语义。筛选输入框继续保留原生边框。

工具栏左侧的编辑操作以 4px 间距排列；右侧先显示筛选框，再显示刷新/取消/导出图标组。筛选框与图标组间距 8px，图标间距 4px，图标组不收缩；窄屏筛选框可收缩，必要时由工具栏整体换行，保持操作区靠右。

[输出导航](../resultTabs/README.md) 将“消息 / 摘要 / 结果 1 / 结果 2……”置于一层，结果项不再内嵌 SQL 标签；当前语句有数据列时展示该结果；成功无列回执默认展示摘要，失败/取消或执行中无数据时展示消息。只有数据集生成结果标签，超过 8 个时用下拉选择全部结果。消息/摘要视图选择只归属当前页面的当前输出版本；重新运行或刷新产生新输出时，旧选择立即失效，按当前语句的数据/回执/错误状态选择默认视图。结果索引仍由 selectResult 控制并加密保存。查看消息/摘要不修改结果索引或筛选分页；选择另一条结果调用 selectResult 重置筛选分页。

[消息](../queryMessages/README.md) 按实际执行顺序列出 SQL、状态和耗时；[摘要](../querySummary/README.md) 汇总成功/失败数量、起止时间及运行时间，支持仅显示错误。二者的执行 SQL 经 [sqlPreview](../sqlPreview/README.md) 只读高亮和复制，不用编辑器草稿冒充。旧记录缺少 SQL 或耗时时明确提示未记录。

消息组件按主页面ID隔离：执行中默认随新增回执滚到底部，手动阅读/翻页暂停，回到底部恢复；内容高度及面板尺寸变化仍保持当前跟随意图。切页及切换摘要/数据视图会清理消息滚动监听，数据表格继续沿用自身回到顶部的规则。

结果视图保留查询耗时、筛选、CSV、错误与空结果说明。Table 使用原生 small，字段名和类型垂直展示，NULL 使用次级文字 (NULL)，二维数组按列索引保留重复列和大整数文本；结构列表按类型显示对象图标。useTableViewportLayout 分配表体高度，表体双向滚动，外部分页每页 50 行，固定在表体外并复用 tablePaginationDefaults。CSV 导出全部筛选行。翻页、筛选和结果更新回到表体顶部，切换视图重测高度。

错误说明使用继承 Ant Design 默认 UI 字体的普通文本容器，保留原始换行并允许长文本换行；不使用 pre/code，避免浏览器默认等宽字体及额外段落边距。

字段类型按接口原文显示，不强制转换大小写；类型和 NULL 通过 Typography.Text 的 secondary 语义展示，不单独设置字体、字号或字重。

重复执行替换本批输出，失败/取消保留已完成结果。interrupted 提示刷新中断；恢复不自动执行 SQL。执行中对象页保留取消按钮，查询页取消按钮归编辑器工具栏。主页面状态色始终跟随工作区选中结果，消息/摘要切换不影响它。

DDL 页和普通查询中的 SQL 定义/语句列通过 DatabaseAdapter.isSQLColumn 识别，统一使用 SQLPreview compact 高亮并提供同排复制图标，保留完整换行和定义，不进入普通单元格省略样式。覆盖 SHOW CREATE TABLE/VIEW/DATABASE/PROCEDURE/FUNCTION/TRIGGER/EVENT、SHOW TRIGGERS、information_schema 定义列及 SQL 语句记录列，具体列名见引擎 resultSQL 模块。普通查询 SQL 列宽 520px；所有 SQL 文本按内容完整展开并自动换行，不限高、不显示内部滚动条，长结果只由外层表体滚动。复制、筛选和 CSV 导出均使用完整原始值；NULL、空值和普通字段保留原展示，数据页仍可双击编辑。

data 页面支持双击单元格，由 [useDataEditing](../../hooks/useDataEditing/README.md) 加载元数据并使用 [dataCellEditor](../dataCellEditor/README.md) 编辑。保存显式写入且重读结果；普通 SQL 结果、视图、无主键表以及不支持字段保持只读。

结果加载和保存刷新提示均使用 ContentLoading。保存刷新期间通过 app.scss 的结果区遮罩盖住旧表格，保留滚动布局。

数据页顶部统一保存所有暂存修改或放弃修改；已改单元格由 data-cell-dirty 类名标记，主题警告背景集中在 app.scss，输入区不再展示独立保存按钮。

保存期间直到服务端数据刷新完成，结果数据区域显示不透明主题背景的 loading 遮罩，暂时隐藏表格但保留其布局与滚动测量，避免逐项清理暂存后闪回旧值；同时阻止操作旧单元格。遮罩直接跟随 useDataEditing.saving，成功或失败的 finally 结束后解除，失败仍沿用原有部分成功及剩余草稿语义，不人为延时。

保存/放弃修改采用 SaveOutlined/UndoOutlined 图标，保存文字不显示计数；点击编辑区域外部恢复文本并保留暂存。

顶部新增行按钮将待插入行显示在第一页最前方，单元格默认显示“(默认)”，双击输入。行号列叉号可移除尚未保存的新行，顶部保存统一提交，放弃修改同时清空新增行。

新增行改为常驻 newRowCell 表单，输入与默认值/指定值/NULL 下拉并列管理；不再渲染 undefined 文本或要求双击。

结果工具栏增加刷新：同页刷新当前查询结果/表数据/结构/DDL；未保存修改时禁用，防止覆盖暂存。

结果工具栏不显示查询耗时；执行耗时仍保留在消息、摘要及历史记录中。

没有结果列的成功响应在消息/摘要显示实际影响行数，不增加结果标签或结果工具栏。摘要每页 50 条且保留全部记录。以 columns.length 判断展示，兼容旧 isQuery=true 但无列的记录；SELECT 有列但零行仍保留表头和查询空态。

所有结果页提供行复选框；数据页另提供“删除行”，跨分页选择同一结果，新增行不参与。结果版本变化立即清空选择，存在暂存时禁用删除；删除通过 useDataEditing 显式确认和完整主键定位，不影响普通 SQL 结果。

缓存当前结果行及筛选结果，输入SQL、滚动和保存状态变化不重复复制所有单元格；筛选使用延后更新避免阻塞输入。查询消息/摘要视图不构建数据行。CSV仍导出全部筛选结果，行序号、跨页勾选和暂存值语义保留。

结果展示通过resultRows按页映射：未搜索时不创建全量行对象或下标，搜索仅缓存匹配下标，翻页复用；每次只为当前50行生成展示对象。CSV通过原始/暂存行导出全部匹配结果，不受当前页限制。

结果 Table 启用 Ant Design 原生 virtual：保留每页 50 行，在页内只挂载视口附近的行，滚出视口的 SQL 预览及编辑控件随行卸载。行高由原生虚拟列表实际测量，保留长 SQL 全文换行、新增行和单元格编辑的自适应高度，不增加单元格内部滚动条。横纵 scroll 使用数值尺寸，固定行号、复选框与表头共用列宽；DDL 未指定宽度的列自动铺满容器。

翻页、筛选、结果或视图切换通过 useResultTableScroll 调用 Table ref.scrollTo 回到顶部，避免依赖普通表格的 ant-table-body DOM。暂存值和跨页选择仍保存在数据状态中，行卸载不丢失修改。结果截断提示在视口外分配高度，避免压住虚拟表体的底部滚动条。

全部数据结果提供复选框和 CSV 下拉：导出全部包含当前筛选/排序下全部已加载行及新增草稿，导出选中仅包含跨页勾选的现有行，零选择时禁用。列头支持升序、降序和取消；排序在全部已加载匹配行上进行后再分页，不向数据库追加 ORDER BY，编辑和勾选始终使用原始 key。数值保留 BIGINT/DECIMAL 精度。

新增和保存刷新均回到第一页，useResultTableScroll 在虚拟行高测量后再次定位，避免输入被表头遮挡及保存后跳底部。新增草稿按最新在前排列；截断提示在表体外分配高度。

排序使用当前返回结果的原始值，暂存编辑不会让正在输入的行移动；导出仍包含暂存值并保持显示顺序。

query 页的刷新按钮显示“重新执行”，悬停明确写语句也会再次执行；保持 SQL 窗口 DDL/DML 能力和既有范围，不增加写入确认。

空态图标复用公共 EmptyStateIcon，统一主题色与尺寸。
