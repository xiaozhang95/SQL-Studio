# 页面结果展示

界面固定文案通过共享 useTranslation 跟随已保存语言切换；SQL、用户输入和数据库返回内容按原文展示。

语句错误随本批输出在消息和摘要中显示。执行期间的连接、请求或批次错误，以及新增或保存数据失败，由当前标签登记到顶部。数据行删除失败在弹框内展示处理结果与失败原因。

[组件索引](../README.md) · [源码](index.tsx)

QueryResults 接收 model（当前页 run/result、连接信息、运行状态、筛选、结果索引与高度及其回调）和 themeMode:ThemeMode。没有 run 返回 null。query 页输出与编辑器上下共存且可拖动高度，data/structure/ddl 页输出铺满可用区域。结果页签右侧展示成功/失败、耗时、行数和列数；执行中显示 Spinner 和「执行中」，失败只显示失败状态。

结果工具栏的新增行、删除行、保存、放弃修改、刷新/重新执行、取消和导出统一使用 [ToolbarButton](../toolbarButton/README.md) 仅图标按钮，默认无边框；功能名称通过 Tooltip 和 aria-label 提供，保留原生悬停、键盘焦点、禁用、加载及危险语义。筛选输入框保留原生边框。

工具栏左侧的编辑操作以 4px 间距排列；右侧先显示筛选框，再显示刷新/取消/导出图标组。筛选框与图标组间距 8px，图标间距 4px，图标组不收缩；窄屏筛选框可收缩，必要时由工具栏整体换行，保持操作区靠右。

[输出导航](../resultTabs/README.md) 将“消息 / 摘要 / 结果 1 / 结果 2……”置于一层，右侧同排展示成功/失败、耗时、行数和列数，结果项不再内嵌 SQL 标签；当前语句有数据列时展示该结果；成功无列回执默认展示摘要，失败/取消或执行中无数据时展示消息。只有数据集生成结果标签，超过 8 个时用下拉选择全部结果。消息/摘要视图选择只归属当前页面的当前输出版本；重新运行或刷新产生新输出时，旧选择立即失效，按当前语句的数据/回执/错误状态选择默认视图。结果索引仍由 selectResult 控制并随工作区索引保存。查看消息/摘要不修改结果索引或筛选；选择另一条结果调用 selectResult 重置筛选。

[消息](../queryMessages/README.md) 按实际执行顺序列出 SQL、状态和耗时；[摘要](../querySummary/README.md) 汇总成功/失败数量、起止时间及运行时间，支持仅显示错误。二者的执行 SQL 经 [sqlPreview](../sqlPreview/README.md) 只读高亮和复制，不用编辑器草稿冒充。旧记录缺少 SQL 或耗时时明确提示未记录。

消息组件按主页面ID隔离：执行中默认随新增回执滚到底部，手动阅读/翻页暂停，回到底部恢复；内容高度及面板尺寸变化仍保持当前跟随意图。切页及切换摘要/数据视图会清理消息滚动监听，数据表格继续沿用自身回到顶部的规则。

结果视图提供筛选、[结果导出弹框](../resultExport/README.md)、错误与空结果说明。查询耗时显示在输出页签右侧、消息、摘要和历史中。数据表使用 30px 行高、吸顶表头和水平分隔线；字段名和类型垂直展示，NULL 使用次级文字 (NULL)，二维数组按列索引保留重复列和大整数文本。useTableViewportLayout 分配表体高度，表体双向滚动，虚拟滚动浏览全部已返回的行，底部显示条数。导出弹框可选 CSV、Excel 或 JSON，范围为已加载的筛选结果或选中行。筛选和结果更新回到表体顶部，切换视图重测高度。

表头的字段名和类型各占一行，超出列宽时显示省略号，悬停可查看原文。排序说明在排序图标上显示。类型按接口原文显示，和 NULL 一起使用 Typography.Text 的 secondary 语义。

达到行数或内容上限时，在结果区域提示截断原因。首行超过内容上限时，显示独立的只读字段文本预览，并禁用筛选、编辑和导出。

重复执行替换本批输出，失败/取消保留已完成结果。interrupted 提示刷新中断；恢复不自动执行 SQL。执行中对象页保留取消按钮，查询页取消按钮归编辑器工具栏。主页面状态色始终跟随工作区选中结果，消息/摘要切换不影响它。

DDL 页和普通查询中的 SQL 定义/语句列通过 DatabaseAdapter.isSQLColumn 识别，统一使用 SQLPreview compact 高亮并提供同排复制图标，保留完整换行和定义，不进入普通单元格省略样式。覆盖 SHOW CREATE TABLE/VIEW/DATABASE/PROCEDURE/FUNCTION/TRIGGER/EVENT、SHOW TRIGGERS、information_schema 定义列及 SQL 语句记录列，具体列名见引擎 resultSQL 模块。普通查询 SQL 列宽 520px；所有 SQL 文本按内容完整展开并自动换行，不限高、不显示内部滚动条，长结果只由外层表体滚动。复制、筛选和 CSV 导出均使用完整原始值；NULL、空值和普通字段保留原展示，数据页仍可双击编辑。

数据页由 [useDataEditing](../../hooks/useDataEditing/README.md) 加载元数据，支持在基础表上双击单元格，使用 [dataCellEditor](../dataCellEditor/README.md) 编辑支持的字段。有主键时按完整主键及原值匹配，无主键时按原始整行匹配。保存时显式写入并重读结果。

结果加载和保存刷新提示均使用 ContentLoading。保存刷新期间通过 app.scss 的结果区遮罩盖住旧表格，保留滚动布局。

数据页顶部统一保存所有暂存修改或放弃修改；已改单元格由 data-cell-dirty 类名标记，主题警告背景集中在 app.scss，输入区不再展示独立保存按钮。

保存期间直到服务端数据刷新完成，结果数据区域显示不透明主题背景的 loading 遮罩，暂时隐藏表格但保留其布局与滚动测量，避免逐项清理暂存后闪回旧值；同时阻止操作旧单元格。遮罩直接跟随 useDataEditing.saving，成功或失败的 finally 结束后解除，失败仍沿用原有部分成功及剩余草稿语义，不人为延时。

保存/放弃修改采用 SaveOutlined/UndoOutlined 图标，保存文字不显示计数；点击编辑区域外部恢复文本并保留暂存。

新增行显示在结果最前方，使用常驻 newRowCell 表单，输入与默认值/指定值/NULL 下拉并列管理。行号列可移除尚未保存的新行，顶部保存统一提交，放弃修改同时清空新增行。

结果工具栏增加刷新：同页刷新当前查询结果/表数据/结构/DDL；未保存修改时禁用，防止覆盖暂存。

没有结果列的成功响应在消息/摘要显示实际影响行数，不增加结果标签或结果工具栏。摘要每页 50 条且保留全部记录。以 columns.length 判断展示，兼容旧 isQuery=true 但无列的记录；SELECT 有列但零行仍保留表头和查询空态。

所有结果页提供行复选框，数据页可滚动选择同一结果的现有行。结果版本变化立即清空选择，存在暂存时禁用删除。删除弹框显示库表名和选中行数，绑定当前页面、结果版本和所选行。确认后按完整主键定位，无主键时匹配原始整行。完全相同的记录每选中一条删除一条。提交前失败时显示原因，发出请求后失败时附带已确认删除数及刷新核对提示。

缓存当前结果行及筛选结果，输入SQL、滚动和保存状态变化不重复复制所有单元格；筛选使用延后更新避免阻塞输入。查询消息/摘要视图不构建数据行。CSV仍导出全部筛选结果，滚动时保留行序号、勾选和暂存值。

结果行用 resultTableRows 按筛选与排序映射，保留原始行键及单元格引用。虚拟表仅挂载可见区域附近的行。导出可以覆盖整个已加载筛选结果或选中行。

结果 Table 启用 Ant Design 原生 virtual：全部已返回行均可滚动访问，只挂载视口附近的行，滚出视口的 SQL 预览及编辑控件随行卸载。行高由原生虚拟列表实际测量，保留长 SQL 全文换行、新增行和单元格编辑的自适应高度，不增加单元格内部滚动条。横纵 scroll 使用数值尺寸，固定行号、复选框与表头共用列宽；DDL 未指定宽度的列自动铺满容器。

筛选、结果或视图切换通过 useResultTableScroll 调用 Table ref.scrollTo 回到顶部，避免依赖普通表格的 ant-table-body DOM。暂存值和滚动前后的选择仍保存在数据状态中，行卸载不丢失修改。结果截断提示在视口外分配高度，避免压住虚拟表体的底部滚动条。

全部数据结果提供复选框和 CSV 下拉：导出全部包含当前筛选/排序下全部已加载行及新增草稿，导出选中仅包含勾选的现有行，零选择时禁用。列头支持升序、降序和取消；排序作用于全部已加载的匹配行，不向数据库追加 ORDER BY，编辑和勾选始终使用原始 key。数值保留 BIGINT/DECIMAL 精度。

新增和保存刷新均回到表体顶部，useResultTableScroll 在虚拟行高测量后再次定位，避免输入被表头遮挡及保存后跳底部。新增草稿按最新在前排列；截断提示在表体外分配高度。

排序使用当前返回结果的原始值，暂存编辑不会让正在输入的行移动；导出仍包含暂存值并保持显示顺序。

query 页的刷新按钮显示“重新执行”，悬停明确写语句也会再次执行；保持 SQL 窗口 DDL/DML 能力和既有范围，不增加写入确认。

查询页结果工具栏左侧显示「已选择 N 行」，筛选框宽 160px，右侧提供重新执行、取消执行和导出按钮。结果表按字段类型分配列宽并由最后一列伸展；NULL 使用浅色斜体，数字列右对齐并使用等宽数字，表头和表体字号随界面字号偏好缩放。

空态图标复用公共 EmptyStateIcon，统一主题色与尺寸；无结果时提供「新建查询」主操作和「从左侧选择表」提示。
