# 转储进度弹框

DataExport({model}) 接收 useDataExport 返回值。以 Ant Design Modal/Descriptions/Progress 展示连接、数据库、文件名、内容、对象/记录计数、字节、错误、耗时和自动滚动日志。摘要默认左右两列，窄窗口（xs）自动单列；亮暗主题继承 token，长名称换行。运行时只能取消；完成/失败/取消后关闭，关闭不执行 SQL、不切换主页面；进度按对象计算，记录为实时计数。没有完整路径时显示浏览器提供的文件名。

内容区按视口限制高度并仅纵向滚动，长名称或窄窗口下仍保留底部取消/关闭按钮。

取消后隐藏进度条及百分比，保留取消日志与关闭按钮；运行、成功及失败状态继续显示相应进度。

常规操作按钮使用 Ant Design default 类型，保留原生悬停、按下、焦点和禁用反馈，不增加交互颜色覆盖。
