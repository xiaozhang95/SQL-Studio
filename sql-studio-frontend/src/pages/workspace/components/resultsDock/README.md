# 结果容器与伸缩

[组件索引](../README.md) · [源码](index.tsx)

参数 children、resizable、height、onHeightChange。高度由工作区受控并随加密快照保存，不再独立读写 localStorage。查询页默认 260px、最小 260px，最大按父区域减去编辑器保留空间；支持指针拖动、上下键 24px、Home/End、双击恢复，不折叠。

独立结果页 resizable=false，铺满页面并隐藏伸缩条。拖动条 5px、抓手 2px，hover/焦点/拖动均为中性 token。组件只管理尺寸交互，不持有查询数据。

结果面板最小高度为 260px，给标签栏、工具栏、完整表头、至少一行数据和底部分页保留空间。旧快照保存的小于最小值高度在展示时自动钳制，键盘 Home 和拖动也遵循该下限。

结果内容显式允许鼠标选择文本，覆盖工作区/Tab 的禁止选择继承，错误回执、摘要、SQL 和数据表均可复制；仅拖动面板尺寸时暂时禁止选择。
