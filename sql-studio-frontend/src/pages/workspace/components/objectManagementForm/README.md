# 对象管理表单

界面固定文案通过共享 useTranslation 跟随已保存语言切换；SQL、用户输入和数据库返回内容按原文展示。

操作失败通过共享 ErrorNotice 在表单上方展示。

[源码](index.tsx) · [组件索引](../README.md)

ObjectManagementForm 接收 manager（对象管理 hook 的表单展示子集）和 themeMode。复用库/表名、字符集/排序规则、危险名称确认、字段表格、错误与高亮 SQL 预览；不请求数据库、不生成协议 SQL。

由 objectManagementModal 承载库和危险操作，由 tableDesigner 承载新建表/设计表。表设计器隐藏重复范围文案，字段编辑、主键/NULL/自增联动和特殊定义保护与原弹窗一致。表单变化调用 invalidatePreview 清理旧预览并标记草稿；所有受控值、加载和保存状态归对应 hook。正文由宿主负责滚动。

可见库表名称、字符集、排序规则及字段名/类型/默认值类型/默认值/注释均提供用途明确的placeholder；隐藏originalName/extra不显示占位文字。

数据库名称的英文标签使用 Name，占位提示使用 Enter a name，保持横向表单与原标签宽度。

库表管理表单统一不展示固定连接/库/表的只读范围下拉框，与重命名表保持一致；目标仍由 manager.dialog 绑定。新建/编辑数据库统一在首行显示名称，编辑时禁用；编辑表继续隐藏重复名称输入（仍注册于 Form 保留原始值及校验）。重命名和危险操作确认输入保留。

危险操作的确认提示将对象原名放在独立的整段可选文本中，前后提示不可选，间距用布局 gap 表达，不拼接空格。复制 Schema、表、视图或库名时不附带提示空格，清空表复用相同行为。名称原值和精确匹配校验保持不变，不 trim 合法名称自身的空格。

所有属性/对象表单统一横向：左侧标签（112px、右对齐），右侧输入；说明和错误跟随右侧输入。危险操作左侧为“确认名称”，可复制的原名提示放在输入下方，避免长对象名撑宽标签列；字段表格内无标签的编辑单元格继续占满本单元格。

新建/编辑数据库若有 engine.databaseEditor.Form，则在当前受控 Form 中展示引擎所属属性区，传入 creating 和可选 manager.databaseDefinition。名称统一由共享表单注册，避免重复；引擎属性区负责支持/禁用状态。MySQL 新建/编辑均为名称、字符集、排序规则三行，名称编辑禁用；外层不持有 PostgreSQL SQL 或属性校验规则。

时间字段输入复用 temporalInput：DATE 使用日期选择，TIME 使用时分秒，DATETIME/TIMESTAMP 使用日期时间；保留原字符串手动编辑及 NULL/默认值语义，带时区和特殊时间值不强制转换。表设计仅常量默认值启用选择器，表达式仍按文本输入。

右侧控件列统一使用flex:1 1 0及minWidth:0，保留原标签宽度与右对齐；允许长内容和帮助说明在控件列内换行，不通过内容最小宽度撑开表单。

添加和删除字段复用 ToolbarButton 图标按钮；特殊字段仍禁用，禁用时可通过 Tooltip 查看原因。字段删除只修改当前表单，提交行为由宿主控制。
