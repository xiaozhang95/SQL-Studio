# GreptimeDB 监控

默认导出 DatabaseMonitor(props:DatabaseMonitorPanelProps)，组合 MonitorPanel 与 [本引擎定义](constant/README.md)。概览为当前库表、主分片、估算行数与磁盘占用，四组趋势为表/分片、估算行数、磁盘/写入缓冲和 SST 文件数，均为实际采样值。详情补充构建版本、SST/索引/元数据占用和分片打开以来的累计活动。

只读取系统目录，主分片口径避免重复汇总副本；没有数据库 QPS/网络指标时不伪造。行数与空间为估算，分片重新打开会重置区域累计数，因此区域累计活动仅展示原值，不计算跨分片迁移的全局速率。可选扩展目录不存在或无权限时保留基础指标并提示；NULL 保持未知，不补零。
