# PostgreSQL 配置

[PostgreSQL](../README.md) · [源码](index.ts)

postgresqlProfile 为只读 DatabaseProfile，type=postgresql，显示名 PolarDB PostgreSQL，默认端口 5432、维护数据库 postgres。图标使用阿里云官方 PolarDB 北极熊 SVG（原始橙色），iconPresentation=brand 表示保留原色和透明背景，连接状态由公共组件单独展示；来源与固定版本见 [资产说明](../../../assets/databases/README.md)。经统一注册入口消费，不请求网络。
