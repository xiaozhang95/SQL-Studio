# Redis 监控只读定义

overviewMetrics、activityMetrics、trendCharts、sectionLabels、infoFields 定义 Redis 指标、图例及分类状态，不持有采样。公共 MetricFormat/MetricDefinition/TrendSeries 位于 [监控契约](../../../../typings/databaseMonitor/README.md)，chartLayout 位于 [共享尺寸](../../../../constant/monitor/README.md)。字段含义见 [Redis INFO](https://redis.io/docs/latest/commands/info/)。
