# 指标趋势图

`TrendChart({title,series,history})` 接收翻译标题、只读 TrendSeries 系列和真实 MonitorSnapshot 历史。使用同一时间轴绘制有限且非负的采样值，允许一个点、多系列及指标缺失；不存在的指标不补零。没有可用值显示空态。横轴使用实际采样时间，纵轴按当前图表自适应，不访问网络或持久化。

鼠标移动查看最近采样时间和该点的精确格式化值；键盘聚焦后左右方向键逐点移动，移出或失焦恢复最新点。折线/面积/图例引用 Ant Design 主题 token，SVG 继承系统字体。history 归父级连接和数据库范围，页面切换及实例重启由采样 hook 清空。
