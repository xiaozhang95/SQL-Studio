# 侧栏更新入口

`UpdateIndicator({ updates, disabled })` 接收 [桌面更新状态](../../../../hooks/useDesktopUpdates/README.md)。Electron 启动后发现新版本时，在主题分隔线上方显示下载图标。支持应用内下载时，点击开始下载，先显示圆形加载，收到文件大小后切换为进度环。下载、安装、加载图标和进度环使用与系统设置、主题相同的 20px StudioIcon 和 1.7px 视区描边，在 40px 控件区域内居中。进度环提供当前百分比。按钮图标、加载图标和进度弧使用侧栏的次级文字色，按钮悬停时提亮，轨道使用主题边框色。说明通过悬停提示和可访问名称提供。其余桌面版本点击同一位置进入发行页面。

下载失败时恢复下载图标，可再次点击。下载和校验完成后，圆环替换为「重启并安装」图标，并沿用工作台的退出确认流程。检查过程中、当前已是最新版本或 Web 端，侧栏保持原有布局。
