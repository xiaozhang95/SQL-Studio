# 系统设置入口

加载及保存错误通过共享 ErrorNotice 展示，保留当前草稿。

SystemSettings 接收 AppearancePreferences（已应用主题、字号、异步 onAppearanceSave 和可选 themeReady，默认 true），由工作区和 AI 助手共用。入口位于两页顶栏右侧，保存期间的 loading 在入口前显示；使用齿轮图标加「系统设置」文字的 text Button，保留 aria-label 和展开状态，外观恢复前禁用。

点击入口打开标题为“系统设置”的 Ant Design Modal，沿用默认位置。左侧按“模型服务”和“外观设置”展示次要文字分组标题，前者包含模型配置，后者包含主题模式和界面字号；三个图文列表按钮分别使用 RobotOutlined、SkinOutlined、FontSizeOutlined，整行点击，当前项使用 controlItemBgActive 灰色背景与默认文字色。右侧保留分区标题；模型页展示已添加模型列表和添加/编辑子弹框，主题和字号页直接展示卡片，不再显示卡片前的“主题：”“字号：”标签或占位列。底部统一提供“取消”和“保存”。弹框头部、内容区和底栏以原生主题边框分隔，左右内容独立滚动，高度随视口收缩。

- AISettings 展示已添加模型列表。添加/编辑通过横向子弹框依次选择供应商、输入 Key 自动加载并手动选择模型，再合入设置草稿。同供应商可添加不同模型，相同供应商与模型 ID 不得重复，不采用覆盖流程；当前供应商仅 DeepSeek。
- 添加记录前需手动选择发现的模型。首条已添加记录自动成为默认模型。模型列表展示品牌图标、模型名称、供应商及「默认」单选项，并提供编辑、测试连接和删除。删除需确认。列表选择、编辑、删除和子弹框应用仅更新草稿，底部统一保存才生效。
- 主题为 system/light/dark，使用带工作区缩略预览的卡片单选，跟随系统卡片并列展示亮暗预览。字号为 small/standard/large，以较小（12px）、标准（默认 14px）、稍大（16px）的示例文字卡片展示。卡片整张可选、保留原生 Radio 的键盘操作，并随宽度换行。只有字号示例使用对应预览字号，其余普通文字沿用默认排版。
- 设置编辑仅更新弹框草稿，切换左侧选项保留输入，保存后才应用并持久化外观。
- 总保存仅提交有变化的分区，成功后关闭；失败保留草稿和错误。模型与外观分别保存，部分成功时明确提示，不把失败显示为全部成功。忙碌时禁用控件、关闭按钮、遮罩关闭和 Escape。
- 取消、关闭按钮、遮罩或 Escape 放弃未提交的草稿，取消模型请求并清理 Key；下次打开重新读取配置。弹框关闭后销毁内容。

[useSystemSettings](hooks/useSystemSettings/README.md) 管理草稿、模型加载与统一提交；[settings](constant/settings/README.md) 集中导航类型和弹框布局尺寸。

[appearanceCards](components/appearanceCards/README.md) 提供共用的受控单选卡片；[themePreview](components/themePreview/README.md) 用原生主题 token 绘制装饰性工作区缩略图，不读取业务数据。

主题与界面字号选项在暗色下使用统一的细边框，仅通过单选圆点表示当前值。左侧分类导航使用共享灰色选中底。

主题和字号选项卡片始终保留 ghspace 的基础阴影，悬停上移 2px 并叠加悬停阴影，键盘焦点也有反馈，禁用及减弱动画场景单独处理。

常规操作按钮使用 Ant Design default 类型，保留原生悬停、按下、焦点和禁用反馈，不增加交互颜色覆盖。
