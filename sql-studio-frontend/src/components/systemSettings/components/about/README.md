# 关于软件

`About({ disabled })` 在系统设置中以简洁的「当前版本 + 版本号」行展示 Vite 写入的产品版本，不渲染 Logo、名称卡片或产品说明。Web 和 Electron 共用同一个版本显示，仅 Electron 显示“检查更新”和“查看控制台”。后者通过 [useDesktopConsole](../../hooks/useDesktopConsole/README.md) 立即打开当前工作台的独立开发者工具窗口，不需要保存设置。`disabled` 随系统设置保存状态禁用操作。

检查后展示最新版本状态。Windows 安装版可在本页下载，点击“重启并安装”直接发起安装，不再弹出二次确认。请求期间禁用重复操作。桌面端也可打开 GitHub Release 手动下载。错误使用共享 ErrorNotice，分别提示限流、拒绝访问、超时和网络等原因；更新清单不可用时仍可显示发现的正式版本并提供手动下载。操作通过 [useDesktopUpdates](../../hooks/useDesktopUpdates/README.md) 调用桌面桥接，不依赖设置草稿提交。

下载时用 Ant Design 圆形进度环替换「下载更新」按钮左侧图标，以环形填充展示实际进度。状态文案区分准备、下载和校验。校验成功后显示「重启并安装」。下载失败时进度环标为失败并保留最后进度，重试从头计数。关闭后重新打开设置或切换分类时恢复主进程状态。应用内下载进度适用于支持自动下载的桌面安装版。
