# 添加模型弹框

界面固定文案通过共享 useTranslation 跟随已保存语言切换；SQL、用户输入和数据库返回内容按原文展示。

配置读取、模型发现和提交错误通过共享 ErrorNotice 展示。

ModelEditor({editor}) 展示横向供应商、API Key、模型表单，editor 为 useModelEditor 返回值。供应商下拉复用品牌图标。模型下拉框右侧通过 Space.Compact 组合刷新图标按钮。输入 Key 后自动加载，也可手动刷新，加载失败提示放在模型控件下方。加载不自动选择。重复模型提示并禁用添加。新增“添加”、编辑“应用”只更新外层列表草稿，系统设置底部统一保存。取消清理输入与请求，沿用 Ant Design 默认位置、尺寸和样式。
