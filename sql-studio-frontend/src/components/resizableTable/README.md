# 可调列宽表格

[源码](index.tsx)

`ResizableTable` 以 Ant Design Table 为底座，为主查询结果表之外的业务表格提供统一列宽拖拽：非固定列的表头右缘有 8px 透明手柄，悬停显示分隔线；点击手柄不会触发排序。拖动实时调整列宽，手柄聚焦后可用左右方向键按 16px 微调，最小列宽 80px。主查询结果表因虚拟滚动和表体引用保留专用实现，手柄外观共用 app.scss 的样式。

首次调整时会冻结表头各列的当前实际宽度，并通过 `resizeKey`（可选）加列结构签名重置；调整后表格使用固定列宽布局，`scroll.x` 同步为实际总宽度，允许最后一列收窄并保留横向滚动。固定列（如行号、操作列）保持原宽，不提供手柄；行选择、展开列与分页列沿用 Ant Design 原生列宽。

表格内容、分页、虚拟滚动、选择、排序和展开等能力全部透传给原生 Table；表头单元格的 className 与拖拽事件由本组件接管，调用方列定义不再提供 `onHeaderCell`。调用方仅需替换组件，无需维护列宽状态。文本对齐由业务列定义决定，本组件不做改动。
