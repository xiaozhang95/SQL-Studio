# useRoundTranscript

useRoundTranscript(rounds, attention=false, live=false) 管理对话的原生滚动视口。返回 viewport、最多 5 轮的 start/end、上下占位高度、当前轮、加载状态和导航方法。根据已挂载轮次的实测高度和未测轮次的估算高度保留滚动范围。数据来自已经读取的本地会话。

滚到窗口中段时沿滚动方向提前挂载一轮，保留视口内正在阅读的轮次和像素位置。快速拖到未挂载的位置时显示加载提示，挂载完成后补足至少 1 秒的可见时长。加载提示不拦截滚动和导航。

问题搜索、Home、End 和回到底部共用同一定位逻辑。新提问跳到最新轮，写入确认出现时定位到最新轮末尾。读到末尾时跟随最新内容变化，阅读历史时保留锚点。卸载时释放高度观察器和加载计时器。
