# 会话列表

界面固定文案通过共享 useTranslation 跟随已保存语言切换；SQL、用户输入和数据库返回内容按原文展示。

重命名失败在当前弹窗内使用共享 ErrorNotice 展示。

History 受控 items/activeId/busy/loading/open 及 onSelect/onNew/onRefresh/onDelete/onRename。桌面侧栏宽度由共享 layout 提供，和手机 Drawer 共用 Ant Design X Conversations。编辑按钮打开横向名称表单。删除弹框显示目标会话名称，并说明会一并删除本机保存的消息和查询结果。提交期间锁定确认，删除失败时在弹框内显示原因。操作按钮停止冒泡，防止同时切换会话。新建会话与刷新操作位于桌面历史栏或窄屏抽屉的标题区域。

桌面会话栏使用与工作台对象栏共用的 [SidebarControls](../../../../../components/sidebarControls/README.md)，顶部以 42px 标题行展示「会话」、数量、刷新和最右侧的新建入口。下方为独立的搜索行，两行各有主题分隔线。列表按今天/昨天/更早分组，更早的记录直接展示；列表项显示消息图标、标题和时间，悬停时用重命名或删除替换时间。桌面侧栏与窄屏 Drawer 共用可清空的搜索框和关键词。按显示标题即时过滤，忽略首尾空白和大小写。默认会话可按当前语言搜索，手动名称按原文搜索。搜索为空时显示全部，无匹配时显示「没有匹配的会话」。过滤保留当前会话选择，关键词仅保存在当前页面。

桌面新建和刷新按钮与历史标题同排，窄屏复用抽屉标题栏的操作位。

useSessionRename管理弹窗选中项、Form、busy/error。重命名弹窗使用 forceRender 预先挂载 Form，再由 hook 填入名称，避免首次打开前操作未连接的表单实例。名称1–80字符，禁止空白名称及控制字符；取消不提交，失败保留输入，成功关闭并更新会话列表。初始化失败可显示空态与错误；恢复不重放 SQL。

selecting表示当前会话内容加载中：暂停新建、删除和重命名，但允许继续选择其他会话；busy用于模型执行、初始化与管理操作，禁止选择。列表loading仅表示轻量索引刷新，不代替会话内容加载。

历史侧栏与会话主区域使用 colorBgContainer。侧栏右沿与问答分隔线共用 `1px solid var(--border)`。列表悬停和选中状态沿用 Ant Design 主题。

历史列表独立滚动，搜索分隔线下方与列表底部各留 8px，同组会话间隔 4px，分组间隔 8px。有日期标题和无日期标题时沿用同一列表留白。分组标题使用弱化文字和 600 字重，字号跟随全局界面字号，会话项最小高度 34px。侧栏和抽屉水平内边距统一为 token.padding（16px）；桌面侧栏固定显示。

当前会话使用与工作区共用的 `--surface-selected` 中性选中底，悬停和聚焦时保持同一底色。会话图标使用默认正文色，行内操作沿用组件语义色。规则通过 chat-history-list 限定在 app.scss，桌面侧栏与抽屉共用。
编辑/删除按钮默认透明并禁止鼠标命中，保留宽度防止标题跳动；对应会话行悬停或键盘焦点进入操作区时显示，选中会话不会常驻显示按钮。
layout 接收公共 useSidebarResize 控制器。桌面侧栏右侧 5px 分隔条支持拖动、键盘左右/Home/End 与双击恢复 272px。宽度与 SQL 工作台连接栏共用并沿用工作台布局持久化，范围 200–560px，实际宽度按主区至少 520px 约束。窄屏继续使用 Drawer。

hook返回的DOM/list ref先单独解构为Ref变量，再传给ref属性；尺寸/导航状态与事件回调独立消费，渲染不读取ref.current。

当前选中项使用主题正文色。

会话操作区的占位宽度通过 style 管理，悬停/聚焦显隐保留在 app.scss。
