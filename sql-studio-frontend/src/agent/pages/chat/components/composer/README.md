# 聊天输入

实际使用Ant Design X Sender，直接作为Form.Item的受控字段，通过onValuesChange保存草稿到Go布局，normalize保留2000字符上限。不使用隐藏input加useWatch回填Sender的中转链，避免输入过程中旧值回写；useWatch仅用于发送按钮读取文本。Enter发送、Shift+Enter换行，onKeyDown与Sender共同保护IME候选确认。onSubmit校验配置、忙状态和非空输入；busy显示停止。底部自定义footer保留模式Dropdown、带蓝鲸模型Dropdown与发送按钮；模型菜单含共享DeepSeek配置入口，先关闭菜单再打开弹窗。onModelChange交给设置hook保存共享配置，组件无网络请求。usage悬浮区分真实输入token与保守估算。

输入区默认4行、最多10行（CHAT.composerRows），沿用默认字体，以原生styles提供更宽松的内边距、淡背景；根容器保留主题边框，输入内容不显示边框、焦点描边或阴影。仅影响Agent Sender，保留其他控件默认边框。

底部模型Dropdown使用默认尺寸文本按钮，无边框和背景色；当前值和所有模型选项统一展示蓝鲸图标。下拉配置按钮左对齐，使用钥匙图标。模型菜单的蓝鲸与钥匙统一使用CHAT.modelMenuIconSize（18px），透传原生图标className并复用菜单默认图文间距，所有选项的图标列和文字起点一致。入口图标使用CHAT.modelTriggerIconSize（20px），复用Button默认图文间距；菜单按完整内容撑宽。字体沿用Ant Design默认值。

回车通过onKeyDown直接读取当前Form字段并调用submit，不依赖隐藏的Sender内置发送按钮状态；阻止Sender重复提交。Shift+Enter和修饰键保留默认行为，IME组合输入和229键码不发送。

底部模式使用默认32px描边Button加Dropdown，与文本模型按钮及发送按钮对齐；只读使用默认中性色，完全访问使用主题警示色。模式菜单显示权限说明和当前选中勾选，完整内容撑宽，保留原有切换风险确认。模式说明独立InfoCircle悬浮按钮，始终展示权限、逐次确认及删除禁令，usage存在时追加上下文用量；不包裹模式菜单。图标尺寸：模型入口20px、菜单18px，发送按钮沿用默认圆形。切换风险确认及共享Key入口保持原行为。
