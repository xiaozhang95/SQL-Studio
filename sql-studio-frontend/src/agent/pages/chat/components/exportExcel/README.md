# ExportExcel

界面固定文案通过共享 useTranslation 跟随已保存语言切换；SQL、用户输入和数据库返回内容按原文展示。

导出错误使用共享 ErrorNotice，在导出操作所属区域展示。

value/title受控，导出当前已获取表格及目录数据为xlsx。懒加载exceljs，无额外SQL或模型请求；原字符串保持字符串，公式样式文本不转换为公式，重复列名保持位置，NULL为空单元格。截断结果明确标记；busy防重复点击，错误局部展示。

由QueryResult统一提供给执行工具结果及助手回答中解析出的表格，每张表独立导出全部已返回行，不受预览分页影响；不把模型回答表格宣称为数据库全量结果。

导出区不设置独立顶部外边距，结果与按钮的间隔由QueryResult统一控制；导出错误与按钮使用CHAT.spacing.detail（8px）。

常规操作按钮使用 Ant Design default 类型，保留原生悬停、按下、焦点和禁用反馈，不增加交互颜色覆盖。
