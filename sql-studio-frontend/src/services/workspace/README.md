# 分片工作区服务

WorkspaceStore.open(signal?) 读取 /workspace 轻量索引，不获取其他标签草稿或结果。hydrate(id,signal?) 仅读取目标页两份内容，校验后返回SQL和RunState，恢复最后结果共享引用和中断提示；不执行SQL。draft(id) 用于关闭范围时只读草稿。请求失败、损坏与404抛错，调用者展示重试，不用空内容覆盖磁盘。

commit(snapshot) 只传入加载过且变化的草稿、结果，其他标签保留索引引用；响应只有新修订和索引，不回传所有结果。无变化不发请求。服务只保存轻量索引及常驻页面的已保存基线，forget(ids) 同时释放基线、加载标记；没有全局全文缓存。evictable(snapshot) 排除当前、运行中、未保存或保存失败页面。加载中的响应由hook取消并通过预期版本防止覆盖后来的修改。页面内容按不可变引用比较，调用方不能原地修改结果。

旧 workspace.json 的一次迁移由后端完成且保留原文件。v2索引不包含SQL/结果行，草稿和结果通过内容散列独立保存，跨文件保存只有索引原子提交才可见。后台历史写入仍用userState独立分区。

索引保留结果成功/失败及来源的轻量摘要，释放结果后非活动标签颜色/悬停来源仍可展示。只在主工作区确认实际释放的页面上清除加载标记，防止快速切页时误清活动页缓存。

运行中不上传该页累计结果，结束后仅上传一次完整 RunState。open 清除过期运行标记后记录待提交状态，即使没有其他编辑也提交修正。409 保留修订、草稿和基线并提示“恢复保存”，不盲目覆盖另一窗口。
