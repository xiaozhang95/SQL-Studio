# 前端源码

开发前阅读并遵守 [前端开发规范](../../docs/FRONTEND_STANDARDS.md)。全局控件约定统一使用 appearance；数据库能力通过 databases 入口分派，页面和公共组件不承载引擎专属实现。

进入后恢复本机工作区配置，没有记录时默认无查询标签；无查询标签时隐藏编辑器与执行工具栏，空白区展示操作提示，对象浏览结果独立展示；对象树双击库展开并展示结构，双击表加载数据。连接表单的 label 与输入框左右排列。未选中树节点使用主题正文色，只有连接根节点按是否打开区分正常/灰色，折叠不置灰；库表图标始终正常。树高亮与查询下拉范围相互独立，连接根节点、选择器和弹窗统一使用各引擎官方品牌图标，旁边以绿色/灰色小圆点表示连接状态，选中行保留上下留白。

App.tsx/main.tsx 为框架入口；其余实际模块使用独立目录和 README。页面及组件布局使用 style/styles，app.scss 保留基础全局、Ant Design 覆盖和确需选择器的交互/媒体查询；颜色引用 Ant Design 原生 token，不手写主题主色。入口加载 antd/dist/reset.css 和 app.scss，SQL 编辑器通过 EditorView.theme 继承系统字体。信息 Tag 使用蓝色 solid，Button 保留组件默认样式；表操作位于对象树右键菜单，主区域统一按页面标签切换。

全部 Modal（连接、AI 配置、优化建议、库表管理及 AntApp 确认弹窗）通过 app.scss 复用 1px 主题外框，避免暗色背景下边缘混在一起；不逐弹窗覆盖相同边框。

全部原生组件覆盖集中在 app.scss；App 不覆盖 placeholder、文字和图标原色。运行工具栏右侧通过 useSQLImport 导入本地 SQL 文件，并可导出当前标签完整 SQL；查询与对象结果统一为一层带图标的方形页面 Tabs：导航无额外内边距，标签连续排列，以顶部主色线标识当前项。App 通过 borderRadius=0 统一 Ant Design 方角；主工作区贴边铺满，编辑器和结果面板不使用卡片外框或阴影。结果字段类型和 NULL 使用普通文字，状态/耗时不使用 Tag，不展示连接来源标签。

顶栏、侧栏搜索与工作区工具栏左右统一使用 workspace-inset=12px；树使用 28px 内容行与 2px 行间距，结果和执行历史采用原生 small Table，保持原字号。

查询结果与执行历史统一使用 tablePagination 的默认尺寸和底栏样式，页码 32px、右对齐且固定在表体滚动区外。左侧对象栏可拖动宽度（200–560px，默认 272px），双击恢复默认，宽度随加密工作区记录恢复。

连接 Select 使用原生默认尺寸、220px 标准宽度；连接图标为 20px，避免撑高控件。输出区由 resultTabs 展示逐条结果标签，消息、摘要与逐条结果并列，SQL 在消息/摘要中高亮并支持复制。连接表单支持输入或选择分组，新建预选“默认分组”，旧连接缺少分组或留空时也归入默认分组；分组随连接配置保存，左侧树以文件夹整理，组内连接可右键编辑更换分组。

没有保存记录时主页面为空；双击库/表创建独立结果页，查询页的 SQL 与最新结果共用一个标签。历史入口只在 SQL 页面，加载该页面连接的记录；载入追加到当前编辑器并标注历史来源。右键可执行选中 SQL，补全弹层沿用系统 Select 的视觉，树折叠按钮无背景。

完整草稿和选区支持多条 SQL：前端按有效分号切分、顺序调用单语句接口，每条结果在同页结果标签查看；引号/注释中的分号不切分。失败或取消停止后续语句，保留已完成结果。

页面、SQL、结果、历史和布局由 Go 保存到用户目录分区 JSON，主题也使用独立配置分区；不再使用 IndexedDB 保存或恢复工作区，不保存连接密码。恢复不自动执行 SQL，顶部指示保存状态。结果标签与主页面 Tab 跟随选中结果成功/失败联动。

MySQL 对象树按“数据库 → 表 → 表名 → 字段/索引”组织；PostgreSQL 在数据库下增加 schema 层，再展示表/视图分类和对象名，展开表按需读取元数据，主键用钥匙图标。索引悬停显示唯一性、类型和组成字段；视图维持既有功能，独立分组。
