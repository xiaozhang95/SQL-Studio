# SQL Studio 新 UI 设计规范

> 版本：设计稿 1.0（基于 SQL Studio v1.1.7 源码）
> 方向：精致进化 · 全应用 · 亮暗双主题 · 绿色强调
> 状态：仅设计，不包含业务代码改动

## 1. 设计目标

当前 SQL Studio 已具备完整的工作台、AI 助手、监控、同步和系统设置，但视觉语言存在四个问题：

1. **全局导航与页面操作混在顶栏**：新建连接、新建查询、收藏、同步、监控、AI 助手和系统设置堆在同一行，页面切换与当前页面操作没有层级差别。
2. **界面偏“白”且层级依赖文字和间距**：纯黑/纯白文字、白色面板、浅灰分隔，长时间使用缺少视觉锚点；绿色只在控件里出现，主操作不突出。
3. **同类信息重复占用垂直空间**：页签、工具栏、结果头部、结果工具栏连续四条横栏，工作区实际可用高度被压缩。
4. **各页面缺少统一的内容框架**：工作台贴边铺满，监控/同步使用独立顶栏与大标题，AI 助手又有自己的侧栏，四个页面不像同一个产品。

本方案在**不改变现有功能边界**的前提下，建立一套统一、克制、可落地的界面体系：

- 保留 Vite + React + TypeScript + Ant Design 6、系统字体、亮暗双主题和绿色主色。
- 用 **56px 全局 Rail + 48px 上下文 Header** 重构应用外壳，页面切换与页面操作分离。
- 用 **一套设计令牌** 统一颜色、间距、圆角、阴影、字号和状态，覆盖全部四个页面与系统设置。
- 用 **“每个操作面一个主按钮”** 建立清晰的动作层级：工作台是“运行”，AI 是“发送”，同步是“同步检查/开始同步”，设置是“保存”。
- 通过更紧凑的表格、更清晰的结果状态和更轻的分隔，把垂直空间还给 SQL 编辑器和结果。

**非目标：**

- 不新增后端能力、AI 能力或数据库能力。
- 不改变 SQL 执行、写入确认、删除禁令、连接加密等现有行为。
- 不引入自定义字体或图标包。
- 不在设计阶段改动业务代码。

## 3. 设计原则

1. **一个操作面只保留一个主操作。** 主操作使用绿色实心按钮，其他操作退为描边、幽灵或图标，避免“处处重要”。
2. **绿色只表达含义。** 连接成功、活动导航、主操作、选中线和聚焦环使用绿色；普通文字、普通边框不使用绿色。
3. **用分隔而不是阴影建立层级。** 主工作区使用 1px 发丝线、背景差和间距；阴影仅用于弹窗、菜单、AI 内容卡和浮层。
4. **密度与呼吸并存。** 数据行 30px、树行 28px、工具条 44px，保证高密度操作；页面级内容使用 18–24px 留白，避免拥挤。
5. **渐进披露。** 导入、导出、收藏、历史等低频操作图标化并配 Tooltip；核心范围选择、运行和结果始终可见。
6. **亮暗同构。** 两套主题共享尺寸、层级和状态，不做简单反相；暗色是独立的近黑+炭灰+亮绿体系。
7. **Ant Design 为底座。** 优先使用 token、组件参数和语义化 `styles`；原生选择器只用于外壳布局与确需的交互状态，且限定作用域。

## 5. 全局框架

### 5.1 结构

```text
┌──────┬──────────────────────────────────────────────────────────────┐
│      │ 上下文 Header 48px：页面标题 + 面包屑 | 状态 | 页面操作       │
│ Rail ├────────────────┬─────────────────────────────────────────────┤
│ 56px │ 工作区对象栏   │ 页签栏 38                                   │
│      │ 272px          │ 编辑器工具栏 44                             │
│      │                │ SQL 编辑器（弹性）                          │
│      │                │ 拖动分隔 6                                  │
│      │                │ 结果区（页签/状态/工具/表格/分页）           │
│      │ 侧栏状态 32    │                                             │
└──────┴────────────────┴─────────────────────────────────────────────┘
```

- 工作台、AI 助手、监控、同步共用 Rail 和 Header。
- 监控/同步使用画布底色 + 内容最大宽度（监控 1380px，同步 1120px），内容区域独立滚动。
- Electron 标题栏保持在最上方；Web 不显示标题栏。Rail 从标题栏下方开始。

### 5.2 全局 Rail

- 宽度 56px，背景 `surface-subtle`，右侧 1px `border`。
- 顶部 34px 应用 Logo（复用 `public/studio.svg`）。
- 导航项 40 × 40，图标 20px，圆角 8；激活项使用 `primary-soft` 底、`primary` 图标和左侧 2px 指示条。
- 导航顺序：工作台、AI 助手、监控指标、同步数据库。
- 底部：亮暗切换、系统设置；与导航区之间以 22px 分隔线隔开。
- 图标按钮提供 `title` / Tooltip 和可访问名称。

### 5.3 上下文 Header

- 高度 48px，背景 `surface`，下沿 1px `border`。
- 左侧：页面标题（14px / 600）+ 面包屑（11.5px / `text-3`）。工作台为「连接 / 数据库 / 页签」，AI 为「会话 / 会话名」，监控/同步为「连接 / 数据库」。
- 右侧：当前页面的状态与操作。工作台：连接状态、新建查询、新建连接、收藏、更多；AI：模型/模式状态、新建会话；监控：采样状态、更多；同步：状态、说明、更多。
- 系统设置不再占用 Header，统一放 Rail 底部；`SectionNavigation` 由 Rail 取代。
- 标题过长时保留页面标题，面包屑逐段省略；窄屏隐藏面包屑。

### 5.4 响应式

| 断点 | 行为 |
| --- | --- |
| ≥ 1280 | 完整布局 |
| < 1280 | 隐藏面包屑、Schema 选择器（如存在）、页签栏提示 |
| < 1080 | 隐藏数据库选择器；监控图表单列；同步源/目标改纵向 |
| < 900 | 对象栏/会话栏改为抽屉；Header 只保留图标；Rail 保持 56px 或收至 48px |

工作区最小宽度 900px，沿用当前约定。

## 6. 工作区

对应截图：[亮色](screens/workspace-light.png) · [暗色](screens/workspace-dark.png)

### 6.1 对象栏

- 宽 272px，默认 200–560 可拖拽；双击恢复 272。
- 结构：标题栏 42px（「对象」+ 连接数 + 新建连接 + 收起）→ 搜索 46px → 树（28px 行，2px 行距）→ 状态栏 32px。
- 树节点：
  - 连接根节点使用 18px 引擎图标（EngineIcon 底板）+ 连接名 + 6px 状态点。
  - 数据库/Schema 使用数据库图标；表使用表格图标；视图使用眼睛图标。
  - 分组标题使用 10.5px / 600 / `text-3`，可在右侧显示数量。
  - 选中行使用 `surface-hover` 底 + 2px 绿色左条，文字恢复 `text`；悬停只改变底色。
  - 未连接连接的图标底板和状态点使用 `text-4` 灰；选中/悬停不改变图标颜色。
- 状态栏：连接数、已连接数、当前引擎；11px `text-3`。
- 搜索仅过滤当前对象树，不改变查询范围；清空后恢复。

### 6.2 工作区页签

- 栏高 38px，页签高 28px，最大宽 220px，最小 96px。
- 默认页签宽 200px；图标 13px；标题支持「数据库 · 查询 N」两段式，长名省略并可悬停查看全文。
- 激活页签：`surface-subtle` 底、1px `border`、`shadow-xs`、文字 `text`，页签栏底部 2px 绿色活动线。
- 悬停：`surface-hover`；关闭按钮在悬停或激活时显示，16px 命中区。
- 未保存修改使用 6px 琥珀色圆点，替代当前 `*`。
- 执行中的页签使用 12px Spinner 替代类型图标。
- 末尾 26px「+」新建查询；超出后横向滚动或下拉选择，不换行。

### 6.3 编辑器工具栏

- 高 44px，左右内边距 12px；上沿 1px 分隔。
- 左侧范围：连接选择（约 176px，含 16px 引擎图标）、数据库选择（约 150px）；PostgreSQL 再增加 Schema 选择（约 138px）。选择器高 29px，沿用 220px 最大宽度并允许收缩。
- 主操作：「运行」绿色 30px，含 13px 播放图标和 `⌘↵` 快捷键提示；执行中替换为「取消」危险文本按钮。
- AI 分组：闪光图标 +「AI 补全」+ 26×14 Switch；「优化」使用幽灵按钮。没有保存模型时隐藏整组。
- 右侧图标操作：导入、导出、收藏、执行历史、更多；29 × 29 命中区，Tooltip 说明。
- 不使用文字按钮堆叠；不改变现有选区执行、事务执行等右键菜单行为。

### 6.4 SQL 编辑器

- 12.5px 等宽，1.72 行高；行号栏 48px，10.5px `text-4`。
- 当前行使用 `surface-subtle` 底 + 左侧 2px 绿色条。
- 文本选区使用 `selection`；匹配括号、补全弹层沿用 CodeMirror 原生交互。
- 编辑器始终占满剩余高度；不添加卡片外框、阴影或圆角。
- 空编辑器保留行号与占位提示；加载中在编辑区显示 ContentLoading。

### 6.5 结果区

- 默认高度建议 300px，最小 240px；如希望减少行为变化，可沿用当前 260/260。原型展示高度 318px，仅用于展示层次。
- 拖动条 6px，中心 40×2 握把；悬停/聚焦时握把变为 `text-4`；支持方向键、Home/End、双击恢复默认。
- 结果页签栏 38px：
  - 消息、摘要、结果 1…结果 N；超过 8 个使用下拉选择。
  - 激活项文字 `text` + 底部 2px 绿色线；数量使用 10px `text-4`。
  - 右侧状态：成功图标 +「成功」、耗时、行数、列数；执行中显示 Spinner +「执行中」和取消入口；失败显示红色语义。
- 结果工具栏 38px：

## 12. 亮暗主题与可访问性

- 两套主题共用尺寸、层级、间距和状态；暗色按近黑画布、炭灰面板、亮绿主色独立设计。

- 键盘：所有交互可聚焦；聚焦环 2px `primary` + 2px offset；树、页签、弹窗支持键盘操作。

- 长文本：名称、SQL、错误原因使用 `overflow-wrap: anywhere`；不截断可复制的关键内容。
- 主题切换不做全页面过渡；避免白色闪烁。

### 13.3 与现有规范的冲突与修订建议

当前 [前端开发规范](../docs/FRONTEND_STANDARDS.md) 要求「保留 Ant Design 默认样式」「常规操作按钮统一 default」「主题使用纯黑/纯白文案与 #ececec/#000 布局底」。新设计有意偏离以下四条，实施前应同步修订规范：

1. **外观基线**：从「保留 AntD 默认外观」改为「以 AntD 组件为底座，使用项目设计令牌；外壳布局和确需的状态样式允许局部受控覆盖」。
2. **按钮层级**：从「常规操作统一 default」改为「每个操作面一个 primary，其余 default/ghost/icon；确认弹窗默认 default，写入确认可使用 warning」。
3. **主题色**：从纯黑/纯白改为近黑 `#161a16` / 近白 `#f2f5f1`；布局底从 `#ececec/#000` 改为 `#f4f6f2/#0a0c0a`；绿色主色由 `#52c41a` 过渡到 `#15803d/#42d47c`。
4. **导航结构**：从「顶栏 + SectionNavigation」改为「左 Rail + 上下文 Header」；系统设置入口移到 Rail 底部。

**保持不变**的规范：

- 不引入自定义字体；普通界面继续用系统/AntD 字体。
- 业务表单继续左侧标签、右侧控件。
- 数据库能力继续按引擎封装，不在通用 UI 硬编码方言。
- 删除/清空继续使用确认弹窗，并在后端做最终校验。
- 组件/hooks/常量/类型按功能独立目录与 README。
- 亮暗双主题、字号偏好、语言、Electron 退出等现有行为不变。

## 14. 分阶段落地建议

| 阶段 | 内容 | 风险控制 |
| --- | --- | --- |
| 1. 令牌与外壳 | 更新 theme tokens；新增 Rail；改造 PageHeader；迁移系统设置入口 | 先只改全局外观，业务逻辑不动；逐页核对亮暗和字号 |
| 2. 工作区 | 页签、对象栏、工具栏、编辑器、结果区 | 保留所有现有回调；重点回归执行、分页、缩放、保存/恢复 |
| 3. AI 助手 | 历史侧栏、欢迎页、对话卡、写入确认、输入框 | 不改 SSE、确认 ID、模式协议；核对长会话和滚动 |
| 4. 监控/同步 | 内容画布、面板、图表、步骤条、进度 | 不改 API 和指标字段；核对自动刷新、取消、失败保留 |
| 5. 设置/弹窗/文档 | 模型、外观、语言、关于；连接/删除弹窗；规范文档 | 核对保存草稿、取消恢复、Electron 检查更新 |

每阶段结束建议在 1440×900 与 1280×800 下检查两种主题、三种字号、长对象名、空/错误/加载状态和键盘可达性；SQL 执行回归使用现有 `sql-studio-sql-regression` 流程。
