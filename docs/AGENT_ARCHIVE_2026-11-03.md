# Agent 全面归档检查（2026-11-03）

## 结论

本轮发现并修复 Agent SQL 安全校验、确认对象展示和中窄屏顶栏问题。自动测试、三种隔离 Docker 数据库、真实 DeepSeek Flash/Pro 以及正式构建浏览器验收均完成。该结论只适用于下述已测范围，不等同于数据库权限沙箱或所有边界的形式化证明。

使用单独的 18120 服务、临时状态目录以及本轮新建的 MySQL / PolarDB PostgreSQL / MariaDB 容器；原有 8080、5173 服务和原 MySQL 容器不改动。Key 只通过不回显终端写入隔离后端，API 不回填，未进入源码、日志、截图或报告。

## 发现、修复与复测

| 级别 | 问题 | 修复和证据 |
|---|---|---|
| P1 | query_readonly 原先会将 USE、跨库 SQL、锁/等待及未知函数送入通用执行器，仅依赖数据库只读事务 | 新增 Agent 单语句、读取类型、函数及 MySQL/MariaDB 范围检查；复现测试原先6种请求到达替身数据库，修复后均在调用前拒绝；普通查询、聚合、别名、子查询、CTE和PG schema名回归通过 |
| P1 | INSERT/UPDATE/CREATE 表达式原先接受 lo_unlink、读取文件及未知存储函数，非删除语句也可能有删除副作用；ALTER DISCARD及账户/服务器管理也未限制 | 明确受支持函数与结构对象，拒绝等待/锁/文件/未知UDF、删除性结构和账户/扩展/服务器管理；工具层和app适配层双重校验，执行前重新读取当前引擎，普通SQL窗口不受限制 |
| P2 | 确认对象只用正则提取第一个名称，无法完整列出 INSERT SELECT、JOIN等来源或索引关联表 | 共用词法扫描提取并去重源/目标对象，保留引号，忽略字符串中的伪SQL；新增多对象测试 |
| P2 | 中窄屏的会话标题覆盖保存状态，窄屏未实际隐藏状态文字 | 1280px以下隐藏重复标题，760px以下只保留保存状态图标与可访问名称；正式页面390px稳定布局无横向溢出，历史抽屉可用 |
| 维护 | app.scss未满足Prettier检查；Agent文档仍混有禁止所有DDL和固定只读等旧描述 | 格式化并同步当前约定；历史增量验证日志保留为历史，本报告记录本轮现状 |

PostgreSQL的 ON CONFLICT DO UPDATE / DO NOTHING 保留支持，单独 DO 程序仍拒绝。对 SQL 支持采取保守子集，遇到未审核函数或有歧义的转义/注释会明确拒绝，不尝试猜测后执行。
