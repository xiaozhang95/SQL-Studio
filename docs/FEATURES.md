# SQL Studio 功能汇总

整理日期：2026-11-02。范围为当前仓库的 Web 前端、Go 后端与内嵌网页独立程序；Electron 封装已移除，不纳入现有功能。

本文依据源码入口、模块说明及接口契约整理，是功能盘点，不代表本次逐项完成了数据库或浏览器回归。发生说明差异时，以当前实现及实际数据库能力为准。

## 1. 产品定位与功能总览

SQL Studio 是面向本机单用户的数据库工作台，提供数据库连接、对象浏览、SQL 编写执行、表结构设计、表数据维护、导入导出与 AI SQL 辅助。

| 模块 | 当前功能 |
| --- | --- |
| 数据库适配 | MySQL、MariaDB、PostgreSQL、使用 PostgreSQL 协议的 PolarDB |
| 连接与分组 | 新建、编辑、测试、删除连接，打开/关闭连接与数据库，分组维护与移动连接 |
| 对象浏览 | 数据库、Schema、表、视图、字段、索引、DDL，搜索与局部刷新 |
| 对象管理 | 数据库维护、PostgreSQL Schema 维护、表/视图重命名和删除、清空表 |
| 表结构设计 | 新建表、字段维护、主键、默认值、注释、差异 SQL 预览与保存 |
| SQL 工作区 | 多标签、语法高亮、对象补全、选区运行、多语句执行、取消 |
| 结果处理 | 多结果、消息、摘要、分页、筛选、排序、勾选、刷新、CSV |
| 数据维护 | 暂存单元格修改、新增行、按主键删除、统一保存或放弃 |
| SQL 文件 | 本地 SQL 导入、草稿导出、库/Schema/表结构及数据转储 |
| 历史与恢复 | 按连接记录执行历史，保存布局、范围、草稿、结果及编辑位置 |
| AI 辅助 | DeepSeek 配置、模型发现、SQL 续写、整页或选区优化 |
| 运行交付 | 前后端开发运行、Go 内嵌网页独立程序、Swagger/OpenAPI |

## 2. 数据库支持范围

| 能力 | MySQL | MariaDB | PostgreSQL / PolarDB PostgreSQL |
| --- | --- | --- | --- |
| 连接类型 | mysql | mariadb，独立类型 | postgresql |
| 默认端口 | 3306 | 3306 | 5432 |
| 维护数据库 | 不需要 | 不需要 | 默认 postgres，可修改 |
| 对象层级 | 数据库 → 表/视图 | 数据库 → 表/视图 | 数据库 → Schema → 表/视图 |
| 查询与显式写入 | 支持 | 支持 | 支持 |
| 表结构设计、主键数据维护 | 支持，特殊定义有保护限制 | 支持，复用兼容能力并处理方言差异 | 支持，复杂类型与依赖有边界 |
| RETURNING | 按服务器原生语法 | INSERT / DELETE / REPLACE RETURNING | 按 PostgreSQL 原生语法 |
| USE 切库 | 支持并传递后续语句的数据库范围 | 支持 | 不支持，使用数据库选择器 |

- PostgreSQL 目录元数据实现要求 PostgreSQL 12 或更新版本；PolarDB 支持范围为 PostgreSQL 协议，不包含 Oracle 兼容版。
- MariaDB 当前适配说明以 11.4 为主要范围，不据此保证所有历史版本均兼容。
- 所有操作仍受数据库账号权限、版本、类型和约束限制。

## 3. 连接与分组管理

- 新建、编辑、删除本地连接；配置引擎、名称、主机、端口、用户名、密码及分组。
- PostgreSQL 可配置维护库；新建时切换引擎更新默认端口和维护库，编辑既有连接不切换引擎。
- 保存前可测试真实连通性，成功返回数据库版本；测试超时为 7 秒。
- 可开启 TLS，校验证书链和主机名；不提供跳过证书校验。
- 密码由后端 AES-GCM 加密保存，接口不返回密码；编辑时密码留空保留原值。
- 新建、重命名、删除自定义分组；支持空分组和默认分组，连接表单可直接输入新分组。
- 移动连接只改变分组归属；删除分组将成员移回默认分组，不删除连接。
- 默认分组不可重命名或删除；分组名称校验空白、控制字符和重复。
- 打开/关闭整个连接或单个数据库；关闭时取消对应范围请求，等待本服务驱动连接释放，不终止其他客户端会话。
- 关闭范围时可保存相关 SQL 后关闭、放弃并关闭或取消；失败保留页面，其他连接和数据库不受影响。
- 新增连接不自动连接、展开或切换当前查询；连接列表失败提供重试。

## 4. 数据库对象浏览

- 左侧按分组展示连接，显示连接状态，按需加载数据库与对象。
- 浏览表、视图、字段及索引；字段展示主键标识，索引提供唯一性、类型和字段顺序等信息。
- PostgreSQL 保留真实 Schema 层级，包括空 Schema；相同表名按 Schema 区分身份。
- 搜索数据库对象，展开/折叠树节点，对象树使用虚拟滚动。
- 双击数据库或 Schema 展示结构列表，双击表打开数据页；已有对象页面可复用并刷新。
- 查看对象 DDL，SQL 定义支持高亮、换行和复制。
- 按目标连接、库、Schema 或对象局部刷新；树选中状态与 SQL 页面查询范围独立。
- 对象栏可拖动宽度、键盘调整和双击恢复默认，保存树展开与滚动位置。

## 5. 数据库、Schema 与表对象管理

- 新建、编辑、删除数据库；危险操作要求确认完整对象名称。
- MySQL/MariaDB 可维护数据库默认字符集及排序规则，选项读取服务器实际信息。
- PostgreSQL 数据库编辑支持所有者、连接数上限与注释；名称、编码、排序规则在编辑表单中不可修改。
- PostgreSQL 支持新建、重命名和删除 Schema；删除使用 RESTRICT，仅允许空 Schema。
- 支持新建表、设计已有表、重命名表/视图、删除表/视图和清空表。
- 执行前校验目标与输入，提供相应 SQL 预览；不因切换活动页面改变提交对象。
- 变更后刷新对应对象缓存；创建对象不自动切换查询范围或展开对象树。
- 重命名修正关联页面范围，不改写已有 SQL 草稿和历史结果，不自动重跑查询。

## 6. 表结构可视化设计

- 新建表、设计表使用独立工作区标签；同一既有对象复用设计页，新建表可保留多份草稿。
- 提供保存、SQL 预览、重新加载，未保存标签显示标识；切页保留当前设计内容。
- 支持适配范围内的字段新增、删除、改名、类型、长度/精度、可空、主键、简单默认值及注释。
- MySQL/MariaDB 支持自增定义；新建表提供 BIGINT 自增主键初始行。
- PostgreSQL 支持 identity 等适配能力；多个字段变更可合并为一个事务内执行的 DO 块。
- 按原结构生成差异 DDL，保存前检查结构是否已被外部修改，避免静默覆盖。
- 保存成功保留原设计标签，新建页转为已建表设计页；重新加载或关闭未保存设计需确认。
- 生成列和不能可靠重建的复杂定义保持只读或锁定；未修改定义尽量原样保留。
- 未提供通用二级索引编辑、字段拖动排序和任意默认表达式编辑；可通过 SQL 窗口使用数据库原生能力。
- 设计草稿只在当前会话中保留，不承诺浏览器刷新后恢复。

## 7. SQL 编辑与执行

- 多查询标签，每页独立保存连接、数据库、Schema、SQL 与最新输出。
- CodeMirror 编辑器提供语法高亮、行号、选区、撤销/重做和数据库方言适配。
- 关键字、数据库、表/视图及已加载字段补全；补全范围跟随当前查询连接与数据库。
- 工具栏运行、Ctrl/Command+Enter 和右键选区运行；有选区优先执行选区，无选区执行整份草稿。
- 右键运行只针对捕获的选区，空选区不回退执行整页；运行快捷键不修改 SQL 内容。
- 支持多语句脚本，按引擎识别字符串、注释等边界后顺序逐条执行。
- MySQL/MariaDB/PostgreSQL SQL 窗口允许查询、DDL 和 DML，不增加只读开关。
- 失败或取消停止后续语句，保留此前完成的结果，展示未执行数量与实际状态。
- 支持请求取消；恢复时把中断的运行标记为 interrupted，不自动重跑。
- MySQL/MariaDB 成功执行 USE 后更新发起页数据库，后续语句显式使用该库；PostgreSQL 独立选择数据库及 Schema。
- 切换已有页面不会把响应写入另一页；范围变更或旧请求取消后，迟到结果不覆盖新状态。
- 切页保留当前会话的编辑撤销/重做；关闭页面释放，浏览器刷新不恢复撤销历史。

**执行边界：** 每条语句为独立请求，不共享事务、SET 或临时表会话。不能将跨请求 BEGIN/COMMIT 当作一个事务；批次失败、取消或退出不意味着此前写入回滚。直接 API 未指定 allowWrite 时仍默认只读。

## 8. 结果、消息与执行摘要

- 在同一查询页内展示消息、摘要与多个数据结果；超过 8 个数据结果时通过下拉选择。
- 消息按执行顺序提供 SQL、状态、耗时和错误；摘要提供成功/失败数量、起止时间及运行时长，可仅查看错误。
- 无数据列的成功回执展示影响行数，不创建空结果标签；零行但有列的查询仍显示表头。
- 结果显示字段名、类型、NULL、空结果及截断提示；保留重复列名和大整数/精确数值的文本精度。
- 结果表分页，每页 50 行；固定分页区、横纵滚动与页内虚拟渲染。
- 对全部已加载匹配行进行本地筛选、列排序，再分页；不为排序向数据库追加 ORDER BY。
- 跨分页勾选行，结果版本变化清空选择；支持 CSV 导出全部或选中行。
- CSV 遵循当前筛选与排序，包含适用的暂存值；导出范围是已加载结果，不代表数据库全表。
- SQL 定义列提供完整高亮和复制，不因单元格展示省略而丢失导出原文。
- 查询结果、表数据、结构和 DDL 可原页刷新；查询刷新使用原执行 SQL 与范围，而非后来修改的草稿。
- 未保存数据修改时限制刷新，避免覆盖暂存；结果面板可拖动调整高度。

## 9. 表数据新增、修改与删除

- 基础表数据页支持双击单元格编辑，跨行、列和分页暂存，修改项高亮。
- 顶部统一保存或放弃；点击编辑区外部结束输入但保留暂存。
- 新增行提供默认值、指定值及 NULL 选择；未指定字段交由数据库生成。
- 新行草稿置顶，可单独移除，保存后刷新回第一页；无主键基础表可新增。
- 已有行更新和删除要求完整可用主键；更新同时检查原值/结构，降低误覆盖风险。
- 多选现有行后确认删除，跨分页保留选择；有暂存修改时先保存或放弃。
- 保存/删除逐项执行，失败停止，明确已成功数量并保留剩余内容；不承诺整批事务原子性。
- 普通 SQL 结果、视图、无完整主键的已有行以及不支持的特殊字段不直接编辑或删除。
- 未提交数据修改不承诺浏览器刷新后恢复；取消不能视作已回滚。

## 10. SQL 文件与数据导出

### SQL 草稿导入、导出

- 本地读取 .sql，支持 UTF-8 与 BOM；校验文件类型、空内容、编码和体积。
- 导入文件上限 1 MiB，并受 JSON 编码后请求限制；新建独立查询页，不覆盖旧草稿、不自动执行。
- 导入文件在浏览器本地读取；后续手动执行或工作区保存仍会将相应 SQL 发送到本机后端。
- 导出当前查询页完整 SQL；范围关闭时可合并相关查询草稿保存为 SQL 文件。

### 结构及结构与数据转储

- 数据库、PostgreSQL Schema、表等菜单支持已适配范围的“仅结构”和“结构及数据”SQL 转储；视图仅导出结构。
- 通过专用 SSE 接口分批读取表数据并顺序写文件，不受普通查询 1000/5000 行上限约束。
- 展示对象阶段、实际行数、字节数、进度与最近日志，支持取消；只有完整成功才提交文件。
- 优先浏览器原生文件流；兼容下载模式缓存上限 256 MiB，超限明确失败。
- 转储处理精确数值、二进制、NULL、生成列、自增或适配范围内的自有序列/identity。
- MySQL/MariaDB 保留适配的字符集、排序规则及导入所需会话设置；PostgreSQL 处理 Schema、适配的序列状态和延后外键。
- 导出期间复核对象 DDL；发现结构变化或数据列不匹配时停止，避免生成静默缺失的文件。
- 关闭导出所属连接或数据库会取消导出；其他连接不受影响。

**转储边界：** 不提供跨表同一时间一致性快照；不包含完整的例程、触发器、事件、授权及外部依赖。PostgreSQL 分区/外部表、复杂序列依赖和 MariaDB 系统版本历史等不能完整处理的场景明确拒绝或提示使用原生工具。完整备份应使用数据库原生备份工具。

## 11. 执行历史与本机工作区

- 按连接保存最近 50 条执行记录，包含执行 SQL、范围、状态和适用的耗时信息。
- 历史可搜索、复制、载入当前查询；载入追加并标记来源，不自动切库或执行。
- 删除连接清理对应历史；连接列表加载失败时不误清理历史。
- 保存标签、连接/库/Schema 范围、SQL 草稿、结果快照、主题、对象树布局、滚动及编辑位置等状态。
- 工作区采用轻量索引与独立草稿/结果分片，按需恢复非活动页，减少启动加载与内存占用。
- 恢复只读取必要内容和元数据，不自动执行 SQL；保存完成的非活动内容可释放内存。
- 顶部展示恢复、保存、已保存及失败状态；页面恢复失败可重试。
- 修订号检查避免旧保存覆盖新状态；损坏/未知版本配置拒绝静默覆盖。
- 默认保存到服务启动工作目录下的 `.sql-studio/state/`，可通过 SQLDESK_STATE_DIR 指定。
- 密码、AI Key 由后端管理并脱敏返回；工作区可能包含 SQL 和结果，备份时需妥善保管。
- 迁移、备份连接时应同时保留 connections.json 与 master.key；不会自动读取或删除任意旧用户目录。

## 12. AI SQL 辅助

- 当前已实现 DeepSeek 服务商配置，支持 API Key 保存、留空保留、清除配置和模型发现/选择。
- 可开启或关闭 SQL 续写；防抖请求，在光标处显示灰色建议，输入法组词期间不发起续写。
- 整页优化或选区优化；展示原文、建议与说明，由用户决定是否应用，支持编辑撤销。
- 上下文包含适用的 SQL 前后文、当前草稿、连接名称/引擎、库/Schema 与选取的表字段信息。
- 连接引擎和名称由后端按 connectionId 解析，不信任客户端伪造的连接描述。
- 页面、范围或模型配置变化时取消旧请求，应用建议前复核文档和范围，避免跨页误用。
- 不自动执行生成 SQL，不向 AI 服务发送数据库密码或查询结果。
- SQL、注释和选取的库表结构会用于 AI 请求，属于发送到外部服务的上下文，应按实际数据敏感性使用。
- 当前未实现任意 OpenAI 兼容服务商接入或其他模型平台的完整支持。

## 13. 界面与操作体验

- Ant Design 界面，支持亮色、暗色及跟随系统，主题偏好本机保存。
- 业务表单采用左标签、右输入控件，提供字段校验、帮助说明与错误反馈。
- 查询、表数据、结构、DDL 和表设计使用统一工作区标签，支持关闭及适用的批量关闭。
- 对象树和结果表使用虚拟渲染；结果按页映射，筛选延后更新，减少输入时无关计算。
- 草稿与编辑位置批量同步，避免每次输入持久化整个工作区。
- 窄窗口支持布局伸缩、独立滚动及执行历史抽屉；不代表已提供专用移动端应用。
- 连接、页面、写入、导出有各自忙碌状态和取消边界，避免重复提交与旧响应污染。

## 14. API、运行与交付

- React/Vite/TypeScript 前端，Gin/Go 模块化单体后端；开发时分别启动。
- 后端根目录可直接 `go run main.go`；前端通过 `pnpm dev` 启动并代理 API。
- 根目录 build.ps1 构建前端，再通过 Go embed 将静态网页编入单个 Go 可执行文件。
- 构建版由同一个 Go 服务提供页面与 API，目标机器无需 Node、Vite、Go 或外部 dist。
- 默认监听 127.0.0.1:8080，可用 SQLDESK_ADDR 改地址；SQLDESK_WEB_DIR 可覆盖静态资源目录。
- 构建脚本支持指定 windows/linux/darwin 与 amd64/arm64；不据此宣称本次已完成全部平台运行验证。
- Windows 构建仅生成独立 EXE，不额外生成 CMD 启动文件；普通用户配置按启动工作目录解析。
- 提供本地 Swagger UI、OpenAPI JSON、健康检查及连接、对象、查询、工作区、状态、AI 接口。
- 默认仅面向本机单用户，包含本机 Host/跨站请求检查，不提供开放 CORS 或多人账号体系。

## 15. 主要限制与未纳入功能

| 项目 | 当前范围或限制 |
| --- | --- |
| 普通查询 | 默认 1000 行，最大 5000 行，约 8 MiB 字段内容，30 秒超时，后端最多 4 个并发查询 |
| 元数据读取 | 通常最长 10 秒，按显式连接与对象范围读取 |
| 流式表导出 | 独立最多 2 并发、30 分钟限制、单行 8 MiB 上限；不同于普通查询截断规则 |
| AI 超时与并发 | 续写 12 秒、优化 30 秒、模型发现 10 秒，共享最多 4 并发 |
| 跨请求会话 | 不支持跨请求事务、SET 或临时表共享；取消不保证回滚 |
| 结果筛选/排序/CSV | 针对已加载结果，不等于服务端全表搜索、排序或备份 |
| TLS 扩展 | 无自定义 CA、客户端证书或 SSH 隧道配置 |
| 可视化设计 | 不涵盖所有高级类型、索引、约束和任意 SQL 定义 |
| 用户与部署 | 无多人账户、角色权限体系、团队共享或远程托管产品能力 |
| 桌面封装 | Electron 已移除，现有交付为浏览器访问的 Go 内嵌网页程序 |
| 监控体系 | 未集成 Prometheus、Grafana、Alertmanager；执行耗时及健康接口不等于完整监控 |
| 完整数据库备份 | 不替代 mysqldump、mariadb-dump、pg_dump 等原生备份工具 |

部分旧 README 仍保留“结构和数据最多 5000 行/8 MiB”的早期说明。当前库/Schema/表菜单的主转储流程已采用专用 SSE 流式读取，应以上述流式规则及实际入口为准，不能把普通查询限制套用到整个转储功能。
