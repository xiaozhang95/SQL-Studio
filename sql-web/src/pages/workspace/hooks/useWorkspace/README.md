## 调用与返回

`()`

返回 WorkspaceModel；区域组件用 Pick 限定实际使用字段。包括连接/标签/查询、结构、结果筛选、历史与 UI 回调。

## 生命周期与边界

各标签独立保存连接、库、Schema、表和 SQL；新建继承当前范围。执行固定发起标签和范围，请求不传写入或行数参数，使用后端默认只读；取消时不声称 SQL 已完成。结构请求在范围变化时取消，结果/历史与草稿分开管理。

请求错误、取消和持久化失败沿用实现中的边界，组件不重复维护同一份业务状态。

## 当前交互

执行结果按查询标签保存不可变快照，每次完成新增结果；可切换和关闭，关闭查询释放对应快照。数据不持久化。菜单执行固定目标范围，结构/DDL 请求共用取消控制及运行锁，SQL 数据查询仍使用只读接口。新建查询仅生成 SQL，不直接执行。
