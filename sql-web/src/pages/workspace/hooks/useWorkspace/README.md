## 生命周期与边界

各标签独立保存连接、库、表和 SQL；新建继承当前范围，SQL 默认为空；已有草稿原样恢复。执行固定发起标签和范围，请求不传写入或行数参数，使用后端默认只读；取消时不声称 SQL 已完成。结构请求在范围变化时取消，结果/历史与草稿分开管理。

请求错误、取消和持久化失败沿用实现中的边界，组件不重复维护同一份业务状态。

## 当前交互

执行结果按查询标签保存不可变快照，每次完成新增结果；可切换和关闭，关闭查询释放对应快照。数据不持久化。有结果就直接展示结果面板，伸缩尺寸由 resultsDock 管理，工作区不维护折叠状态。菜单执行固定目标范围，结构/DDL 请求共用取消控制及运行锁，SQL 数据查询仍使用只读接口。顶部和数据库菜单新建查询均为空白；表菜单新建查询生成目标表的 SQL，不直接执行。

closeTabs(key, mode) 支持 current/others/right，按目标页签与当前顺序批量关闭，并清除被关闭查询的结果与选择状态。当前页保留时不切换；被关闭时选择邻近的保留页，全部关闭时创建空白查询。执行期间禁止关闭，右键关闭不发送 SQL 或删除数据库对象。closeTab 复用 current 模式。

## 连接树与联动

连接操作通过 connectionAction(action, id) 显式指定目标，编辑/删除不依赖当前查询连接。关闭清空该连接的结构缓存并取消请求，清空所有引用该连接的查询的连接/库/表选择，保留 SQL 与已有结果快照；重连不恢复旧选择；保存编辑后使目标连接缓存失效，不改变其他连接的活动范围。后端按请求独立释放数据库会话，因此关闭在前端管理元数据生命周期，无需新增断开接口。

右侧只可选择已加载成功的连接；切换连接清库表，切库清表。表与数据库右键执行完整目标范围，查询请求、历史与结果来源均使用目标连接，而非当前下拉连接。保存的草稿不会自动打开连接；先展开再使用，运行快捷键也受连接状态保护。

openHistory 仅在有效连接范围下打开抽屉并重置搜索。QueryHistory 按当前 connectionId 筛选历史，页面以连接 ID 作为组件 key，避免跨连接保留分页和展开状态；历史入口在运行工具栏导出之后。

validateDatabases 由元数据加载成功事件调用，按连接 ID 同时校验前台和后台查询；请求取消或失效时不调用。只有元数据校验通过才恢复字段/DDL 请求，不自动执行 SQL。删除连接仍清理失效的连接范围，编辑连接仍清空其旧库表。

openConnection 统一处理树箭头、双击和右键打开。连接未打开或首次加载失败时，先清空该连接相关草稿中的库/表，再加载结构，不从持久化草稿默认选库；已连接节点通过箭头收起/展开保留用户当前选择；点击或双击连接名称时回到连接范围，清空当前查询的库/表选择。SQL 和结果不受影响。
