# 工作区恢复与保存

useWorkspacePersistence(snapshot,restore) 返回 ready/saving/error。读取 Go workspace 分区，只有缺失时读取旧加密 IndexedDB，兼容更早 localStorage 草稿；验证成功才恢复，首次空界面不覆盖旧配置。写入300ms防抖，状态表示最新提交是否完成。Go是唯一保存目标，失败不回落浏览器；旧加密记录保留供迁移核对。配置包括页签/SQL/结果/视图/编辑器位置/树状态和布局，不包括连接凭据；恢复只读必要元数据，不执行 SQL。

未知工作区版本、损坏、解密失败或后端读取失败保留原数据并停止本会话持久化；保存冲突显示错误，需要刷新。最后300ms未提交变更可能在强制关闭时丢失。表设计标签描述可恢复，未保存表单草稿不进入配置。

当前缺失配置直接使用默认空工作区，不再迁移旧浏览器记录，删除配置可重置布局。
