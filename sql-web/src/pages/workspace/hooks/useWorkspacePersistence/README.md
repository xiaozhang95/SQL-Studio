# 工作区加密恢复与保存

[源码](index.ts)

参数为 WorkspaceSnapshot 与 restore 回调，返回 ready、saving、error。首次恢复完成前不保存空状态，页面禁止编辑；只保存明确白名单字段，不包含连接凭据。页签、范围、SQL、结果、结果选择/筛选/分页、编辑器位置、对象树和结果面板高度均写入加密 IndexedDB。

快照由调用方 useMemo 保持稳定；变化即异步提交，同名写入按序完成。状态指示在最新提交完成后显示已保存。旧草稿存在时迁移为加密记录，提交成功后移除对应明文；结果高度也迁入快照。读取失败保留原记录，本次会话不覆盖；保存错误明确返回，不降级为明文。

恢复仅重建页面，元数据重连由工作区负责，不恢复 SQL 请求。刷新打断的运行显示提示，已完成结果仍可查看。

sidebarWidth 随同一快照保存，兼容不含该字段的 version=1 旧快照；调用方回退到 272px，不新建明文尺寸记录。

支持恢复 table-create/table-design 标签描述。表单草稿只在切换时由存活组件保留，不加入加密快照；刷新后重新读取必要结构，不自动保存或执行 DDL。
