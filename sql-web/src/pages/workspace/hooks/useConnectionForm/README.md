## 调用与返回

`({ open, connection?, onSaved })`

返回 form、engine、busy/saving/testing、section、status、切换/测试/保存回调及面板状态设置器。

## 生命周期与边界

初始库默认 postgres；切换类型只替换仍为默认值的端口/用户名。空密码保留交给服务端按 ID 处理；不回显凭据。测试状态在关闭后清理，避免动画结束覆盖成功反馈。

请求错误、取消和持久化失败沿用实现中的边界，组件不重复维护同一份业务状态。

## 当前交互

新建表单仅预填数据库类型对应端口，其余输入为空；切换类型只调整仍为默认值的端口，不自动填入名称、主机、账号或初始库。编辑已有连接继续回显脱敏信息，空密码保留旧凭据。
