# SQL 工作区

[源码](index.tsx) · [组件](components/README.md) · [hooks](hooks/README.md) · [配置](constant/README.md)

index.tsx 只组合顶栏新建连接/新建查询与主题、左侧连接、SQL 编辑与结果、连接弹窗和历史抽屉。业务状态位于 useWorkspace，快照由 useWorkspacePersistence 加密保存，主题由 App 提供。连接、库、表和 SQL 随查询标签保存；执行和真实结果归属发起窗口。

整体布局集中在 src/app.scss，全局 src/app.scss 将布局颜色映射到 Ant Design 原生 CSS token；主色不单独定义。入口先加载 antd/dist/reset.css。连接、库选择在运行按钮前；历史入口在导出之后，使用表格分页展示，行详情默认折叠。移除品牌标题、侧栏重复标题/连接信息和对象/历史数量；只读状态合并进开关。图标引用品牌资产，信息 Tag 使用蓝色 solid，Button 使用组件默认样式。SQL 编辑器继承页面系统字体。

表操作通过对象树右键菜单发起；主区域只有一层可关闭页面标签。分页固定在滚动区外。信息 Tag 按当前要求使用蓝色 solid，语义状态保留状态色。

## 布局修正

主区域无外边距，编辑器和结果面板使用无圆角、无阴影的贴边布局，仅保留区域分隔线；有结果时两区直接相邻，结果顶部预留独立拖动区。进入或刷新恢复本机加密快照，没有保存记录时为空；空白区展示新建查询和双击对象的简短提示，关闭最后一个查询后同样隐藏；双击库展示结构列表，双击表展示数据，不隐式新建 SQL 草稿。对象结果页铺满主区域并隐藏伸缩条。无结果时整个底部面板隐藏，已有查询编辑器填满剩余区域；结果表格双向滚动留在 Table body，分页位于滚动区外，避免滚动条裁切。

左侧统一为连接 → 数据库 → 表/视图的完整树，根节点右键打开/关闭、刷新、编辑、删除。成功加载结构才点亮连接；关闭取消并清空该连接的缓存，清空相关查询范围、保留 SQL 草稿，重连不恢复旧选择。右侧仅列出已加载连接和库，但选择范围和树高亮相互独立；树的单击、双击与展开均不修改查询下拉范围，表操作携带显式目标；历史按当前连接 ID 隔离。箭头或双击连接/库节点均可展开、收起并按需加载。

workspaceTabs 统一管理 query/data/structure/ddl 页面、状态色及关闭菜单。每个查询页的 SQL 和最新结果共用标签，重复执行替换该页结果；对象结果各自占一个页面。历史入口仅在 SQL 页面，按当前 SQL 页连接加载，按连接独立读取、保存及清空；载入直接追加到当前编辑器末尾并添加历史注释，不新建标签。

SQL 页支持一次执行多条语句，依次调用现有只读单语句接口，每条结果在同页结果标签选择，并可在并列的消息、摘要标签查看执行 SQL，不新增页面。整批固定源连接，逐条保存历史；失败或取消停止后续语句，保留已完成结果，重复运行替换整批。

恢复包含页签、SQL、结果/筛选/分页、选中结果、编辑位置、树展开/选中和结果高度，仅重新加载必要元数据，不自动执行 SQL。选连接补全库名，选库自动加载表/视图；顶部 Tab 和结果标签使用当前选中结果的语义色。

对象栏右边缘可拖动伸缩，支持键盘左右/Home/End 及双击恢复默认；宽度随加密布局保存，刷新恢复，窗口变窄时保留主区域空间。查询结果和执行历史分页共享配置与底栏样式，均使用默认 32px 页码，保持各自 50/10 条的每页数量。

输出区采用消息、摘要、逐条结果的并列标签。消息和摘要展示已执行 SQL，支持只读语法高亮及复制；摘要记录前端批次起止和运行时间，语句成功耗时来自后端、失败耗时来自前端请求计时，旧记录缺失值显示未记录。参见 [输出记录工具](utils/README.md)。

库/表右键操作复用 objectManagementModal 与 useObjectManagement；新建/编辑采用可视化表单和单次显式写入，危险操作输入对象名确认。结构转储为本地 SQL 下载（仅结构），普通编辑器仍默认只读。

新建表与设计表固定在右侧主标签，不再弹窗。工具栏固定、正文独立滚动，切换查询页或其他设计页保留本次草稿；保存后原页继续设计。库编辑及删除/清空/重命名等操作仍使用确认弹窗。

当前保存提示为已保存到本机，界面状态与主题由 Go 用户目录配置管理。

配置错误提示支持关闭；关闭提示不将失败伪装为保存成功。

顶部“新建查询”右侧以竖线分隔 AI 配置入口，弹窗支持服务商、官方动态模型列表、API Key 与续写开关，服务商品牌和接口由 ai 适配器提供；打开弹窗获取模型列表，保存不生成或执行 SQL。

界面主题选择器提供选择界面主题的placeholder；所有可见表单输入与选择控件均有字段语义占位提示，隐藏字段与开关除外。

顶栏前两个操作归入与侧栏同宽的分区，竖线对齐对象栏右边界，DeepSeek与主内容保持相同12px起始内边距。顶栏和侧栏共用useSidebarResize的visibleWidth，拖动/键盘调整/窗口缩放同步；侧栏收窄时按钮自然换行，避免重叠。
