# 连接与对象侧栏

[组件索引](../README.md) · [源码](index.tsx)

## 参数与回调

model 取自 useWorkspace；使用连接列表、当前连接、加载/错误、对象快照及连接操作回调。

## 行为与边界

侧栏顶部仅保留连接选择及操作菜单，不重复展示连接标题、类型、地址和数量标签。新建连接主按钮位于全局顶栏；执行历史按钮固定在侧栏底部，不显示数量。选择连接清空当前标签旧库表；对象树内部滚动。

连接选项使用 flex 排列和 20px 装饰图标，避免 inline-flex 基线把 Select 撑高；选择器和操作按钮保持 Ant Design 标准 32px 高并垂直对齐。

页面私有组件从 `./components/connectionSidebar` 导入；只服务工作区，不通过聚合出口扩散依赖。
