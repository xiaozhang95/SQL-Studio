# 页面结果展示

[组件索引](../README.md) · [源码](index.tsx)

model 提供当前页 run/result、运行状态、筛选与分页。本组件没有结果导航，主页面标签由 workspaceTabs 统一管理。query 页结果与 SQL 编辑器上下共存，data/structure/ddl 页结果铺满可用区域，无编辑器和伸缩条；结果页不展示执行历史入口，历史只属于 SQL 编辑工具栏。

没有 run 时返回 null；开始执行即显示当前页加载状态，成功零行仍显示成功反馈。每页保存最新结果，切页恢复自己的筛选和分页；重复执行重置该页视图。状态、耗时、错误与实际来源保存在 run 中，来源通过页面标题悬停展示。

Table 使用原生 size=small 和 8px 单元格内边距，字段名/类型间距 2px；NULL 显示次级文字 `(NULL)`。二维数组按列索引保留重复列、NULL 和大整数文本。结构列表按类型显示表/视图图标，普通查询单元格不添加对象图标。

useTableViewportLayout 分配表体高度，双向滚动仅位于 Table body；外部分页固定，每页 50 行。筛选/翻页/结果更新回到内容顶部；CSV 导出当前结果的全部筛选行。操作通过左侧对象菜单发起，不在结果区重复提供结构/DDL 切换按钮。

外部分页复用 [tablePaginationDefaults](../../constant/tablePagination/README.md)，与执行历史采用同一配置及底栏样式：默认尺寸 32px 页码、统一计数文案和内边距，分页仍独立于表体滚动。

工具栏始终显示“选择语句结果”Select，使用与上方连接选择器一致的原生默认尺寸及 220px 宽度，只有一条结果也保留下拉框；独立对象结果及旧快照以单项展示。多语句的所有结果仍属于同一 SQL 页面。执行中禁用切换并显示执行占位，结束默认显示最后执行语句；切换结果重置筛选与分页。失败/取消提示剩余未执行数量，之前成功结果仍可选择和导出。重复执行替换本页整批结果。

选中成功/失败结果时，Select 文字、边框、箭头及主页面 Tab 同步语义绿/红；弹层各项分别着色，选中与 hover 使用对应状态背景。记录与选中索引随加密快照恢复，刷新不重新查询。interrupted 显示上次刷新打断运行的提示；结果高度由工作区受控。

结果选项、框内状态图标和状态色统一交给 [resultSelect](../resultSelect/README.md) 封装，外侧只显示耗时，不再重复成功/失败图标及文字。
