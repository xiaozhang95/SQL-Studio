# 多结果展示

[组件索引](../README.md) · [源码](index.tsx)

model 提供当前结果、结果快照列表、切换/关闭、筛选/分页。底部仅展示结果，不再放查看数据或结构/DDL 固定切换按钮；操作从左侧表右键菜单发起。

每次 SQL、表数据、结构及 DDL 查询新增不可变快照，支持切换与关闭，不覆盖旧结果。结果只在内存保存；切查询标签仍隔离。二维数组按列索引保留重复列、NULL 和大整数文本。字段类型显示为表头第二行的普通文字，NULL 使用次级文字 `(NULL)`；状态和耗时采用图标加文字，工具栏不再展示连接/数据库来源标签。结果来源仍保留在快照数据中。

Pagination 是滚动区外的独立组件，每页 50 行，分页右对齐，索引列固定左侧；切页、筛选及切结果回到内容顶部，CSV 导出当前结果的全部筛选行。滚动区可通过键盘操作。组件布局优先使用 style；沿用 Ant Design Table、Tabs 和 Pagination 默认控件。

## 布局修正

没有任何结果快照时整个组件返回 null，包括待执行、筛选/导出与空态全部隐藏；存在结果快照时直接展示可伸缩面板，不提供折叠按钮或折叠状态；已执行但零行的结果仍显示成功反馈。表头和表体由 useTableViewportLayout 分配高度，纵向和横向滚动统一位于 Table body，外层不再套滚动；分页继续在外部固定。

## 页签样式

上下查询页签共用 workspace-tabs 样式与 Ant Design editable-card，统一背景、边框、间距、图标、原生关闭按钮和主题 colorPrimary 激活色。结果页签隐藏新增按钮，通过原生 onEdit 关闭快照。每个结果快照携带 kind（query/data/structure/ddl），分别使用 Code/Table/Profile/FileText 图标；失败结果保留原操作类型。样式覆盖统一在 src/app.scss，局部布局用 style。

结果 Tabs 同样使用原生 size=small，与查询页签均为 32px 高、4px 8px 内边距；上下共用导航底色及激活/非激活背景层次。
