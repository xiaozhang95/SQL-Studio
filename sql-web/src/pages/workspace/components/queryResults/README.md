# 多结果展示

[组件索引](../README.md) · [源码](index.tsx)

model 提供当前结果、结果快照列表、切换/关闭、筛选/分页与面板显隐。底部仅展示结果，不再放查看数据或结构/DDL 固定切换按钮；操作从左侧表右键菜单发起。

每次 SQL、表数据、结构及 DDL 查询新增不可变快照，支持切换与关闭，不覆盖旧结果。结果只在内存保存；切查询标签仍隔离。二维数组按列索引保留重复列、NULL 和大整数文本。信息 Tag 使用蓝色 solid，状态使用语义色，来源必须保留。

Pagination 是滚动区外的独立组件，每页 50 行；切页、筛选及切结果回到内容顶部，CSV 导出当前结果的全部筛选行。滚动区可通过键盘操作。组件布局优先使用 style；沿用 Ant Design Table、Tabs 和 Pagination 默认控件。

## 布局修正

没有任何结果快照时整个组件返回 null，包括待执行、筛选/导出与空态全部隐藏；已执行但零行的结果仍显示成功反馈。表头和表体由 useResultTableLayout 分配高度，纵向和横向滚动统一位于 Table body，外层不再套滚动；分页继续在外部固定。

## 页签样式

结果页签采用 Ant Design 原生 line 下划线样式，与连接表单常规/SSL 一致；保留独立关闭按钮，不再使用 editable-card。样式覆盖统一在 src/app.scss，局部布局用 style。
