# SQL 优化预览

SQLOptimization({model: ReturnType<typeof useAISQL>, themeMode}) 展示原 SQL、模型建议 SQL 和中文说明，复用只读 SQLPreview。请求中显示加载并允许取消，失败显示错误；有完整结果才允许应用。应用委托 hook 校验原文档并替换，不执行查询或索引建议。弹窗关闭后清空结果。

弹窗标题为优化建议，原文/优化结果用自适应网格双列等高预览对照，容不下两个 320px 面板时上下排列；每个面板只显示一次标题并将复制按钮并入标题栏。下方独立展示调整说明，保留换行并对连续长文本自动折行，避免横向撑开正文。正文限制视口高度，仅纵向滚动，页脚操作保持可见；网格不使用负边距，避免滚动区域出现多余横向滚动条。
