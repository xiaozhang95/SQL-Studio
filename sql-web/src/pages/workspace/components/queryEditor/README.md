# 查询编辑与执行工具栏

[组件索引](../README.md) · [源码](index.tsx)

model 提供查询标签、SQL、连接库表范围、补全字段、运行/取消与编辑器实例回调。按钮文案统一为运行、导入、导出；工具栏左侧为已加载连接、库、运行与执行时的取消，右侧为导入、导出、执行历史；行数选择与写入模式开关、状态及确认逻辑均已移除。请求不传 limit/allowWrite，使用后端默认只读和默认上限。

编辑器保留系统字体继承、高亮、补全和 Ctrl+Enter。工具栏右侧导入 SQL 在独立 hook 中本地读取文件并新建标签，不覆盖当前 SQL，不自动运行。导出 SQL 调用 model.exportCurrentSQL，将当前标签完整文本保存为 UTF-8 .sql 文件；空白 SQL 禁用导出，无需连接数据库。

查询页签使用 Ant Design size=small，原生高度 32px；结果页签使用相同 small 尺寸。二者共用 workspace-tabs 卡片背景、激活色、图标与原生关闭按钮。

查询页签整块支持右键菜单：关闭当前、关闭其他、关闭右侧；按右键目标计算，不提前切换活动页。执行期间菜单禁用，无其他/右侧页签时对应项禁用。关闭最后一页会保留一个空白编辑器。SQL 补全弹层统一页面字体、主题背景、边框、阴影和圆角；移除 emoji 图标和匹配下划线，保留键盘选择与匹配加粗。

运行按钮与快捷键仅允许使用结构已加载成功的连接；导入与导出 SQL 草稿不依赖连接。选择器与左侧树共用缓存和当前标签范围，窄视口工具栏允许换行。

不再提供表下拉，表仍由树节点选择并参与补全。执行历史调用 model.openHistory，打开前清空搜索；未选择有效连接时禁用入口，历史按当前连接 ID 隔离。

页签和工具栏等操作文字不产生浏览器选区；编辑器、下拉搜索输入仍允许文字选择，SQL 编辑、全选及复制行为不变。

上下页签导航使用更明显的主题底色，非激活项使用抬升背景，激活项使用内容区背景；亮色导航使用 colorFill，区分导航、非激活与激活三个层次。
