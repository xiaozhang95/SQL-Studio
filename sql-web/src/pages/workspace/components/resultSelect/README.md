# 结果与状态选择器

[组件索引](../README.md) · [源码](index.tsx)

run 提供同页语句结果，running 为执行锁，resultIndex/onChange 为受控选择。单项结果、独立对象结果及旧快照均显示 Select，保持原生默认 32px 高度及 220px 宽度。

框内 prefix 展示当前结果的成功/失败图标；文案、边框、箭头和图标共用当前选中结果的语义色，弹层每项也有对应图标。外侧不再重复状态图标和成功/失败文字，耗时由 queryResults 展示。父级根据同一个 resultIndex 同步主页面 Tab 状态，选择后由 onChange 重置筛选与分页。

执行中使用旋转图标和“执行中”文案，禁用切换且不沿用已完成语句的成功色；空结果展示“暂无结果”。长 SQL 单行省略，选项 title 保留完整 SQL；不执行查询、不写入持久化、不修改范围。
